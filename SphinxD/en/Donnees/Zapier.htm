USING ZAPIER WITH SPHINX ONLINE

Zapier lets you connect Le Sphinx with thousands of the most popular apps, so you can automate your work and have more time for what matters most. Learn more.

You can use SphinxOnline triggers and actions from Zapier.

Triggers

  • Trigger an action each time a new complete survey response is received.

    Mandatory fields: Survey name.

  • Trigger an action each time a new complete survey response is received, with the option of recalling the content of responses to certain survey variables.

    Mandatory fields: Survey name.

    EXAMPLE: For example, recall the satisfaction score given by the respondent and other useful information.

  • Trigger an action when an email address is added to the blacklist.

Actions

  • Configure an action that adds a new recipient to the list of emailing recipients.

    Mandatory fields: Survey name, Mailing ID, Address, Parameters.

NOTE: An API access token is required to connect SphinxOnline to Zapier. Access the API access token generation procedure.
