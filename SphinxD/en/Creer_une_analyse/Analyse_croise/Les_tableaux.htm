Configure tables

By default, a crosstab appears as a table. Several options are available to you:

  • Choose the type of values to display in the table.

    EXAMPLE: number, percentage, bar percentage, average, etc.

    NOTE: In the case of a multivariate analysis, it is possible to choose the values to display for each of them. To do this, click , and then choose the values to display for each variable (in rows and in columns).

  • Display the totals of the values (totals in rows, in columns in the case of a multivariate analysis).

  • Display the variations, check the Show cell variation box. 

  • Use the Conditional formatting option allows you to customize the display of cells in your table by comparing the values presented with custom-defined thresholds.

  • Define objectives option allows you to compare cell values to well-defined objectives. The difference can be displayed in values or percentages. To set objectives, proceed as follows:

    1. Select the table.

    2. Click on .

    3. Define an objective for each modality (to be displayed in values or percentages).

    4. Set the options (choice of reference mode, style and other display options):

      1. Choose to compare the objective to the previous column (default) or to a fixed column.

      2. Assign an icon and define its color, when the objective is reached / not reached.

      3. Rename the objectives column, choose to display the deviation in values or in percentages.

        NOTE: Tick the ‘Difference in a separate column’ box to display it in a new column.

  • To change the display of modalities and variables heading (by displaying either text, image or both simultaneously), to assign an image to each modality/variable, proceed as follows:

    1. Choose the Text and Image or Image option from the Heading drop-down menu.

    2. Click .

    3. Click on the + button placed in front of each modality / variable then select an image from the DATAVIV 'gallery (images / pictograms) or by importing it directly (from the internet or from your computer).

    4. Define the size to use for the images.

  • Set the columns initial size allows you to customize the width of the columns in your table, to do this, proceed as follows:

    1. Check the option Set the columns initial size.

    2. Enter column widths, in pixels, and separated by semicolons (;).

      An empty field indicates that the column width is calculated automatically.

    NOTE: The option will be automatically checked if you manually modify the width of the columns directly from the table. A value will be displayed according to the modification made.
