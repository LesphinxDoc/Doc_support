Multi-report sharing

After finalizing the design and configuration of the various reports with controlled access, all you have left is to share the access by email.

Before sharing, you can configure and customize the login page and the reports home page, but also perform a final check by consulting the list of reports, the list of users and roles:

NOTE: Multi-report sharing only concerns reports configured to be viewed by Authorized users.

LIST OF REPORTS

From the list of reports, you can rename, duplicate or delete the created reports.

Additional information is displayed in the thumbnail of each report:

  • Type of access (Authorized users, password protected access, open access);

  • The number of users that can access this report;

  • The modification date.

USERS AND ROLES

In this part, you will have access to the list of users and roles with all the necessary information (list of reports, date of addition, date of connection). For an advanced display, click on .

Colored dots will appear next to each report name to indicate the status:

  • New: this user has been added recently. he has not yet been invited to log in to the report.

  • Contacted: this user was invited by email, but never logged in to the report.

  • Active: this user has logged in to the report at least once.

You can also filter the users according to report entitlement, profiles, status (new, contacted, active), date added or last connection date.

PARAMETERS

In this section, you can customize the display of the login page and the report home page.

To do so:

  • Login page

    1. Click on the Reporting tab, then on Authentication page.

      NOTE: The authentication page can only be configured if you have chosen one of the following sharing types: Password protected access or Authorized users.

    2. Modify the messages (Welcome message, authentication message & additional message), the color / background of the header and the color / background of the content.

      An image gallery is available to customize the background.

      NOTE: You can also import images from your computer (max size: 500 KB).

  • Home page for reports

    You can customize the title and description of the page (font, size and color).

Definition of the mailing list

Define the mailing list by adding the recipients to contact. To do this:

  1. From the Share my reports tab, click on the Add recipients button.

  2. Select the users to contact.

    You can filter the list of users using the "Filter" button.

  3. Finally click on "Save your selection".

Message setup:

  1. Add the name of the sender, his address and the object of the email.

  2. Personalize the content of your email through various options available in the toolbar.

  3. Check the "I accept the General Terms and Conditions" box.

  4. Click Send to send out the invitation e-mail.

    You have the access link to all the reports. It is possible to share it on social networks (Facebook, Twitter and LinkedIn) or to integrate it directly into a website using the embedding code.
