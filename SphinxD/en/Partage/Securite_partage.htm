Security & report sharing

You can securely share your report with other users. They then have access to the report views that are populated by data updated in real time as you collect responses. Depending on the type of sharing chosen, the data and views are filtered according to user profiles.

  • Click on to copy the report link.

    By clicking on the link to the report, a new page will open in your browser. This contains the report you have created with all its pages. You can then copy the generated link to distribute it by email or use the corresponding buttons to distribute it on social networks (Facebook, Twitter, LinkedIn).

  • Click on to generate an i-frame code if you want to integrate the view into your website.

    Embedding a report in an iframe or a pop-in is only allowed if the host domain is explicitly declared in a whitelist. Without specific configuration, any external embedding attempt is blocked.

    To define the authorized domains:

    1. Go to the Security and sharing section of the relevant report.

    2. Click the gear icon located to the right of “Report link”.

      A configuration modal window opens.

    3. Enter the domains authorized to embed the report via iframe or pop-in, then click Add.

      Format: *domain.com, sub.domain.com, .domain.com

      EXAMPLE:
      - lesphinx-developpement.fr authorizes only this domain.
      - subdomain.lesphinx-developpement.fr authorizes only this subdomain.
      - *.lesphinx-developpement.fr authorizes all subdomains.

    4. Click Validate.

3 types of sharing are available. Depending on the type of sharing you choose, data and views are filtered according to user profiles.

  • Open access:

    All users with the link can access the report.

  • Password protected access:

    All users with a report password can access it.

    A password is set by default.

    To view/change the report password, you must confirm your identity by first entering your account password.

  • Authorized users:

    Only the users you authorize, login/password identification. Access to data and views filtered according to user profile.

  1. Click on the Add users button to give users access.

  2. For each recipient, enter their e-mail address (mandatory) and all the information needed to define their profile.

    You can add users manually or import a list directly (in csv format) by clicking on the Import CSV file button.

    The user will be asked to create a password on first connection (the link is valid for 60 days only). This password will be valid for all reports that the user is authorized to consult on this platform.

It is also possible to modify users' profiles once they have been added. To do so:

  • Click on from the list of users.

    EXAMPLE:
    If you want to restrict the results according to the user's location, add the name of the study variable corresponding to the geographical location (for example, City), and for each individual the corresponding value (ex: London).
