Create a shared account

A shared account or collaborative account is a work environment shared between several accounts. It enables working on shared studies while keeping track of what was done by each user. Users can also have access to a personal account (nominative) in addition to the shared account to work on other studies.

  • Create a shared account

  • Add user accounts to a shared account

  • Remove a user's access to the shared account

  • Use a shared account from the user's perspective

 

Create a shared account

To create a shared account, proceed as follows:

  1. Log into your admin account.

  2. From the Accounts tab, click on the arrow to the right of the Create an account button, then click on Create a shared account.

  3. Fill in your information:

    • Name of the account (only letters, numbers, dashes and underscores allowed).

    • Email address.

    • Opening/closing date.

    • (Optional) Profile (Company name, Name, Firstname, Phone, Language).

    • Rights: configure account rights (responses credits, email credits, number of report users, etc.).

    • Limits: configure the number of responses by survey / number of questions by survey / number of surveys.

  4. Click on SAVE to finish.

    An email is automatically sent to ask to confirm the email address associated to the account.

    NOTE: Setting up a password for a shared account is not necessary.
    Indeed, you need to log in from the associated user account to access it.

Add access to a shared account

Once the shared account has been created, you can add the users/accounts who can access it (See the procedure for creating accounts).

NOTE: The same user can have access to multiple shared accounts.

To do so, you have three options:

  • Create a user

    1. Enter the user's name and email address.

    2. (Optional) Fill in the user's profile information.

    3. Click Create user.

      The created user is automatically linked to the collaborative account.

  • Link existing users

    You can link existing users to the collaborative account. To do so:

    1. Click the Link existing users button.

    2. Select the users to add.

      You can filter the user list using the Username and Email columns.

    3. Click Validate.

  • Import users

    1. Click the Import users button.

    2. Click Select file... and choose the file to import.

      NOTE: Allowed file types (".txt", ".csv", ".xlsx")

      The file must include the following two columns:

      • Login: User login.

      • Email: User's e-mail address.

      Optional columns:

      • firstname / lastname: User first name and last name.

      A summary will be displayed after importing the file (number of users to be created, error messages / warnings in case of issues—for example, an existing username).

    3. Click Create.

      The imported users are automatically linked to the shared account.

      NOTE: When a user is created, they must confirm their email address and set their password by clicking the link received by email. The link is valid for 96 hours.

The list of users with access to the shared account is available from the right-hand side panel.

Remove a user's access to the shared account

To remove a user's access to the shared account, proceed as follows:

  1. Select the shared account in the list of accounts.

  2. Click on the Manage users button.

  3. Click on the icon next to the user whose access you want to remove.

  4. A confirmation message pops up, click on Remove access to validate.

Use a shared account from the user's perspective

The user can switch between their personal account and the shared accounts they have access to at any time.

To do so:

  1. Click on the name of your account.

  2. Click on Change account.

  3. Select the shared account to use.

Conflict prevention

It is strongly discouraged to work simultaneously with others in the same environment. Doing so may result in the loss of changes made by users.

When multiple users access the same survey environment at the same time using a shared account, an indicator showing the number of users currently logged in (excluding the current user) will appear at the top right of the screen.

A warning message will also appear depending on the environment:

  • When saving a view in the analysis environment (Dataviv).

  • When one user enters the Design section (online survey design).
