Réaliser une analyse croisée / multiple

  • Un tri croisé permet d’analyser simultanément les réponses à deux questions. Le croisement étudie en outre, la présence ou non de dépendance entre les deux variables et leur degré de corrélation.

    EXEMPLE : Dans une enquête portant sur le tourisme, on peut vouloir étudier le lien entre le lieu du séjour et les dépenses totales.

  • Une analyse croisée multiple permet d’analyser simultanément les réponses à plus de deux questions. Cela permet d’étudier le lien entre plusieurs paramètres et de synthétiser les résultats pour affiner l’analyse des réponses.

    EXEMPLE : Dans une enquête portant sur le tourisme, on peut vouloir étudier le lien entre le sexe, l’âge et les dépenses totales du séjour.

Il existe trois manières de réaliser une analyse croisée / multiple :

  1. La première solution est de dépouiller les réponses. Tout d’abord on place une première variable (drag & drop depuis la liste à gauche) sur la zone de travail centrale. Ensuite, en cliquant-glissant une autre par-dessus, un onglet croiser va apparaître. En glissant la variable sur cet onglet, les variables vont automatiquement se croiser.

    Veuillez cliquer sur l'image pour un aperçu animé

  2. La deuxième solution est de sélectionner au moins deux variables présentes sur une même page de travail et cliquer sur le bouton .

  3. La troisième solution est de choisir analyse croisée/ multiple en passant le curseur sur le bouton d’ajout d’un nouvel élément (Bouton ). Procédez à un drag and drop de la variable que vous souhaitez affecter en colonne, ligne ou cellule, depuis la liste des variables disponibles à gauche, vers la zone correspondante.

Réaliser une analyse multivariée

Il existe deux manières de réaliser une analyse multivariée.

  • La première solution consiste à glisser-déposer une nouvelle variable sur une analyse croisée ou une analyse multivariée déjà existante. Trois onglets vont apparaître, ajouter une ligne, ajouter une colonne ou mettre en cellule, il faut faire glisser la variable sur l'onglet en fonction de l'endroit où vous souhaitez la placer.

    On obtient généralement un tableau croisé avec un graphique dont les propriétés peuvent être modifiées à l'aide de la boîte de dialogue.

  • La deuxième solution consiste à sélectionner une analyse croisée ou multivariée avec une variable présente sur la même page de travail.

    Des icônes apparaissent sur les tableaux sélectionnés pour indiquer l'opération souhaitée.

    • permet d'ajouter une variable en ligne à l'analyse croisée ou multivariée.

    • permet d'ajouter une variable en colonne à l'analyse croisée ou multivariée.

    • permet de mettre en cellule une variable dans l'analyse croisée ou multivariée.
