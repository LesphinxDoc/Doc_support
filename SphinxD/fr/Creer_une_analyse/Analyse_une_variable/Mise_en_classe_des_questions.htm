Mise en classe des questions numériques/dates

Afin de représenter les valeurs d’une variable de type numérique ou date il est possible d’affecter chaque valeur à une classe pour faciliter l’analyse et d’éditer la classification qui vous semble la plus pertinente.

Question de type numérique

EXEMPLE : Dans une enquête portant sur le tourisme, on peut vouloir mettre en classes les dépenses d’hébergement selon des bornes que l’on va définir pour faciliter l’analyse.

Les valeurs d’une variable numérique peuvent être groupées selon six méthodes de définition de classes :

  • Des classes de même répartition : permet de déterminer en combien de classes les valeurs seront groupées, avec un pourcentage similaire dans chaque classe.

  • Des classes de même valeur : il y aura autant de classes que de valeurs existantes dans la variable.

  • Des classes de même amplitude : permet de déterminer en combien de classes les valeurs seront groupées avec un écart entre les classes qui sera constant.

  • Des classes calculées autour de la moyenne : permet de choisir 3, 5 ou 7 classes dont l’intervalle de chacune a une longueur de 0.5, 1 ou 2 fois l’écart-type. La classe médiane contient la moyenne.

  • Des classes de même effectif : permet de déterminer en combien de classes les valeurs seront groupées avec le même nombre de valeurs dans chaque classe.

  • Des classes personnalisées : permet à l’utilisateur de définir les bornes de chaque classe.

Question de type date

Les valeurs d’une variable de type date peuvent être groupées selon différents regroupements périodiques prédéfinis.

EXEMPLE : Dans une enquête portant sur le tourisme, on peut vouloir mettre en classes les dates de départs en vacances selon les jours de la semaine.

Pour mettre en classes les valeurs d'une question, procédez comme suit :

  1. Sélectionnez votre analyse.

  2. Dans l’onglet Options, catégorie calcul, cliquez sur le bouton mettre en classes.

  3. Choisissez la méthode de classification souhaitée à l’aide du menu déroulant.

    REMARQUE : Dans le cas d’une analyse croisée contenant une ou plusieurs variables numériques / dates, il est possible de choisir la variable sur laquelle la mise en classes sera appliquée grâce au menu déroulant et si vous souhaitez l’appliquer aux variables similaires.
