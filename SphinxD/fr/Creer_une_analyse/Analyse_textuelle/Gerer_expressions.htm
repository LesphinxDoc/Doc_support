Gérer les expressions

Cette option permet d'utiliser la notion de proximité pour les formes d'expressions larges. C'est-à-dire qu'il sera possible d'associer plusieurs formes de l'expression sous le même format en ignorant plus ou moins de mots au sein de l'expression.

EXEMPLE : On souhaite repérer les expressions traitant de "l'accueil de l'agence". Or plusieurs formes peuvent être rentrées par le répondant, comme :
- Accueil de mon agence
- Accueil de notre agence
- Accueil de cette agence
- Accueil parfait dans mon agence
- Etc...

L'intérêt est de proposer une seule forme de l'expression permettant de regrouper l'ensemble de ces expressions.

Pour ajouter des expressions dans le lexique, procédez comme suit :

  1. Sélectionnez l'analyse textuelle.

  2. Depuis l'onglet Options, cliquez sur Gérer les expressions (bouton ).

    Une nouvelle fenêtre s'ouvre :

  3. Complétez manuellement les expressions à afficher dans le lexique.

    Le symbole % indique la proximité. Il permet de ne pas tenir compte du bruit entre les mots.

    REMARQUE : Définition du "bruit" :
    Il faut distinguer deux catégories de mots. Les mots qui seront détectés et les mots non détectés, que l'on appelle "bruit".
    Le bruit est composé de tous les mots sauf des noms et adjectifs.

  4. (Optionnel) Cliquez sur le lien Générer automatiquement les expressions pour générer automatiquement des expressions.

  5. Cliquez sur OK pour valider.

    L'expression est affichée dans le lexique sous la forme suivante : Mot1 ... mot2 (voir le nuage de mots ci-dessous).
