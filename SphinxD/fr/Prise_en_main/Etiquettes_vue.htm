Ajouter une étiquette à une vue

L'étiquetage de vue vous permet de mieux organiser votre liste de vues. Il est possible d'ajouter des étiquettes, filtrer sur ces étiquettes et les supprimer si besoin.

Ajouter une étiquette à une vue

Pour ajouter une étiquette, procédez comme suit :

  1. Accédez à la liste des vues (partie Analyse).

  2. Placez le curseur en dessous du nom d'une vue.

  3. Cliquez sur "+ Etiquettes".

  4. Donnez un nom à la nouvelle étiquette puis cliquez dessus pour l'ajouter ou sélectionner une/plusieurs étiquette(e) déjà existante(s) depuis le menu déroulant.

    REMARQUE : Les étiquettes doivent uniquement se composer de caractères alphanumériques, sans espaces ni signes spéciaux.

Filtrer les vues selon une étiquette

Pour filtrer les vues selon une étiquette, procédez comme suit :

  1. Accédez à la liste des vues (partie Analyse).

  2. Depuis le menu déroulant Mes étiquettes, sélectionnez une ou plusieurs étiquette(s).

    Seules les vues ayant l'étiquette concernée seront affichées dans la liste des vues.

Supprimer une étiquette

Pour supprimer une étiquette,

  1. Survolez l'étiquette de la vue concernée.

  2. Cliquez dans la zone pour entrer en édition.

  3. Cliquez sur l'icône de l'étiquette à supprimer.

    L'étiquette est supprimée.

    REMARQUE : Si l'étiquette supprimée (au niveau de la vue concernée) est associée à d'autres vues, elle sera toujours disponible dans la liste des étiquettes.
