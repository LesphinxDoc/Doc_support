Prompts IA : Guide et modèles

Guide pratique : créer facilement un prompt pour générer une variable avec l’IA

Créer un prompt peut sembler technique, mais en réalité, il s’agit surtout d’expliquer clairement à l’IA ce que vous attendez.

Ce guide est là pour vous accompagner pas à pas dans la rédaction de prompts.

1. À quoi sert un prompt ?

Un prompt est une instruction qui permet d’expliquer à l’IA ce que vous attendez d’elle. C’est grâce à lui que l’IA comprend la tâche à réaliser, les informations à utiliser et la forme du résultat à produire.

Un bon prompt garantit donc un résultat clair, cohérent et conforme à vos besoins.

2. Les éléments indispensables d’un bon prompt

L’important est de structurer votre prompt de manière simple et logique : un éventuel contexte, une instruction principale, les règles à respecter et le format attendu.

  • Le contexte (facultatif, mais utile)

    Le contexte fournit à l’IA les éléments nécessaires pour savoir sur quoi porte la variable, mais pas ce qu’elle doit faire.

    Il peut inclure une notion, un concept ou un domaine auquel la variable se rattache.

    EXEMPLE : thématique RH, expérience utilisateur, perception d’un service.

  • La tâche

    La tâche décrit ce que l’IA doit faire concrètement. C’est l’action précise à réaliser à partir de la donnée.

    EXEMPLE : analyser un texte, détecter un ton, choisir une catégorie parmi une liste, attribuer un score selon des critères définis.

  • Les règles

    Les règles expliquent comment l’IA doit prendre sa décision. Elles posent les critères, définitions et conditions nécessaires pour garantir un résultat cohérent.

    EXEMPLE : décrire les catégories possibles, indiquer les seuils, préciser quoi faire en cas de réponse ambiguë.

  • Le format attendu

    Le format attendu indique la forme exacte du résultat final. C’est essentiel pour que la variable soit exploitable dans votre analyse.

    EXEMPLE : un chiffre unique, un label exact, une liste, un ou plusieurs résultats, un format de texte (minuscules / majuscules) ...

3. Conseils pour un prompt efficace

  • Restez clair et direct : inutile de compliquer.

  • Expliquez les catégories ou niveaux pour éviter les interprétations.

  • Indiquez ce qui est interdit (justifications, reformulations).

  • Évitez les mots flous ou subjectifs (“beaucoup”, “long”, “pas assez clair”…).

  • Vérifiez qu’aucune règle ne se contredit.

  • Testez votre prompt pour vérifier qu’il fonctionne bien.

Et si vous avez besoin d’inspiration ou souhaitez partir d’un modèle existant, vous pouvez directement vous appuyer sur les prompts prêts à l’emploi listés ci-dessous, chacun adapté à un usage spécifique.

 

Modèles de prompts

Ce prompt classe le commentaire dans l’une des catégories standard : information, avis, demande, plainte, suggestion ou compliment. Pour l’utiliser, remplacez [Variable] par votre propre variable.

Questions de clarification

Ce prompt génère des questions utiles pour mieux comprendre ce que la personne exprime. Pour l’utiliser, remplacez [Variable] par votre propre variable.

Résultat attendu : Chaque question doit commencer par 1., 2. ou 3. et par une majuscule.

Copier

Résumé du texte

Ce prompt produit un résumé très court qui indique le sujet principal du commentaire. Pour l’utiliser, remplacez [Variable] par votre propre variable.

Copier 
Produis un résumé très court (quelques mots), indiquant clairement le sujet principal, dans la même langue que le texte.
Format : commencer par une majuscule et finir par un point.

Liste de tâches

Ce prompt génère des tâches concrètes basées sur les problèmes ou besoins exprimés dans le texte. Pour l’utiliser, remplacez [Variable] par votre propre variable.

Copier 
Analyse ce texte et, uniquement si la personne exprime un problème, une difficulté, une demande ou un besoin, génère des tâches concrètes pour y répondre.
Résultat attendu : Chaque tâche doit commencer par 1., 2. ou 3. et par une majuscule. Si aucune tâche pertinente, laisse la réponse vide.
Texte : [Variable]
Idées exprimées

Ce prompt extrait les idées essentielles du texte sous forme de mots-clés. Pour l’utiliser, remplacez [Variable] par votre propre variable.

Copier 
Identifie les idées présentes dans ce texte, sous forme de mots-clés, sans faire de résumé et sans phrases complètes. 

Résultat attendu : une liste de 1 à 5 idées très courtes, séparées par des points-virgules. 

Texte : [Variable] 
Détection adresses

Ce prompt identifie les adresses présentes dans un texte. Pour l’utiliser, remplacez [Variable] par votre propre variable.

Copier 
Repère les adresses éventuelles présentes dans ce texte (adresses postales, noms de rues, numéros, lieux précis). 

Résultat attendu : liste des adresses détectées, ou réponse vide si aucune adresse. 

Texte : [Variable] 
Catégorie socioprofessionnelle (CSP)

Ce prompt permet d’identifier la catégorie socioprofessionnelle à partir d’une profession. Pour l’utiliser, remplacez [Variable] par votre propre variable.

Copier 
Transforme cette profession en catégorie socioprofessionnelle standardisée. 

Règles : 
- Agriculteurs, exploitants 
- Artisans, commerçants, chefs d’entreprise 
- Cadres et professions intellectuelles supérieures 
- Professions intermédiaires 
- Employés 
- Ouvriers 
- Retraités 
- Autres personnes sans activité professionnelle 

Résultat attendu : uniquement la catégorie socioprofessionnelle. 

Profession : [Variable] 
Guide d'appel en cas d'insatisfaction

Ce prompt propose deux phrases empathiques pour guider une conversation avec une personne mécontente. Pour l’utiliser, remplacez [Variable] par votre propre variable.

Copier

- une question pour clarifier la situation 
- une proposition simple pour aider la personne. 

Résultat attendu : La première phrase doit être une interrogation (?) et la seconde une proposition (.). Si le texte n’exprime pas d’insatisfaction, laisse la réponse vide. 

 Texte : [Variable]

Copier

Analyse du sentiment

Ce prompt détermine si le texte exprime un sentiment positif, négatif, neutre ou partagé. Pour l’utiliser, remplacez [Variable] par votre propre variable.

Copier 
Analyse ce texte et détermine le sentiment global exprimé. 

 Règles spécifiques :
 
- Si la majorité du contenu exprime des critiques, plaintes, frustrations ou remarques négatives → Négatif  
- Si le contenu n’exprime ni appréciation positive ni critique négative → Neutre 
- Si le contenu exprime principalement des appréciations positives → Positif  
- Si le contenu mélange positif et négatif → Partagé  

Résultat attendu : un seul mot parmi : Négatif, Neutre, Positif, Partagé. 

Texte : [Variable]
