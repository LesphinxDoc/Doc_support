Traduire mon questionnaire

Sphinx Declic permet de faire des enquêtes multilingues parmi plus de 40 langues. Vous pouvez donc traduire votre questionnaire dans les langues de votre choix et analyser toutes les réponses dans la même analyse.

Définir les langues de l'enquête

  1. Depuis le stade Questionnaire, cliquez sur l’onglet Langues.

  2. Sélectionnez les langues à ajouter dans votre enquête.

  3. Cliquez sur le bouton Enregistrer.

    Vous allez donc pouvoir traduire votre questionnaire dans chacune des langues que vous venez de sélectionner.

Traduire le questionnaire

Deux possibilités s’offrent à vous pour traduire votre questionnaire. Vous pouvez traduire par vous-même chaque question et texte (légende) du questionnaire, ou utiliser l’outil de traduction automatique.

Traduire le questionnaire manuellement

  1. Après avoir ajouté de nouvelles langues à votre enquête, à l’étape Questionnaire, cliquez sur l’onglet Traduction.

  2. Choisissez la langue source dans le menu déroulant Langue (il s'agit de la langue courante du questionnaire) et la langue cible dans le menu déroulant Traduction (c'est la langue dans laquelle vous désirez traduire le questionnaire).

    Les questions et modalités de votre questionnaire sont présentées en liste et des champs texte se trouvent à droite. Il s’agit alors de rédiger la traduction d’une question / modalité dans le champ texte correspondant. Ce travail doit être effectué pour chacune des langues sélectionnées.

    REMARQUE : Notez qu’il est possible d’utiliser ponctuellement la traduction automatique en cliquant sur l’icône  à droite de la zone de texte.

    N’hésitez pas à Tester votre questionnaire pour le visualiser dans la langue de votre choix.

Traduire le questionnaire automatiquement

  1. Après avoir ajouté de nouvelles langues à votre enquête, à l’étape Questionnaire, cliquez sur l’onglet Traduction.

  2. Choisissez la langue source dans le menu déroulant Langue (il s'agit de la langue courante du questionnaire) et la langue cible dans le menu déroulant Traduction (c'est la langue dans laquelle vous désirez traduire le questionnaire).

  3. Cliquez sur le bouton pour traduire tout le formulaire ou sur l'icône à droite d'une question pour ne traduire que la question (ou modalité) souhaitée.

    Votre questionnaire est alors automatiquement traduit dans la langue sélectionnée.

    REMARQUE : Il vous est possible de modifier les traductions proposées en cliquant dans la zone de texte de l'élément à modifier.

    N’hésitez pas à Tester votre questionnaire pour le visualiser dans la langue de votre choix.

Importer / Exporter des traductions

Il est enfin possible d'exporter les traductions définies dans Sphinx Declic ou d'importer un fichier de traduction pour traduire votre questionnaire sans utiliser l'utilitaire de traduction automatique. Cette dernière fonction est utile si vous avez au préalable traduit les questions de votre enquête sur un fichier xls.

Pour exporter des traductions :

  1. Cliquez sur le bouton Importer/Exporter.

  2. Sélectionnez l'option Exporter.

  3. Sélectionnez les langues à exporter.

  4. Cliquez sur OK pour télécharger le fichier de traduction.

Pour importer des traductions :

  1. Cliquez sur le bouton Importer/Exporter.

  2. Sélectionnez l'option Importer.

  3. Sélectionnez le fichier contenant les traductions.

  4. Cliquez sur OK pour importer les traductions.
