Gérer les liens

Dans cette partie vous pouvez accéder rapidement aux différents liens de questionnaires / observations et rapports de votre étude. Il est possible de les copier, d’en créer de nouveaux, de les éditer et de les supprimer si besoin.

REMARQUE : L'édition et la suppression des liens ne sont possibles que pour ceux créés depuis cette interface.

Créer un lien

  1. Accédez à l'onglet Général, puis cliquez sur Gestions des liens.

  2. Cliquez sur le bouton Créer un lien.

  3. Sélectionnez le type de lien à créer et configurez ses paramètres:

    • Lien de saisie

      1. Donnez un nom au lien.

      2. Paramétrez l'enregistrement automatique des saisies (facultatif).

        auto=1 / auto=2 / auto=3 / auto=4

        La saisie est enregistrée à chaque changement de page, le numéro de la page atteinte est conservé.

        Si auto vaut 1, 2 ou 3, cette page sera automatiquement affichée lors du prochain accès.

        Si auto vaut 4, on revient toujours sur la première page.

        Lorsque le questionnaire est définitivement enregistré :

        • Auto = 1 : Accès interdit (la réponse est déjà enregistrée).

        • Auto = 2 : Retour à la première page.

        • Auto = 3 : Retour à la dernière page.

      3. préremplissez certaines variables (facultatif) : permet d’attribuer des valeurs par défaut.

        EXEMPLE : Agence=Annecy&CodeBanque=7
        préremplit les variables "Agence" et "CodeBanque".

        REMARQUE : Ne pas utiliser de guillemets autour des valeurs.

      4. Choisissez la langue d'affichage du questionnaire.

        Si le questionnaire est multilingue, le choix Demander sera proposé par défaut pour permettre au répondant de choisir la langue.

      5. (Facultatif) cochez la case Options avancées pour définir des requêtes si nécessaire.

        Les requêtes disponibles pour le lien de saisie :

        • autosave : autosave = 1, enregistrement à chaque réponse de question (et non pas à chaque page).

        • conditions : conditions=no les conditions d'affichage et les renvois ne sont pas appliqués.

        • linkafter : &linkafter=http://....................... le script indiqué sera exécuté après l'enregistrement de l'observation.

          Cela permet par exemple d'écrire des données dans une autre base

        • linktype : pour forcer une action après enregistrement différente de l'action définie par défaut à la publication : URL|script|confirm

          • &linktype=script&linkURL=<URL encodée> : les réponses seront passées en paramètres au script (méthode GET),

          • &linktype=scriptpost&linkURL=<URL encodée> : les réponses seront passées en paramètres au script (méthode POST) (attention les réponses seront restituées sans recalcul final des variables calculées),

          • &linktype=URL&linkURL=<URL encodée>

          • &linktype=form&linkparam=1&linkparam2=html : on renverra des informations dans le formulaire d'indice 1 (les indices commencent ici à 0) et sous forme de page html (si ce paramètre est absent, le retour se fera sous forme d'une image sans possibilité de liens cliquables donc.

          • &linktype=report&linkparam=1 : on renverra des informations dans le rapport d'indice 1 (les indices commencent ici à 0)

          • &linktype=confirm : on renverra une simple confirmation.

        • login : pour indiquer le mot de passe de la saisie.

        • key : donner une clé pour la saisie, si elle n'existe pas une nouvelle observation sera créée.

        • readonly : readonly=1, le formulaire n'est pas saisissable.

        • svnjp : svnjp=1, permet de sauvegarder la réponse et de continuer la saisie du questionnaire.

        • transactions : transactions=no, toutes les pages sont affichées les unes à la suite des autres.

    • Consulter une observation

      1. Donnez un nom au lien.

      2. Choisissez la langue d'affichage du questionnaire.

        Si le questionnaire est multilingue, le choix Demander sera proposé par défaut pour permettre au répondant de choisir la langue.

      3. (Facultatif) cochez la case Options avancées pour définir des requêtes si nécessaire.

        Les requêtes disponibles la consultation des observations:

        • conditions : conditions=no les conditions d'affichage et les renvois ne sont pas appliqués.

        • login : pour indiquer le mot de passe de la saisie.

        • key : donner une clé pour la saisie, si elle n'existe pas une nouvelle observation sera créée.

        • sample : pour restreindre la navigation à un profil d'observations.

          EXEMPLE : &sample=1, indique que le profil correspond à la première strate prédéfinie.

          EXEMPLE : &sample=age>30 et sexe="homme" le profil est indiqué sous forme d'une expression booléenne.

        • transactions : transactions=no, toutes les pages sont affichées les unes à la suite des autres.

  4. Cliquez sur le bouton Créer.

    Les paramètres du lien sont modifiables à tout moment via le bouton situé à droite du lien.

Copier un lien

  1. Accédez à l'onglet Général, puis cliquez sur Gestions des liens.

    Une liste des liens créés s’affiche (liens de questionnaires, rapports, etc.).

  2. Cliquez sur l’icône à droite du lien concerné.

Supprimer un lien

  1. Accédez à l'onglet Général, puis cliquez sur Gestions des liens.

    Une liste des liens créés s’affiche (liens de questionnaires, rapports, etc.).

  2. Cliquez sur l’icône à droite du lien concerné.

  3. Cliquez sur Supprimer pour valider l'opération.
