Nettoyer les données personnelles des réponses

La gestion des données personnelles permet de supprimer les données qui ne doivent plus être conservées dans les réponses collectées.

Une action de nettoyage remplace les valeurs des variables sélectionnées par une non-réponse. Le nettoyage peut être effectué après une durée de conservation définie ou selon la réponse à une question de levée d’anonymat.

ATTENTION : La mise en place d’une action de nettoyage est rétroactive. Elle prend en compte l’ensemble des réponses collectées depuis la mise en place de l’enquête qui correspondent aux conditions définies.

ATTENTION : Le nettoyage est définitif. Les données nettoyées ne peuvent pas être restaurées.

Créer une action de nettoyage

Pour créer une action de nettoyage :

  1. Sélectionnez Gestion des données personnelles depuis l’onglet Données puis cliquez sur Créer une action.

  2. Saisissez un nom permettant d’identifier l’action dans Nom de l’action.

  3. Indiquez la date à partir de laquelle l’action de nettoyage doit commencer à s’exécuter dans Démarrer le.

  4. Cochez Arrêter le, puis indiquez la date de fin si vous souhaitez arrêter l’exécution de l’action à une date déterminée.

  5. Cochez Restreindre le nettoyage à un profil, puis sélectionnez le profil à utiliser si vous souhaitez appliquer le nettoyage uniquement à certaines réponses. Le profil détermine les observations auxquelles l’action de nettoyage s’applique.

    EXEMPLE : Une enquête recueille des réponses pour plusieurs marques ayant des politiques de conservation des données différentes. Si les données des répondants associés à la marque A doivent être conservées pendant 18 mois maximum, utilisez un profil pour cibler uniquement ces répondants et leur appliquer l’action de nettoyage correspondante.

  6. Choisissez le type de nettoyage à appliquer dans Conditions de déclenchement.

    1. Nettoyage récurrent selon une durée

      1. Sélectionnez Nettoyage récurrent selon une durée.

      2. Saisissez le nombre de mois pendant lesquels les données doivent être conservées dans Temps de conservation (mois).

      3. Sélectionnez la variable de date utilisée comme référence pour calculer la durée de conservation dans Sur la base de la variable.

      Lorsque la durée de conservation est atteinte, les variables sélectionnées dans l’action sont nettoyées.

      EXEMPLE : Vous définissez un temps de conservation de 12 mois et sélectionnez la date de réponse comme variable de référence. Une fois les 12 mois écoulés pour une réponse, les données concernées par l’action sont nettoyées.

    2. Nettoyage selon une réponse à une question de levée d’anonymat

      1. Sélectionnez Nettoyage selon une réponse à une question de levée d’anonymat.

      2. Sélectionnez la variable correspondant à la question de levée d’anonymat dans Variable.

      3. Sélectionnez la réponse correspondant au refus de lever l’anonymat dans Modalité.

        ATTENTION : dès lors que le répondant refuse de lever l'anonymat, ses données personnelles sont nettoyées. Elles ne pourront pas être récupérées s'il modifie ensuite sa réponse à cette question.

      4. Cochez Gestion des non réponses si vous souhaitez également prendre en compte les répondants qui n’ont pas répondu à la question de levée d’anonymat.

      5. Saisissez le nombre de jours pendant lesquels les données doivent être conservées dans Temps de conservation (jours).

      6. Sélectionnez la variable de date utilisée comme référence pour calculer la durée de conservation dans Sur la base de la variable.

        Le délai de conservation permet au répondant de revenir sur son choix avant le nettoyage de ses données. S’il choisit de lever son anonymat pendant ce délai, ses données ne sont pas nettoyées.

        Lorsque Gestion des non réponses est activée, le même principe s’applique aux répondants qui n’ont pas répondu à la question de levée d’anonymat. Ils disposent du délai défini pour revenir sur le questionnaire et choisir de lever leur anonymat. À l’expiration du délai, si aucune levée d’anonymat n’a été effectuée, les variables sélectionnées sont nettoyées.

        EXEMPLE : Vous définissez un temps de conservation de 30 jours et activez Gestion des non réponses. Un répondant qui ne répond pas à la question de levée d’anonymat dispose de 30 jours pour revenir sur le questionnaire et lever son anonymat. À l’expiration de ce délai, s’il n’a pas levé son anonymat, les données concernées par l’action sont nettoyées.

  7. Sélectionnez les Variables à nettoyer depuis la liste des Variables disponibles en utilisant les boutons de déplacement.

    Lors du nettoyage, les valeurs de ces variables sont remplacées par une non-réponse.

    ATTENTION : Vérifiez les variables sélectionnées avant d’enregistrer l’action. Les données nettoyées ne peuvent pas être restaurées.

  8. Activez Activer l’exécution automatique pour lancer automatiquement le nettoyage.

    Lorsque cette option est activée, l’action de nettoyage est exécutée automatiquement une fois par jour, à partir de la date définie dans Démarrer le.

    Si une date de fin est définie dans Arrêter le, l’exécution automatique s’arrête à cette date.

  9. Choisissez Enregistrer.

    L’action de nettoyage est créée. Lorsque l’exécution automatique est activée, le système vérifie quotidiennement les réponses et nettoie celles qui remplissent les conditions définies dans l’action.

    REMARQUE : Tous les paramètres obligatoires doivent être renseignés pour enregistrer l’action. Si un paramètre est manquant ou incorrect, un message s’affiche sous le champ concerné.

Recevoir une notification après l’exécution du nettoyage

Vous pouvez recevoir une notification par e-mail après chaque exécution de l’action de nettoyage. Cette notification contient un récapitulatif de l’exécution, notamment le nombre de réponses nettoyées.

Pour paramétrer la notification par e-mail :

  1. Cochez Paramétrer une alerte automatique.

  2. Sélectionnez l'adresse d'expéditeur à utiliser et définissez le nom d'expéditeur.

  3. Saisissez les adresses e-mail des personnes qui doivent recevoir la notification dans Utiliser les adresses email définies.

  4. Sélectionnez la langue du message.

    Un message par défaut est envoyé aux destinataires. Il contient le nom du compte, nom de l'étude, nom de l'alerte, ainsi que le nombre de réponses nettoyées et la date et conditions de déclenchement.

    Si vous souhaitez personnaliser l'objet et le contenu du message, cliquez sur Message personnalisé.

    REMARQUE : Le contenu des champs de fusion présents dans le message personnalisé s'affiche dans la langue sélectionnée à l'étape précédente.

    Pour rétablir le message par défaut, cliquez sur Réinitialiser l'objet et le contenu de l'email par défaut.

Gérer une action de nettoyage

Vous pouvez à tout moment modifier, dupliquer, exécuter ou supprimer une action de nettoyage. Vous pouvez également activer ou désactiver son exécution automatique.

Pour effectuer une action, cliquez sur l’icône correspondante dans la colonne Actions de la liste des actions de nettoyage.

Pour lancer immédiatement le nettoyage, choisissez Exécuter l’opération maintenant. Cette action permet d’exécuter le nettoyage manuellement, même si son exécution automatique est désactivée.
