Ressources pédagogiques, études de cas, enquêtes exemples et jeux de données

Pour accompagner les utilisateurs dans la plate-forme Sphinx Campus, nous avons mis en place quatre rubriques essentielles :

  • Les Ressources Pédagogiques,

  • Les Études de cas,

  • Les Enquêtes Exemples,

  • Les Jeux de données.

Ce guide vous expliquera comment accéder et utiliser ces ressources pour optimiser votre expérience avec Sphinx Campus.

Ressources pédagogiques

Les ressources pédagogiques sont destinées à vous aider à maîtriser les fonctionnalités des logiciels Sphinx. Elles comprennent des cours détaillés et des exercices pratiques, disponibles en téléchargement.

Accéder aux ressources pédagogiques

  1. Cliquez sur Mes Ressources,

  2. dans le menu de gauche, cliquez sur Mes ressources,

Chaque thématique listée dans la table des ressources pédagogiques propose un cours téléchargeable.

  • Cliquez sur le lien Cours souligné à côté de chaque thématique pour télécharger le cours au format pptx (PowerPoint).

  • Pour télécharger tous les supports de cours en une seule fois, cliquez sur le lien en bas de la page : Télécharger les supports de cours (.pptx 24.7Mo).

Études de cas

vous trouverez des enquêtes associées à des études de cas. Ces enquêtes vous permettront de suivre pas à pas les étapes clefs de la mise en place d'une étude.

Accéder à une enquête

Pour accéder à l'enquête en édition, procédez comme suit :

  1. Cliquez sur Mes Ressources,

  2. dans le menu de gauche, cliquez sur Études de cas,

  3. cliquez sur l'icône (  ) "voir l'enquête" correspondante à l'enquête concernée.

Télécharger l'étude de cas

Pour télécharger l'étude de cas de l'enquête concernée, procédez comme suit :

  1. Cliquez sur Mes Ressources,

  2. dans le menu de gauche, cliquez sur Études de cas,

  3. cliquez sur l'icône (  ) correspondante à l'enquête concernée.

Réinitialiser une enquête

Si vous avez supprimé une enquête ou que vous avez effectué des modifications et que vous souhaitez réinitialiser l'enquête exemple par défaut sur votre compte, procédez comme suit :

  1. Cliquez sur Mes Ressources,

  2. dans le menu de gauche, cliquez sur Études de cas,

  3. cliquez sur l'icône de réinitialisation (  ) correspondante à l'enquête concernée.

    Vous retrouverez l'enquête réinitialisée dans la rubrique Mes projets.

Enquêtes Exemples

Les enquêtes exemples mises à votre disposition vous permettent de vous entraîner et de mettre en pratique vos compétences en analyse de données.

Les enquêtes exemples traitent différentes thématiques : Les jeunes et la consommation,  le développement touristique, le climat interne entreprise, etc..

Accéder aux enquêtes exemples

  1. Cliquez sur Mes Ressources,

  2. dans le menu de gauche, cliquez sur Enquêtes exemples,

  3. cliquez sur l'icône (  ) "voir l'enquête" correspondante à l'enquête concernée.

    Les enquêtes exemples sont par défaut disponible sur votre compte, allez dans Mes projets pour y accéder.

Réinitialiser l'enquête

Si vous avez supprimé une enquête ou que vous avez effectué des modifications et que vous souhaitez réinitialisé l'enquête exemple par défaut sur votre compte, procédez comme suit :

  1. Cliquez sur Mes Ressources,

  2. dans le menu de gauche, cliquez sur Enquêtes exemples,

  3. cliquez sur l'icône de réinitialisation (  ) correspondante à l'enquête concernée.

    Vous retrouverez l'enquête réinitialisée dans la rubrique Mes projets.

Jeux de données

Vous pouvez télécharger ces jeux de données puis les importer via "Nouveau projet". Ces jeux de données vous permettront de tester les fonctionnalités offertes par l'import de données dans Sphinx Campus.

Pour télécharger un jeu de données, procédez comme suit :

  1. Cliquez sur Mes Ressources,

  2. dans le menu de gauche, cliquez sur Jeux de données,

  3. cliquez sur l'icône (  ) correspondante à l'enquête concernée.
