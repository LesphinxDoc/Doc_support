Rédiger le message SMS

Après avoir créé votre canal de diffusion, vous pouvez rédiger le message SMS à envoyer.

Lors d'une nouvelle campagne, rédigez le message d'invitation, premier message envoyé aux destinataires pour les inviter à participer à l’enquête.

Si besoin, un message de relance peut également être préparé afin de rappeler aux personnes n’ayant pas encore répondu de participer à l’enquête.

REMARQUE : La relance peut être effectuée par e-mail, par SMS, par message RCS ou par message WhatsApp.

Pour rédiger le message, procédez comme suit :

  1. Depuis la partie Diffusion, accédez à la rubrique Messages du canal concerné.

    REMARQUE : Par défaut un message d'invitation et un message relance sont mis à votre disposition. Vous pouvez les modifier et les utiliser ou les dupliquer si nécessaire.

  2. Cliquez sur le bouton Nouveau message puis sur SMS.

  3. Rédigez le contenu du message à envoyer.

    Un indicateur du nombre de caractères vous indique la taille du message.

    REMARQUE : Le nom d’expéditeur est, par défaut, remplacé par un numéro court. Si vous souhaitez définir un nom d’expéditeur, veuillez en faire la demande à l’adresse suivante : hotline@lesphinx.eu.

    Un aperçu du SMS s’affiche à droite de l’écran.

    REMARQUE : Le rendu peut différer selon l'appareil.

  4. Configurez le message à envoyer en remplissant les différents champs mis à votre disposition :

    • Lien du questionnaire : cliquez sur le bouton Lien du questionnaire pour l'ajouter dans le contenu du message à envoyer. Le champ [SURVEYLINK] sera ajouté dans le message, il se transformera automatiquement en un lien lors de la réception du SMS.

      Sélectionnez le lien vers le questionnaire à insérer dans votre message SMS depuis la liste déroulante (visible uniquement si vous avez créé au moins un lien depuis la Gestion des liens). Le texte [SURVEYLINK] sera remplacé par le lien sélectionné.

    • Champ de fusion : vous pouvez insérer des champs de fusion dans votre message si besoin pour afficher des données préremplies, cliquez sur Champ de fusion puis sélectionnez la/les variable(s) à insérer.

    • Sélection du type d'alphabet à utiliser : Alphabet occidental ou Alphabet non-occidental.

      Si le SMS est écrit dans une langue qui contient des caractères uni-code, vous devez sélectionner l'Alphabet non occidental pour qu'ils soient bien affichés.

      La longueur d'un SMS est de :

      • 160 caractères en alphabet occidental.

      • 70 caractères en alphabet non-occidental.

      REMARQUE : Certains opérateurs ne prennent pas charge ce type d'encodage SMS. Il est possible que vous ne puissiez pas tester la fonctionnalité.

    • La mention STOP : ce texte est automatiquement ajouté à la fin du message pour permettre au destinataire de bloquer la réception nouveaux SMS.

  5. Cliquez sur le bouton Enregistrer et quitter pour sauvegarder vos modifications.
