Rédiger le message e-mail

Après avoir créé votre canal de diffusion, vous pouvez rédiger le message e-mail associé.

Le message d’invitation doit susciter l’intérêt des destinataires et les inciter à répondre à l’enquête. Veillez à y inclure des informations claires sur le sujet, la durée de l’enquête et le lien de participation. Pour maximiser l’impact de vos envois, il est recommandé d’appliquer les bonnes pratiques en matière d’emailing (objet pertinent, ton adapté, personnalisation, etc.).

Si besoin, un message de relance peut également être préparé afin de rappeler aux personnes n’ayant pas encore répondu de participer à l’étude.

REMARQUE : La relance peut être effectuée par e-mail, par SMS, par message RCS ou par message WhatsApp.

Pour rédiger un e-mail :

  1. Accédez à la rubrique Messages du canal de diffusion concerné.

    REMARQUE : Par défaut un message d'invitation et un message relance sont mis à votre disposition. Vous pouvez les modifier et les utiliser ou les dupliquer si nécessaire.

  2. Cliquez sur le bouton Nouveau message puis sur Email.

  3. Sélectionnez un modèle dans les onglets Galerie ou Mes modèles, ou importez votre code MJML/HTML depuis l'onglet Importer du code.

  4. Nommez votre message, puis cliquez sur Appliquer.

    L’éditeur s’ouvre. Modifiez le contenu de votre message.

L'environnement de rédaction du message est composé de 3 zones :

  • Le volet de gauche, qui vous permet de sélectionner des liens personnalisés, des sections ou des contenus à glisser-déposer dans le message.

  • Le plan de travail, qui vous permet d'ajouter l'objet du message, le nom et l'adresse de l'expéditeur, de rédiger votre message, de visualiser son rendu sur ordinateur, tablette et mobile et d'accéder à d'autres actions complémentaires.

    Ajouter un objet, un nom et e-mail d'expéditeur

    Saisissez l'objet du mail, indiquez le nom de l'expéditeur et sélectionnez l'e-mail d'expéditeur.

    • Objet du mail : Insérez l'objet du mail.

      EXEMPLE : "Votre avis nous intéresse" dans le cadre d'une enquête de satisfaction.

    • Nom de l'expéditeur : Ce champ est facultatif, il correspond au texte qui apparaîtra dans le champ DE de votre e-mail.

    • Email expéditeur : Il s'agit de l'adresse e-mail qui sera utilisée pour l'envoi.

      Ajouter une adresse d'expéditeur

      Pour ajouter une nouvelle adresse, il suffit de cliquer sur le bouton + puis renseigner l'adresse.

      Un e-mail de validation sera envoyé à cette adresse. Elle devra être validée avant de pouvoir être utilisée comme adresse d'expédition.

      Cliquez sur la roue dentée pour gérer les adresses d'expédition (suppression / renvoi d'e-mail d'activation).

      REMARQUE : Veuillez suivre la procédure suivante pour ajouter un domaine d'envoi.

  • Le volet de droite, qui vous permet de modifier les propriétés des éléments sélectionnés.

Si vous partez d'un message vide, ajoutez d'abord des colonnes pour y insérer du texte, des images et d'autres éléments :

  1. Glissez déposez l’élément 1, 2 ou 3 Colonne(s) depuis la partie Section du volet de gauche.

    Cliquez sur l'image pour un aperçu animé

  2. Insérez les différents éléments que vous souhaitez ajouter à votre message (depuis les parties Liens personnalisés et Contenu) dans les colonnes correspondantes.

    Liens personnalisés

    • Questionnaire bouton : permet d’ajouter un bouton pour accéder au questionnaire.

    • Questionnaire simple : permet à l’utilisateur d’ouvrir directement le questionnaire via un lien.

    • Questionnaire image : permet d’ajouter une image cliquable donnant accès au questionnaire.

    • Questionnaire de secours : permet à l'utilisateur d’accéder au questionnaire lorsqu'il ne parvient pas à utiliser le bouton ou le lien principal.

    • Question intégrée : permet d'insérer une question dans le corps du message à envoyer.

    • Voir la version en ligne : permet d'accéder à la version en ligne de l'e-mail si l'utilisateur ne parvient pas à afficher le contenu depuis sa messagerie.

    • Se désabonner : permet à l'utilisateur de se désabonner de vos envois.

    • Réseaux sociaux : permet d'insérer des icônes vers les réseaux sociaux de votre choix en associant l’URL correspondante dans les propriétés de chaque élément.

    Contenu

    • Texte : permet d'ajouter une zone de texte.

      REMARQUE : Il est possible de reformuler, d'améliorer la clarté, de corriger la grammaire ou d'enrichir votre contenu grâce à l'intelligence artificielle. Consultez plus d'informations sur la modification de texte par IA.

    • Bouton : permet d'ajouter un bouton donnant accès à un site web. Le bouton peut être personnalisé depuis le volet Propriétés de l’élément.

    • Image : permet d'insérer une image (depuis votre ordinateur ou depuis une URL).

    • Email de contact : permet d'afficher le texte "Merci de répondre à ..." (l'adresse e-mail associée au compte est insérée par défaut). Vous pouvez modifier ce texte.

      Ajoutez ce texte lorsque vous diffusez un emailing depuis une adresse en noreply.

    • RGPD : permet d'insérer une mention RGPD afin d'informer et de rassurer l'utilisateur sur la collecte et l'utilisation de ses données personnelles.

    Sélectionnez un élément pour accéder à ses propriétés dans le volet de droite. Vous pouvez modifier :

    • L'alignement de l’élément : à gauche, à droite, centré ou justifié.

    • La marge interne : permet d'ajuster la position de l’élément par rapport à l’élément parent.

      EXEMPLE : Le bouton "Non" dispose d'une marge interne de 25 px en haut et en bas tandis que le bouton "Oui" n'a aucune marge interne.
      La position de chaque bouton est donc différente à l'intérieur de la colonne.

    • Mise en forme (police de caractères, taille de police, couleur, largeur, couleur de fond, bordure, etc.).

  3. Cliquez sur le bouton Enregistrer pour sauvegarder vos modifications.

    Une fenêtre de vérification du message s'affiche si l'un des éléments n'est pas correctement paramétré. Consultez plus d'informations sur la vérification du message.

    REMARQUE : Pour réussir et optimiser vos campagnes d'emailing, nous vous conseillons d'appliquer les bonnes pratiques.

    Si nécessaire, testez votre message.
