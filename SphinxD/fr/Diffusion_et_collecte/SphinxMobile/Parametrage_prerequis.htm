Prérequis de l'application & paramétrage depuis Sphinx Declic

SphinxSurvey est une application mobile qui permet de collecter les données d'enquêtes, en mode déconnecté, à partir d'un Smartphone / tablette. Ci-dessous une image illustrant les étapes de la collecte des réponses.

Pré-requis

L’application a été conçue pour fonctionner sur les systèmes iOS et Android.

Elle s'installe gratuitement. Il suffit pour cela de la télécharger depuis votre appareil.

  • Depuis l'AppStore (nécessite une version supérieure à iOS 9).

  • Depuis le PlayStore (nécessite une version supérieure à Android 8.0.0).

    REMARQUE : Pour une utilisation optimale, nous vous recommandons de toujours effectuer les dernières mises à jour de votre appareil, du système d'exploitation (Android/IOS) et d'utiliser la dernière version de SphinxSurvey.

Autoriser l'utilisation de SphinxSurvey pour une enquête

  1. Depuis la partie Diffusion, cliquez sur Application mobile, onglet Paramétrage.

  2. Cochez l'option Autoriser l'utilisation de SphinxSurvey pour cette enquête.

    L'enquête sera ensuite téléchargeable via les appareils mobiles (dans la limite des autorisations de téléchargement).

  3. Définissez un mot de passe (permettant de télécharger l'enquête depuis l'application).

  4. (Optionnel) Paramétrez le reste des options si besoin.

    Permettre la modification des réponses et la visualisation des résultats

    En activant cette option, l'enquêteur pourra accéder aux réponses et les modifier si besoin depuis l'appareil utilisé.

    Consulter cette page plus d'informations sur la modification des réponses depuis SphinxSurvey.

    Optimisation de l'affichage des formulaires

    Cette option permet d'optimiser le rendu des formulaires pour la saisie sur appareil mobile : les cases à coches pour la saisie des questions (questions simples et tableaux) seront plus élargies. Ceci permet de saisir plus facilement sur un écran tactile.

    REMARQUE : Attention cependant, dans ce mode, le rendu du questionnaire n’est pas tout à fait identique au rendu paramétré sur le logiciel. Cette option est cochée par défaut.

    Définir une image d'accueil personnalisée pour le libre-service

    Il est possible de définir une image d'accueil personnalisée pour le mode libre service. Pour ce faire :

    1. Cochez l'option Définir une image d'accueil personnalisée pour le libre service.

    2. Glissez-déposez une image ou cliquez sur le rectangle.

    3. Sélectionnez une image depuis votre ordinateur.

      Pour supprimer l'image ajoutée, passez le curseur de votre souris dessus puis cliquez sur l'icône de suppression.

    Activer la synchronisation automatique des réponses

    Cette option vous permet de synchroniser automatiquement les réponses collectées à une heure fixe.

    REMARQUE : L'appareil doit avoir accès à internet au moment de la synchronisation.

    Pour ce faire :

    1. Cochez la case Activer la synchronisation automatique.

    2. Définissez l'heure de synchronisation depuis le menu déroulant.

    3. (Facultatif) Cochez la case Activer les notifications en cas d'échec si vous souhaitez être notifié par e-mail (adresse à modifier si besoin) lorsque la synchronisation des réponses échoue depuis un ou plusieurs appareils.

      Il est possible d'ignorer les notifications pour certains appareils en indiquant leur ID dans la zone de saisie prévue à cet effet (IDs à séparer par un ";" si plusieurs appareils).

      L'ID d'un appareil est visible depuis la partie Historique synchro.

  5. Cliquez sur Enregistrer pour valider.
