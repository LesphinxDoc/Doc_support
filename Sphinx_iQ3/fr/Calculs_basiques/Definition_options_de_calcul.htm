DÉFINITION ET OPTIONS DE CALCUL

Définition de variables

Une variable peut être appelée par son nom ou par son numéro précédé de la lettre « V ». Exemple : « sécurité » ou « V1 »

Une variable dont le nom contient un espace doit être écrite entre crochets.

Exemple [tenue de route]

Dans une variable fermée, les modalités sont référencées par des index : la première modalité correspond à l’index 1, la seconde à l’index 2…

Définition d’une liste de variables 

Une liste de variables doit être écrite entre guillemets. Les variables qu’elle contient peuvent être séparées par « ; » ou par « - » :

V1 ; V3 (ne prend en compte que les variables 1 et 3)
V1-V10 (prend en compte les variables de 1 à 10)

Syntaxe et traitement des nombres

Un nombre est un chiffre entier ou décimal. Il provient d’une saisie ou d’un calcul effectué sur des variables.

Les calculs faits sur les nombres décimaux ne se basent pas sur des arrondis mais prennent en compte tous les chiffres après la virgule. Toutefois, les résultats restitués se limitent à deux chiffres après la virgule par défaut ; l’utilisateur peut changer ce paramètre dans le dialogue de définition de la variable (étape rédiger mon questionnaire par exemple) s’il le souhaite.

Syntaxe et traitement des dates

Une date peut être exprimée sous forme d’une chaîne de caractères de type "24/03/2014 14:52:59" ou #24/03/2014#. Les délimiteurs " et # sont valides.

Elle peut aussi correspondre à la valeur retournée par une variable de type Date ou à toute fonction ou expression complexe retournant une date. Par exemple, la date courante retournée par la fonction Maintenant().

Syntaxe et traitement des textes

Un texte peut être exprimé sous forme d’une chaîne de caractères de type "Quelle belle journée !".

Elle peut aussi correspondre à la valeur retournée par une variable de type Texte ou à toute fonction ou expression complexe retournant une chaîne. Par exemple, la chaîne retournée par la fonction Droite().

Options de calcul

Les options de calcul permettent de préciser les 3 éléments suivants :

  • Le traitement souhaité des non-réponses (ignorées ou remplacées).

  • Le traitement souhaité des variables échelles (numérique si l’on veut les utiliser dans des fonctions de calcul ou fermé).

  • La possibilité de générer de nouvelles modalités lors de la création des questions fermées.

Traitement des non-réponses

Lorsqu’un calcul contient des variables dont la valeur est Non-réponse, il est possible de :

  • Ne pas effectuer le calcul pour l’observation et conserver le résultat existant (issu d’un précédent calcul).

  • Mettre le résultat du calcul à Non-Réponse pour l’observation.

  • Effectuer le calcul en remplaçant la non-réponse par :

    1. La valeur 0 (si variables numériques) ou chaîne vide (autres types de variables).

    2. La moyenne (si variables numériques) ou la chaîne la plus citée (autres types de variables).

      Le remplacement des non-réponses ne s’opère pas :

      • Dans les fonctions mathématiques impliquant une liste de variable, par exemple moyenne("variable1 ;variable2").

      • Dans les propriétés qui font des calculs sur l'ensemble des observations, par exemple variable.moyenne.

      • Dans les tests de comparaison impliquant des variables, par exemple variable1 < 5.

      • Dans les fonctions date et heure.

Cependant, l’affichage des résultats tient compte des options de remplacement de non-réponses choisies. Concrètement, une moyenne de deux non-réponses est une non-réponse. Si l’on choisit l’option :

  • « Ne pas effectuer le calcul pour l’observation », le résultat restitué sera une non-réponse.

  • « Effectuer le calcul en remplaçant la non-réponse par 0 », le résultat restitué sera 0.

De même, les calculs faits à partir des résultats tiennent compte des options de remplacement des non-réponses. Par exemple, le calcul « 10+moyenne de deux non-réponses » donne :

  • Non-réponse si l’option « Ne pas effectuer le calcul pour l’observation » est retenue.

  • 10 si l’option « Effectuer le calcul en remplaçant la non-réponse par 0 » est retenue.
