FONCTIONS DE DATE ET D'HEURE

Age : calcul de la durée écoulée entre deux dates

Description :

Renvoie, pour chaque observation, la durée écoulée entre deux dates. Celle-ci est exprimée dans l’unité souhaitée (mois, jour ou année si l’unité n’est pas précisée).

Syntaxe :

Age(variable date1, "unité")
Age(variable date1, variable date2, "unité")
L’unité est optionnelle. Si elle n’est pas définie, le résultat est exprimé en années.
La syntaxe des unités est la suivante :
"aa" ou "yy" : nombre entier d’années
"aa.a" ou "yy.y" : nombre décimal d’années
"mm" : nombre entier de mois
"mm.m" : nombre décimal de mois
"jj" ou "dd" : nombre entier de jours
"jj.j" ou "dd.d" : nombre décimal de jours

EXEMPLE :
Pour obtenir l’âge calculé entre la date d’aujourd’hui et la variable naissance, écrire :
Age (naissance)
Pour obtenir le résultat précédent en années, écrire :
Age (naissance, "aa")
Pour obtenir l’ancienneté du collaborateur, écrire :
Age ([date embauche], [date départ])

Variables autorisées et valeurs prises en compte :

Cette fonction s’applique sur des variables dates.

AjouterAnnées : Ajoute des années aux valeurs d'une variable / à une date spécifique

Description :

Renvoie, pour chaque observation, la date augmentée du nombre d'années spécifiées en paramètre.

Syntaxe :

AjouterAnnée(date, nombre)

EXEMPLE :
Pour ajouter 2 ans aux valeurs de la variable naissance, écrire :
AjouterAnnées(naissance,2)
Pour ajouter 2 ans à une date spécifique, écrire :
AjouterAnnées("12/04/2022",2)

Variables autorisées et valeurs prises en compte :

Cette fonction s’applique sur des variables dates.

Maintenant : calcul de la date du jour

Description :

Renvoie la date et l’heure courantes.

Le résultat de cette expression change à chaque exécution du calcul.

Syntaxe :

Maintenant()
Maintenant
Now
Now()

EXEMPLE :
Pour obtenir la date du jour et l’heure à laquelle le calcul a été demandé, écrire :
maintenant()
maintenant("ss") pour obtenir les secondes
maintenant("s") pour obtenir la date heure : 2023-11-24T15:24:52
maintenant("mm") pour obtenir les minutes
maintenant("hh") pour obtenir les heures
maintenant("d") pour obtenir le jour : 24/11/2023
maintenant("D") pour obtenir le jour : vendredi 24 novembre
maintenant("m") ou maintenant("M") pour obtenir le mois : 24 novembre
maintenant("y") ou maintenant("Y") pour obtenir l'année : novembre 2023

Semaine : renvoie le numéro de la semaine d’une variable date

Description :

Renvoie, pour chaque observation, la semaine de la variable indiquée. Celle-ci est exprimée sous forme de nombre compris entre 1 et 53.

La règle retenue pour déterminer la 1re semaine de l’année correspond à la langue de l’enquête : une enquête en langue de référence française considère que la première semaine commence le premier jour de l’année.

Syntaxe :

Semaine(date)
Week(date)

EXEMPLE :
Pour obtenir le numéro de la semaine de la variable date portant le numéro 1, écrire :
Semaine (date) ou Semaine (V1)
Pour obtenir le numéro de la semaine en cours, écrire :
