FONCTION DE CALCUL

EcartType : calcul de l’écart-type de plusieurs variables

Description :

Renvoie, pour chaque observation, l’écart-type entre les variables indiquées sans tenir compte des non-réponses.

Syntaxe :

EcartType("Liste de variables")
StDev("List of variables")

EXEMPLE :
Pour obtenir l’écart-type des variables « sécurité », « tenue de route », écrire :
EcartType ("sécurité ; [tenue de route]")
Pour obtenir l’écart-type des variables 1, 2, 4, 5, 6, 20, écrire :
EcartType ("V1 ; V2 ; V4-V6 ; V20")

Variables autorisées et valeurs prises en compte :

Type de variable

Valeur prise en compte

Numérique

Valeur de l’observation

Fermée échelle

Si la variable contient un barème alors la valeur prise en compte est le barème associé à la modalité répondue sinon la valeur est l’index de la modalité.

Fermée unique

Idem que la question fermée échelle

Fermée multiple

La valeur prise en compte est la somme des barèmes associés aux modalités répondues si un barème est défini, sinon la valeur est la somme des index des modalités répondues.

À noter : pour les variables fermées, les modalités pour lesquelles le barème n’a été défini ne comptent pas dans les calculs.

NombreObservations : calcul du nombre d’observations de l’enquête ou d’un profil

Description :

Renvoie le nombre d’observations de l’enquête, ou d’un profil déterminé. Lorsque cette fonction est utilisée dans un tableau de bord, elle renvoie le nombre d’observations de la strate active.

Syntaxe :

NombreObservations
NombreObservations ("profil")
NumberOfObservations
NumberOfObservations ("profil")

EXEMPLE :
Pour obtenir le nombre d’observations de l’enquête (l’échantillon total), écrire :
NombreObservations
Pour obtenir le nombre d’observations correspondant à « BMW », la 1ère modalité de la variable Marque, écrire :
NombreObservations("Marque parmi \"BMW\"") ou NombreObservations("v1 parmi \"1\"")
Pour obtenir le nombre d’observations correspondant au profil « note <10 », écrire :
NombreObservations("note < 10")

TableExterne : Récupération d’une valeur dans un fichier de codes

Description :

Renvoie, pour chaque observation, la valeur de ‘Colonne‘ pour la ligne correspondant à la valeur de ‘variable’.

Syntaxe :

TableExterne(table, variable clé, colonne clé)
ExternTable(file, value, columns)

EXEMPLE :
Pour obtenir le nom du pays correspondant à la marque de voiture enregistrée dans la variable Marque, écrire :
Tableexterne("pays.txt",marque,"pays")

Sachant que le fichier texte est organisé ainsi :

REMARQUE : Ce fichier doit être enregistré avec l’extension « .txt » ou « .csv » et placé dans le répertoire de l’enquête ou dans le sous-répertoire multimédia de l’enquête.

Calcul de « TableExterne » pour une variable.
