FONCTIONS DE TEXTE

Avec : Vérification de la présence d’une liste de mots dans un texte

Description :

Vérifie la présence d’une liste de mots ou de parties de mots dans la chaîne indiquée.

Syntaxe :

Texte avec "mot1 ; mot2 ; mot3"

EXEMPLE :
Pour vérifier la présence des mots « rouge », « rougeâtre », « bleu » dans la variable V1, écrire :
V1 Avec "rouge ; bleu"

La formule renvoie la valeur 1 si l’un des mots (ou parties de mots) est présent dans le texte et la valeur 0 dans le cas inverse.

AvecListe : Vérification de la présence d’un mot dans un texte

Description :

Vérifie, pour chaque observation de la variable texte, la présence d’un mot ou d’une série de mots.

Syntaxe :

AvecListe(texte, "liste de mots", ignore)
WithList(text, "list of words", ignore)
Ignore est optionnel. Il prend deux valeurs :
Vrai pour ignorer la casse et les accents.
Faux pour prendre en compte la casse et les accents (valeur par défaut).

EXEMPLE :
AvecListe (DescriptionVoiture, "rouge ; bleu") renvoie la valeur « 1 » si l’observation contient les mots « rouge » ou « bleu », sinon la valeur « 0 ».
AvecListe (DescriptionVoiture, "mercedes", vrai) renvoie la valeur « 1 » si l’observation contient les mots « MERCEDES » ou « mercedès », sinon la valeur « 0 ».

FormatDurée : Calcul un intervalle de temps

Description :

Retourne une chaîne qui représente un intervalle de temps en tenant compte de l'unité utilisée et du format à appliquer.

Le paramètre 'unité' est optionnel. Ses valeurs possibles sont "d" ou "j" pour les jours, "H" ou "h" pour les heures, "m" pour les minutes, "s" pour les secondes.

Le paramètre 'format' est optionnel. Par défaut, le nombre est converti en une chaîne compacte, dans laquelle les valeurs vides sont ignorées.

La syntaxe du format personnalisé est celle du langage de programmation C#.

Syntaxe :

FormatDurée(nombre, [unité], [format])

EXEMPLE :
FormatDurée(456.2341) => "456j5h37m6s"
FormatDurée(456.2341, "h") => "19j14m2s"
FormatDurée(457.2341, "s") => "7m37s"
FormatDurée(458.5,"h","dd\ \j\o\u\r\s\ hh\ \h\e\u\r\e\s") => "19 jours 02 heures"

Parmi : Vérification de la présence d’une expression ou d’une liste d’expressions dans un texte
