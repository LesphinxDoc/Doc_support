STRUCTURES DE CONTRÔLE

Faire

Description :

Répète un groupe d’instructions tant que les conditions d’exécution sont vérifiées.

Syntaxe :

Faire

           <instructions>

Boucle TantQue <condition>

Répété tant que la condition est vraie.

Do

          < instructions >

Loop While < condition >

Répété tant que la condition est vraie.

EXEMPLE :
Pour calculer le nombre d'occurrences d'un caractère « p » ou d'un mot dans V1 :
TexteApres = V1
Caractere = "p"
NombreDeFois = 0
indice = 1
ResultatSouhaite = 3
Faire TantQue indice <> 0
    indice = DansChaîne(TexteApres,Caractere)
    Si indice > 0 Alors
        NombreDeFois = NombreDeFois + 1
        TexteApres = SousChaîne(TexteApres,indice)
    FinSi
Boucle
Selon Cas ResultatSouhaite
Cas 1
    V = NombreDeFois
Cas 2
    V = TexteApres
Cas 3
    V = NumChaîne(NombreDeFois) & "  :  " & TexteApres
FinSelon

Selon cas

Description :

Exécute un groupe d’instructions si les conditions d’exécution sont vérifiées.

Syntaxe :

Selon Cas <expression>

 

Cas 
       <instructions1>

Répété zéro ou plusieurs fois.

CasSinon
       <instructions2>

Répété zéro ou une fois.

FinSelon

 

Select Case <expression>

 

Case 
       <instructions1>

Répété zéro ou plusieurs fois.

CaseElse
       <instructions2>

Répété zéro ou une fois.

EndSelect

 

 

Exemple

Commentaires

Selon Cas [Note]

    Cas 20

    V = "Excellent"

    CasSinon

    V = "A étudier"

FinSelon

Une variable est créée en fonction de la valeur de Note.

Si Note de l’observation est à 20 alors la variable prend la valeur « Excellent », sinon elle prend la valeur « A étudier ».

ref = 20

Selon Cas ref

    Cas [note]

    V = "Excellent"

    CasSinon

    V = "A étudier"

FinSelon

Une variable est créée.

ref est la valeur de référence. Elle est de 20 dans l’exemple.

L’instruction est exécutée par observation : si la note de l’observation est à 20 alors la variable calculée prend la valeur « Excellent », sinon elle prend la valeur « A étudier ».

Selon Cas [Note]

    Cas 20

    Cas 19

    V = "Excellent"

    Cas 18

    Cas 17

    V = "Bien"

    CasSinon

    V = "A étudier"

FinSelon

Dans ce cas, si la note de l’observation est à 19 ou 20 alors la variable calculée prend la valeur « Excellent », si la note est à 17 ou 18 alors la variable prend la valeur « Bien » sinon, c’est la valeur « A étudier ».

ref = "MERCEDES"

Selon Cas ref

    Cas [Marque]

    V="OK"

FinSelon

La valeur de référence est MERCEDES.

L’instruction vérifie par observation si la variable maque est Mercédès (sans tenir de la casse et des accents). Dans ce cas, la variable créée prend la valeur "OK".

Tantque

Description :

Répète un groupe d’instructions tant que les conditions d’exécution sont vérifiées.

Syntaxe :

Faire TantQue <condition>

           <instructions>

Boucle

Répété tant que la condition est vraie.

Do While <condition>

           <instructions>

Loop

Répété tant que la condition est vraie.

 

Exemple

Commentaires

T(1) = V1.Nombre

N(1) = V1.Libellé

T(2) = V2.Nombre

N(2) = V2.Libellé

T(3) = V3.Nombre

N(3) = V3.Libellé

T(4) = V4.Nombre

N(4) = V4.Libellé

T(5) = V5.Nombre

N(5) = v5.Libellé

permut = Vrai

Faire TantQue permut = Vrai

    permut = Faux

    Pour cpt = 1 à 4

        Si T(cpt) < T(cpt + 1) Alors

            permut = Vrai

            tmp = T(cpt)

            T(cpt) = T(cpt + 1)

            T(cpt + 1) = tmp

            tmpch = N(cpt)

            N(cpt) = N(cpt + 1)

            N(cpt + 1) = tmpch

        FinSi

    Suivant cpt

Boucle

V = N(1) & ";" & N(2) & ";" & N(3) & ";" & N(4) & ";" & N(5)

Les variables de 1 à 5 évaluent 5 critères sur une échelle de 5 niveaux (pas du tout d’accord, pas d’accord, moyennement d’accord, d’accord, tout à fait d’accord).

 

L’objectif de cette boucle est de calculer le niveau d’importance de chaque critère à partir des réponses aux échelles.

 

A l’issue de la boucle, une variable fermée à plusieurs réponses est créée. Les modalités de cette variable sont enregistrées dans l’ordre d’importance des critères pour chaque observation.

 

Exemple :

V1 correspond à sécurité, V2 à vitesse ; V3 à esthétique ; V4 à confort et V5 à espace.

 

Le résultat de cette boucle sera :

Observation1 : sécurité ; esthétique ; espace ; vitesse ; confort

Observation2 : vitesse ; confort ; espace ; sécurité ; esthétique
