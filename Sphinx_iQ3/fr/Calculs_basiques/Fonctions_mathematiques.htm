Abs : Calcul de la valeur absolue d’une variable

Description :

Renvoie, pour chaque observation, la valeur absolue de la variable indiquée.

Syntaxe :

Abs(nombre)

EXEMPLE :
Pour obtenir la valeur absolue de la variable « note » portant le numéro 1, écrire :
Abs (note) ou Abs (V1)

Valeur de l’observation

Fermée échelle

ValAleatoire : calcul d’un nombre aléatoire

Description :

Renvoie, pour chaque observation, un nombre aléatoire.

Syntaxe :

ValAleatoire()
Rnd()
ValAleatoire(inf, sup)
Rnd(inf, sup)

EXEMPLE :
Pour obtenir un nombre aléatoire situé dans l’intervalle ]0,1[, écrire :
ValAleatoire()
Pour obtenir un nombre aléatoire entier situé dans l’intervalle [1,10], écrire : 
ValAleatoire(1,10)

ATTENTION : La valeur aléatoire se recalculera automatiquement lors de l'enregistrement de la réponse ou lorsqu'elle est utilisée ailleurs (sur une autre page) dans le calcul d'une autre variable etc...
Pour bloquer le calcul de la valeur aléatoire,   il suffit d'indiquer dans la formule que le calcul ne doit être effectué que si cette variable est non-réponse.
Exemple :
Si V1.estnonreponse alors
V= ValAleatoire(1,10)
Finsi

Cas d’utilisation :

  • Test des protocoles de collecte de données : nous souhaitons comparer la qualité des réponses collectées avec deux formulaires différents : le premier comprend des images et le second des vidéos à titre d’exemple. Nous adressons au hasard l’un des deux formulaires aux répondants en utilisant la fonction ValAleatoire. Nous comparons ensuite les résultats des deux sous-échantillons.

  • Evaluation d’une série de produits : pour collecter l’avis des répondants sur trois produits différents, nous produisons un formulaire de trois pages, dont chacune reprend l’image du produit et les questions qui s’y rapportent. Pour neutraliser l’effet d’ancrage dû à l’ordre de présentation, les pages sont renvoyées dans un ordre aléatoire.

EXEMPLE :

Description :

Renvoie la multiplication de ‘nombre1’ par ‘nombre2’.

Syntaxe :

Nombre1 * Nombre2

EXEMPLE :
Pour obtenir le produit des variables BudgetRestaurant et NombrePersonnes, écrire :
