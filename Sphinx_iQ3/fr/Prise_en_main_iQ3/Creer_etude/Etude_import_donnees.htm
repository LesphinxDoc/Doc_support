CRÉER UNE ÉTUDE PAR IMPORT DE DONNÉES

Fichiers tabulés (.xlsx, .csv, .txt)

Pour importer une table de données au format .xlsx ou .csv / .txt, procédez comme suit :

  1. À partir de l’écran d’accueil, cliquez sur Créer une étude.

  2. Cliquez sur Fichiers tabulés.

    REMARQUE : Assurez-vous que le contenu de votre fichier est bien au format brut (c'est-à-dire sans mise en forme des cellules) pour éviter d'éventuels problèmes d'importation.

  3. Sélectionnez le fichier à importer.

    REMARQUE : Dans le cas d'un fichier Excel, vous devez également sélectionner la feuille à utiliser.

  4. Cliquez sur Suivant.

  5. Procédez à la configuration des paramètres d'import ;

    • Définir le nombre de lignes à ignorer au début et à la fin.

    • Indiquer que la 1 ère ligne contient les noms des variables.

    • Indiquer que la 2 ème ligne contient le libellé des variables.

    • Définir les lignes vides à ignorer (au début, à l'intérieur ou à la fin).

    • Définir les caractères à utiliser pour remplacer les non-réponses.

    • Définir le séparateur à utiliser pour identifier les questions multiples (par défaut c'est le point-virgule).

  6. Cliquez sur Suivant.

  7. (Facultatif) Modifiez le type et le nom des variables si nécessaire.

  8. Cliquez sur Suivant.

  9. En cas d’éventuelles erreurs ou incohérences détectées, identifiez-les afin de les corriger soit en modifiant directement votre fichier ou :

    En sélectionnant l'option Rectifier automatiquement les données.

    En sélectionnant l'option Mettre les données en-non réponse.

  10. Cliquez sur Terminer pour finaliser l'opération d'import de données.

Étude statistique (SPSS, Triple-S)

Pour importer des données d'une étude SPSS ou Triple-S, procédez comme suit :

  1. À partir de l’écran d’accueil, cliquez sur Créer une étude.

  2. Cliquez sur Étude statistique.

  3. Cliquez sur Parcourir pour sélectionner le fichier à importer.

  4. Cliquez sur Suivant.

  5. Cliquez sur Terminer pour valider l'import.

Données web (recherche sur Google, Google Scholar)

Pour importer des données issue d'une recherche sur le moteur de recherche Google/ Google Scholar, procédez comme suit :

  1. À partir de l’écran d’accueil, cliquez sur Créer une étude.

  2. Cliquez sur Données web et réseaux sociaux.

  3. Indiquez le sujet sur lequel portera votre recherche dans le champ Sujet.

  4. Cochez les moteurs de recherche à utiliser : Google et Google Scholar.

  5. Définissez le nombres de réponses maximum par source interrogée et par langue,

    pour Google Scholar, il est possible de définir des paramètres pour affiner la recherche:

    • Réponses contenant (tous les mots, l'expression exacte, au moins un des mots, aucun des mots).

    • Uniquement les réponses publiées avant, après ou entre X dates.

    • Télécharger les contenus des documents.

  6. Sélectionnez les langues à utiliser.

  7. Cliquez sur Suivant.

  8. Cliquez sur Terminer pour valider l'import.
