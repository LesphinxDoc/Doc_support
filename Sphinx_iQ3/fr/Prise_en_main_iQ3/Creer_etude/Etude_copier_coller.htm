CRÉER UNE ÉTUDE PAR copier-coller DE QUESTIONS

Cette fonctionnalité permet de créer une nouvelle étude en copiant et collant des questions au format texte.

Pour ce faire :

  1. Cliquez sur le bouton Créer une étude depuis l'écran d'accueil.

  2. Cliquez sur Créer une étude par copier/coller de questions.

    Format attendu des questions :

    • Collez chaque libellé de question sur une ligne.

      Les questions comportant uniquement un libellé seront considérées comme des questions ouvertes, sauf si leur type est spécifié dans le nom de la variable (voir le point sur le type de variable).

    • Ajoutez les modalités en dessous du libellé en les séparant par un retour à la ligne.

    • Séparez chaque question (avec ou sans modalités) par une ligne vide en appuyant deux fois sur la touche Entrée.

    Options supplémentaires :

    • Ajoutez un * au début d'un libellé pour rendre la réponse obligatoire.

      Copier
      EXEMPLE
      1
2
3
*Avez-vous une voiture à votre disposition ?
      Oui
      Non

    • Définissez un nom de variable en l’écrivant sous le libellé de la question, au format [NomVariable].

      Les espaces dans le nom de la variable seront transformés en underscore _.

      EXEMPLE : [Note satisfaction] deviendra Note_satisfaction.

    • Spécifiez le type de variable en ajoutant "$num" (pour une variable numérique) ou "$date" (pour une variable de type date) à la fin de son nom.

Quel est votre age ?
      [Age$num]

      Quelle est la date de votre arrivée?
      [Arrivee$date]

    • Ajoutez une consigne en l'encadrant avec ** **.

      Exemple de consigne : **Plusieurs réponses sont possibles**.

  3. Importez les questions en les collant dans la zone prévue à cet effet.

  4. Cliquez sur Suivant puis donnez un titre à l'étude, définissez la ou les langues de l'étude, etc.

  5. Cliquez sur Terminer pour valider.

Après la création de l’étude, concevoir et paramétrer le questionnaire. Plus de détails dans la section Questionnaire.

Importer des questions par copier/coller dans une enquête

Il est possible d'importer des questions par copier/coller dans une enquête existante à tout moment.

  1. Depuis l'environnement de Conception du questionnaire, cliquez sur l'onglet Insertion.

  2. Cliquez sur Copier-coller de questions.

  3. Copiez-collez les questions dans la zone prévue à cet effet.

  4. Cliquez sur Terminer pour valider.
