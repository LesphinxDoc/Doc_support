CRÉER UNE ÉTUDE à PARTIR DE QUESTIONS générées PAR L'IA

Cette fonctionnalité permet de générer automatiquement un questionnaire grâce à l'intelligence artificielle.

Étapes à suivre :

  1. (Obligatoire) Connectez-vous au compte SphinxOnline depuis Sphinx iQ3.

    Procédure pour se connecter au compte SphinxOnline depuis Sphinx iQ3 :

    1. Ouvrez le logiciel Sphinx iQ3.

    2. Cliquez sur Connexion en haut à droit de l'écran.

    3. Sélectionnez l'URL de connexion depuis le menu déroulant Adresse URL de connexion.

      Si l'adresse URL du serveur n'est pas présente dans la liste :

      1. Cliquez sur le bouton +.

      2. Sélectionnez Autre serveur depuis le menu déroulant URL d'accès au compte.

      3. Insérez l'adresse URL de votre serveur.

      4. Cliquez sur Enregistrer pour valider.

    4. Cliquez sur Suivant.

      La page de connexion s'affichera dans votre navigateur.

    5. Saisissez l'identifiant et le mot de passe du compte, puis cliquer sur Se connecter.

    6. Dans la fenêtre qui s'affiche, cliquez sur Ouvrir Sphinx iQ3.

      REMARQUE : Cochez l'option "Toujours Autoriser [URL du serveur] à ouvrir les liens de ce type dans l'application associée" pour éviter l'affichage de cette fenêtre lors des prochaines connexions.

      Une fois connecté, le nom du compte apparaît en haut à droite de l'écran.

      En cliquant dessus, il est possible de :

      • Ouvrir le compte en ligne dans le navigateur.

      • Changer de compte (si le compte personnel est lié à un ou plusieurs comptes collaboratifs).

      • Se déconnecter.

  2. Cliquez sur le bouton Créer une étude depuis l'écran d'accueil.

  3. Cliquez sur Générer un questionnaire par IA.

    Première utilisation ? Accepter les conditions d'utilisation de l'IA

    L’acceptation des conditions générales spécifiques aux assistants IA est requise.

    1. Lisez attentivement les conditions générales spécifiques aux assistants IA.

    2. Cochez la case suivante :

      • "Je reconnais avoir accepté sans réserve l'addendum "Assistant IA" affiché ci-dessus et je déclare être le représentant légal du titulaire de ce compte ou avoir le pouvoir de le représenter valablement et être conscient d'engager ma responsabilité en cas de déclaration mensongère"

    3. Cliquez sur le bouton J'accepte.

  4. Décrivez le questionnaire souhaité.

    Fournissez un maximum d'informations pour optimiser la génération du questionnaire.

    REMARQUE : La description est limitée à 1000 caractères.

    Des suggestions de prompt (description de questionnaire) sont disponibles (ex. Satisfaction service, Notoriété image, Climat interne, etc.) : choisir un thème et ajuster la description si nécessaire.

  5. Cliquez sur Suivant pour lancer la génération.

  6. Modifiez le questionnaire si besoin :

    Ajustez le format des questions (ex. rendre une question obligatoire, ajouter une consigne etc.). Pour plus d'informations, consulter la section Format attendu des questions.

    ATTENTION : Revenir en arrière (en cliquant sur Précédent) et relancer une nouvelle génération supprimera le questionnaire précédent et entraînera une consommation supplémentaire de tokens.

  7. Cliquez sur Suivant puis définir un titre à l'étude, définir la/les langue(s) de l'étude, etc...,

  8. Cliquez sur Terminer pour valider.
