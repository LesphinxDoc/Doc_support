Ajouter un nouvel élément (Analyse, filtre, texte, image)

Lorsque vous survolez avec le curseur sur le bouton situé à droite, à côté des boîtes de dialogue, 9 options d’analyses apparaissent.

ANALYSES ET FILTRE

  • L’analyse à plat permet de réaliser un tri à plat, avec une seule variable.

  • L’analyse croisée/ multiple permet de réaliser un tri croisé ou une analyse multivariée, avec au moins deux variables à analyser simultanément.

  • Les analyses avancées permettent de réaliser une analyse de satisfaction, un KeyViews, analyse de données, classification et représentation sur carte géographique.

  • Le tableau personnalisé permet de créer des analyses avancées où vous pouvez définir des profils qui viendront agir sur les variables à afficher dans vos lignes et colonnes.

  • L'analyse textuelle et sémantique permet d'explorer vos données textuelles à travers l'affichage de verbatim, nuage de mots-clés, influences et spécificités par contexte, analyses lexicales automatiques ou encore à travers une analyse thématique.

  • Le filtre de vue permet d’ajouter un filtre, qui sera effectif sur toutes les pages de la vue, pour n’étudier qu’une catégorie spécifique de répondants.

ZONE DE TEXTE

Le bouton texte permet de créer une zone texte qui peut être éditée en fonction de sa taille, de sa couleur ou de sa police.

Pour créer une zone de texte, procédez comme suit :

  1. Cliquez sur le bouton .

  2. Cliquez sur texte.

    REMARQUE : Vous pouvez directement ajouter une zone de texte en double cliquant sur l'endroit de la page où vous souhaitez la placer.

  3. Renseignez votre texte dans la zone.

  4. (Facultatif) Modifiez son apparence (couleur, couleur de fond, bordure).

  5. (Facultatif) Appliquez un style prédéfini (Titre 1, Titre 2, Titre 3, Normal, Citation).

  6. (Facultatif) Modifiez les proportions / changez l'orientation de la zone de texte en utilisant l'icône .

    Appliquer des options de filtrage à une zone de texte et définir le nombre de décimales à afficher

    Il est possible d'appliquer des options de filtrage à une zone de texte qui comporte une formule de calcul et également de définir le nombre de décimales à afficher.

    EXEMPLE : Dans une vue qui affiche les résultats de l'année 2022, nous souhaitons rappeler le chiffre d'affaire réalisé en 2021 via une formule de calcul insérée dans une zone de texte qui ne pas doit être filtré lors de l'utilisation des filtres de vue.

    Pour ce faire :

    1. Sélectionnez la zone de texte contenant la formule de calcul.

    2. Depuis l'onglet Avancé, partie Calcul, cliquez sur Options de filtrage.

    3. Sélectionnez l'option de filtrage à utiliser.

      Plus d'information sur les options de filtrage.

    4. Depuis la partie Format, définissez le nombre de décimales à afficher.

    Insérer un lien hypertexte dans une zone de texte

    Pour insérer un lien hypertexte dans votre zone de texte, procédez comme suit :

    1. Sélectionnez votre texte.

    2. Cliquez sur le bouton .

    3. Insérez par l'adresse web à utiliser.

      REMARQUE : Pour permettre de générer un envoi d'email vers une adresse lorsque une personne clique sur le lien, rajoutez le terme "mailto:" dans le champ Adresse Web.


    4. (Facultatif) Renseignez une info-bulle (qui affichera un texte lors du survol du lien).

    Affecter une action à une zone de texte

    Pour affecter une action à une zone de texte, procédez comme suit :

    1. Sélectionnez la zone de texte.

    2. Depuis l'onglet Scénario, choisissez une action :

      • Illustrer par une vue : permet d'afficher une vue dans un popup lorsqu'on clique sur le texte.

      • Filtrer des analyses : sélectionnez les analyses à filtrer puis définissez le filtre à utiliser.

        EXEMPLE : dans cet exemple, nous avons défini un filtre "sexe parmi homme" sur la zone de texte "Hommes" pour filtrer l'analyse ci-dessous.

      • Naviguer vers un lien externe : saisissez l'URL puis choisissez la cible (ouvrir dans un nouvel onglet ou dans l'onglet courant).

      • Naviguer vers une page : choisissez la page à afficher lorsqu'on clique sur la zone de texte.

      • Naviguer vers une vue : choisissez la vue à afficher lorsqu'on clique sur la zone de texte.

    Insérer un paramètre de l'étude dans une zone de texte

    Vous pouvez insérer un/des paramètre(s) de l'étude dans une zone de texte.

    EXEMPLE : Afficher automatiquement le numéro de la page et le nombre de pages.

    Pour ce faire :

    1. Double-cliquez sur la zone de texte.

    2. Cliquez sur le menu déroulant Légende auto.

    3. Sélectionnez le paramètre à utiliser.

IMAGE

Le bouton image permet d’illustrer une analyse en ajoutant dans une page des images ou des pictogrammes.

  • Les images peuvent être importées depuis l’ordinateur ou internet.

  • Les pictogrammes peuvent être affichés par catégorie depuis le menu catégorie ou en les cherchant directement depuis la barre de recherche.

Pour importer une image / un pictogramme, procédez comme suit :

  1. Cliquez sur le bouton .

  2. Cliquez sur Image.

  3. Sélectionnez l'image depuis la galerie ou cliquez sur l'onglet Ajouter une image pour importer une depuis votre ordinateur ou depuis internet.

  4. Cliquez sur OK pour valider.

  5. (Facultatif) Modifiez son style (couleur du pictogramme, ajouter un calque coloré pour les images).

  6. (Facultatif) Modifiez les proportions / changez l'orientation de l'image en utilisant l'icône .

Pour affecter une action à une image, procédez comme suit :

  1. Sélectionnez l'image.

  2. Depuis l'onglet Scénario, choisissez une action :

    • Illustrer par une vue : permet d'afficher une vue dans un popup lorsqu'on clique sur l'image.

    • Filtrer des analyses : sélectionnez les analyses à filtrer puis définissez le filtre à utiliser.

      EXEMPLE : dans cet exemple, nous avons défini un filtre "sexe parmi homme" sur le pictogramme en bleu afin de filtrer l'analyse ci-dessous.

    • Naviguer vers un lien externe : saisissez l'URL puis choisissez la cible (ouvrir dans un nouvel onglet ou dans l'onglet courant).

    • Naviguer vers une page : choisissez la page à afficher lorsqu'on clique sur l'image.

    • Naviguer vers une vue : choisissez la vue à afficher lorsqu'on clique sur l'image.

FORME GRAPHIQUE

Le bouton Forme graphique permet d'ajouter des formes graphiques pour mieux illustrer les analyses.

Pour ajouter une forme graphique, procédez comme suit :

  1. Cliquez sur le bouton .

  2. Cliquez sur Forme graphique.

  3. Choisissez la forme à utiliser.

  4. (Facultatif) Modifiez son style (couleur, bordure).

  5. (Facultatif) Modifiez les proportions / changez l'orientation de la forme en utilisant l'icône .

Pour affecter une action à une forme, procédez comme suit :

  1. Sélectionnez la forme.

  2. Depuis l'onglet Scénario, choisissez une action :

    • Illustrer par une vue : permet d'afficher une vue dans un popup lorsqu'on clique sur la forme.

    • Filtrer des analyses : sélectionnez les analyses à filtrer puis définissez le filtre à utiliser.

    • Naviguer vers un lien externe : saisissez l'URL puis choisissez la cible (ouvrir dans un nouvel onglet ou dans l'onglet courant).

    • Naviguer vers une page : choisissez la page à afficher lorsqu'on clique sur la forme.

    • Naviguer vers une vue : choisissez la vue à afficher lorsqu'on clique sur la forme.

AJOUTER DES ÉLÉMENTS AU MASQUE

Les zones de texte, images et formes graphique peuvent être rajoutés au masque afin de les afficher sur toutes les pages de votre vue.

Pour ce faire :

  1. Sélectionnez les éléments (image, zone de texte ou forme).

  2. Faites un clic droit puis cliquez sur Ajouter au masque.

REMARQUE : Une fois rajoutés au masque, les éléments ne sont éditables que depuis la première page de la vue.

Pour supprimer un objet de la zone de masque, procédez comme suit :

  1. Sélectionnez l’élément.

  2. Faites un clic droit dessus puis cliquez sur Retirer du masque.
