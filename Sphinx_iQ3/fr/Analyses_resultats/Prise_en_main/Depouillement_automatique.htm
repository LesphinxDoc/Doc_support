GÉNÉRER UN dépouillement AUTOMATIQUE

Générez un rapport automatique avec toutes les variables de votre étude sous forme de tri à plat ou de croisement avec une variable. Pour ce faire :

  1. Rendez vous dans la partie Analyse des résultats,

  2. Si vous avez déjà créé au moins une vue d'analyse, cliquez sur le bouton Créer une nouvelle vue. Sinon, passez directement à l'étape 3.

  3. Sélectionnez la carte Dépouillement à plat ou Dépouillement croisé.

  4. Donnez un nom à votre vue d'analyse.

  5. (Facultatif) Modifiez la police de référence et/ou le thème de couleurs de vos analyses renseignés par défaut pour les adapter à votre charte graphique.

    Personnaliser le thème de couleurs d'une vue d'analyse

    Vous pouvez choisir le type de palette de couleurs que vous souhaitez appliquer à vos analyses :

    • Une couleur, avec le choix d'appliquer un dégradé ;

    • Deux couleurs, avec le choix d'appliquer un dégradé ;

    • Un jeu de couleurs :

      • Une couleur existante peut être supprimée en se plaçant sur celle-ci et en cliquant sur l'icône poubelle qui apparaît en haut à droite.

      • Il est également possible d'ajouter autant de couleurs que vous le souhaitez en cliquant sur le + à droite des couleurs existantes.

      • Si vous définissez une palette de couleurs personnalisée, vous pouvez l'enregistrer pour la réutiliser en cliquant sur l'icône étoile.

    REMARQUE : Il existe des palettes de couleurs prédéfinies disponibles en cliquant sur l'icône palette à droite de la liste déroulante.

    Vous pouvez modifier les couleurs à tout moment en cliquant sur celles-ci puis en bougeant le curseur sur la palette ou en entrant un code Hexadécimal. Une fois modifiée, vous pouvez enregistrer une couleur dans vos couleurs favorites.

  6. Pour un dépouillement croisé, sélectionnez la variable qui servira de référence pour votre tri croisé dans la liste déroulante.

  7. Cliquez sur OK.

    Lors d'un dépouillement automatique des variables, les analyses s'afficheront sous forme de graphique.
