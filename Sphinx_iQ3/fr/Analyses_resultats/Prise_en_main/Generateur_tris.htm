Générateur de tris

Le Générateur de tris permet de créer un book de tris, une vue d'analyse optimisée pour l'export au format Excel de tableaux à plat ou croisés.

  1. Depuis section Analyse, cliquez sur Générateur de tris.

    Si vous avez déjà créé au moins une vue d'analyse, cliquez d'abord sur Créer une nouvelle vue.

  2. Saisissez un nom pour la vue d'analyse.

  3. (Facultatif) Modifiez la police de référence et le thème de couleurs afin de les adapter à votre charte graphique.

  4. (Facultatif) Sélectionnez une variable de redressement.

    REMARQUE : Lorsque vous sélectionnez une variable de redressement, les tableaux affichent les effectifs bruts, les effectifs redressés ainsi que les pourcentages redressés.

  5. Pour un tri croisé, sélectionnez la variable de référence dans la liste déroulante.

  6. Cliquez sur OK.

    La vue d'analyse est générée.

    REMARQUE : Vous pouvez modifier cette vue avant de l'exporter.

  7. Cliquez sur Exporter puis sélectionnez Document.

  8. Sélectionnez le format xlsx (Excel) puis configurez les options d'export si nécessaire (nom du fichier, pages à exporter, etc.).

    REMARQUE : Par défaut, toutes les pages sont regroupées dans un seul onglet. Pour créer un onglet par page, décochez l'option Regrouper toutes les pages dans un seul onglet.

    ATTENTION : Certains éléments ne sont pas exportés au format xlsx (Excel).

  9. Cliquez sur OK pour générer le fichier.
