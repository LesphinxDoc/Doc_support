Définir un redressement

Malgré tous les efforts déployés pour sélectionner les individus, lors des phases d’e-mailing par exemple, il se peut qu’un échantillon soit « biaisé », c'est-à-dire que sa composition ne soit pas satisfaisante, car elle ne correspond pas aux critères de représentativité que l’on avait préalablement définis.

EXEMPLE : Nous pensions atteindre 60% de femmes et 40% d’hommes et ce n’est en réalité pas le cas. Il faut alors « redresser » l’échantillon.

Pour ce faire :

  1. Accédez à l'onglet Calcul depuis les propriétés de la vue puis cliquez sur Définir un nouveau redressement.

  2. Cliquez sur le bouton Ajouter un critère pour sélectionner la variable sur laquelle on souhaite redresser l'échantillon.

  3. Indiquez par la suite le pourcentage que l'on aurait souhaité obtenir pour chaque modalité.

    EXEMPLE : Dans notre exemple, nous avons actuellement 41.23% des répondants qui sont des femmes hors nous avions pour objectif d'avoir 60% de femmes sondées. Le but étant de rendre l'échantillon représentatif de la population étudiée sur ce critère.

  4. Cliquez sur le bouton Suivant.

  5. Donnez un nom à votre variable.  

  6. Cliquez sur OK, une nouvelle variable de Redressement sera créée.

REMARQUE : Notez qu'il est possible d'ignorer le redressement sur certaines analyses. Pour ce faire, sélectionnez une analyse, puis cochez la case "Ignorer le redressement" depuis l'onglet Avancé.

REMARQUE : Vous avez la possibilité d'afficher les effectifs bruts lors de l'application d'un redressement sur votre vue. Pour ce faire, depuis les propriétés de la vue, onglet Calcul, cochez la case Toujours afficher les effectifs bruts (non redressés).
