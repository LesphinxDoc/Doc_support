Afficher le verbatim

En choisissant d’afficher le verbatim,  on obtient un nuage de mots contenant les éléments les plus significatifs de la variable textuelle. Les mots les plus cités seront au premier plan, tandis que les moins cités seront à l’arrière-plan.

EXEMPLE : Dans une enquête portant sur des lettres au Père Noël, on peut vouloir afficher le verbatim des messages laissés par les enfants en faisant une analyse filtrée sur les filles, puis une autre analyse en filtrant les garçons en définissant un profil. Ensuite, on peut réduire les données pour n’avoir que les messages spécifiques aux filles ou aux garçons. Ainsi on remarque que les éléments qui apparaissent le plus pour les filles sont « Poupée », « Barbie » ou « École » et « Voiture », « Jouet » ou « Playmobil » pour les garçons.

  

Pour afficher le verbatim, procédez comme suit :

  1. Glissez déposez votre variable texte.

    Un graphique (nuage de mots) et un tableau s'affichent.

  2. Si besoin, éditez les options du graphique/ tableau :

    • Pour le graphique :

      • Rotation des mots : permet la rotation des mots dans le nuage de mots pour un rendu plus joli.

      • Filtrer le tableau au clic : permet d'afficher les réponses contenant le mot sélectionné.

        REMARQUE : Cette option est uniquement disponible lorsque le tableau est affiché en complément du graphique Nuage de mots dans la même analyse.

    • Pour le tableau :

      • Sélectionner le type d'affichage : Grille ou Liste enrichie.

      • Afficher le Verbatim complet ou les Phrases.

      • Afficher des signatures : il est possible d’ajouter une ou plusieurs variables signatures dans le tableau des données textuelles.

        EXEMPLE : Vous pouvez joindre les variables concernant l’âge, le prénom ou la ville des répondants pour chaque ligne de données du tableau.

      • Afficher une évaluation : permet d'afficher une évaluation, par exemple la note de satisfaction donnée.

        REMARQUE : L’option Évaluation est disponible uniquement lorsque le tableau est présenté en mode Liste enrichie.

      • Colorier selon l'orientation : permet de colorier le texte selon l'orientation (vert pour une orientation positive, rouge pour une orientation négative et orange pour une orientation partagée.

      • Lignes par page : définissez le nombre de lignes à afficher par page dans votre tableau de verbatim (10, 20 ou 50 lignes).
