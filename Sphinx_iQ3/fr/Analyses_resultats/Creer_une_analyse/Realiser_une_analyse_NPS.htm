Réaliser une analyse NPS

Le NPS ou Net Promoter Score permet d’évaluer le niveau de recommandation des individus sur un produit ou une marque. Il mesure l’écart entre les promoteurs (ceux qui recommanderont le produit) et les détracteurs (ceux qui ne recommanderont pas le produit).

De manière générale, les promoteurs sont ceux qui ont attribué une note de 9 à 10, les détracteurs sont ceux qui ont donné une note de  0 à 6. Les passifs sont les restants, donc ceux qui ont mis une note de 7 à 8.

Pour réaliser une analyse NPS, procédez comme suit :

  1. Cliquez sur le bouton .

  2. Sélectionnez Analyse avancée.

  3. Cliquez sur Net Promoter Score depuis la partie analyse de satisfaction.

  4. Sélectionnez la variable échelle à évaluer depuis le menu déroulant Variable NPS.

  5. (Facultatif) Modifiez l'abréviation NPS.

  6. Réarrangez les modalités dans la catégorie correspondante (Détracteurs, Passifs et promoteurs).

    REMARQUE : Il est possible de renommer les catégories.

Une fois l’analyse NPS réalisée, il est possible de changer la variable et le choix des catégories en sélectionnant l’analyse et en cliquant sur ou en faisant clic droit éditer sur l’analyse.

OPTIONS ET ANALYSE DU NPS

Dans l’onglet option, catégorie graphique, vous pouvez choisir d’afficher trois types de valeur :

  • Le score NPS : calculé en soustrayant au pourcentage des promoteurs le pourcentage des détracteurs.

  • La moyenne ou la médiane : calculées à partir d’un barème automatiquement affecté à chaque modalité, en partant de 1 pour la première modalité d’insatisfaction jusqu’à n pour la dernière modalité de satisfaction. Le barème peut être modifié en sélectionnant choisir un barème.

  • Il est également possible d’afficher la tendance en dessous de l’analyse. Elle permet d’ajouter une courbe pour voir la tendance d’une série de données temporelle sur une période choisie. Vous pouvez sélectionner le type de graphique que vous souhaitez pour afficher la tendance, sur quelle variable de temps vous vous basez et pour quelle période de temps.

Plus le NPS est du côté négatif plus il y a de détracteurs et plus le NPS est du côté positif, plus il y a de promoteurs pour le produit. Un score NPS est considéré comme bon lorsqu’il est supérieur ou égal à zéro.
