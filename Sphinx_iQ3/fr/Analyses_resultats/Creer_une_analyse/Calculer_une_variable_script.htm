Calculer une variable par script

Cette fonctionnalité permet de calculer une nouvelle variable en écrivant une formule de calcul (moyenne, écart-type, etc.) à partir d'une ou de plusieurs autres variables.

Pour accéder à cette fonctionnalité, rendez-vous dans la section Analyse puis lorsque vous êtes dans une vue d'analyse, cliquez sur le bouton Calculer une variable... en dessous de la liste des variables.

Ensuite, procédez comme suit :

  1. Sélectionnez l'option Calculer une variable par script.

  2. Rédigez votre formule de calcul dans l'encadré prévu à cet effet en choisissant la fonction de calcul ainsi que les variables à utiliser.

    Quelques astuces :

    • Vous pouvez double-cliquer sur une variable présente dans la liste des variables sur la droite pour l'ajouter dans votre formule de calcul.

    • Une variable peut être appelée par son nom ou par son numéro précédé de la lettre V, par exemple : "securite" ou "V1".

    • Une variable dont le nom contient un espace doit être écrite entre crochets.

    REMARQUE : Pour vous aider dans la rédaction de votre formule de calcul, vous disposez d'un assistant à la rédaction en-dessous de la zone de texte. Pour plus d'informations sur les expressions et le traitement des non-réponses notamment, veuillez consulter la page dédiée aux formules de calcul.

  3. Cliquez sur Suivant.

    Vous pourrez apercevoir une prévisualisation des résultats de votre calcul.

  4. Cliquez sur Suivant.

  5. Paramétrez la variable à créer en renseignant son nom (libellé), son type (numérique, fermée unique, texte, code, etc.).

  6. (Facultatif) Cochez la case Variable automatique pour que le calcul s'exécute pour toute observation ajoutée ou modifiée après la création de la variable calculée.

  7. Choisissez l'emplacement de la nouvelle variable.

  8. Cliquez sur Terminer.

Votre variable calculée est créée.
