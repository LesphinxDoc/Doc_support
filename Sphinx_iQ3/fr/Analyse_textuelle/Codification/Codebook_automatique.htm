CODEBOOK AUTOMATIQUE

Le codebook est la grille d’analyse de votre corpus, en général elle contient des thèmes (idées) présents dans le corpus mais peut parfois contenir des éléments descriptifs permettant de classer les textes (source des extraits, auteur…). Cette étape permet d’obtenir des résultats quantitatifs de votre analyse (nombre de thèmes cités, répartition des thèmes etc…). Notez que chaque élément de la grille est appelé "variable".

Il est possible de créer automatiquement un codebook grâce au moteur sémantique de Sphinx iQ3. Cette fonction crée la grille puis code automatiquement les observations. Le codebook automatique contient les concepts présents dans le corpus et chaque observation est codée pour chaque concept y faisant référence.

Pour utiliser la fonction de codebook automatique :

  1. Dans le bandeau, cliquez l’onglet Analyse de contenu.

  2. Cliquez sur le bouton Codebook automatique.

  3. Sélectionnez le type de repérage à utiliser.

    Ceci vous permet de choisir la finesse des concepts (Thèmes généraux, Idées principales ou Concepts détaillés) utilisés pour la création automatique du codebook. Plus le repérage sera fin, plus le codebook sera dense et précis.

  4. Définissez le nombre maximal de concepts à afficher.

    Ce paramètre définit le nombre de variables de codification qui seront créées pour le codebook automatique.

    Cliquez sur Voir l'ensemble des concepts pour afficher le thésaurus utilisé pour l'analyse sémantique. Sont listés les différents niveaux de concepts (des plus génériques, thèmes généraux, aux plus précis, concepts très détaillés).

REMARQUE : Notez qu'après sa création, il est possible d'éditer le codebook, et de modifier les variables de codification et / ou leurs thèmes.

Vous pouvez également créer un nouveau codebook automatique en cliquant sur le bouton Codebook automatique (dans l'onglet Analyse de contenu). Le fait de recréer un codebook automatique réinitialisera le codebook courant.
