UTILISATION DANS LES DICTIONNAIRES

Il est également possible d’utiliser la notion de proximité pour la codification. On passe pour cela via les dictionnaires.

Pour définir la notion de proximité dans les expressions, on utilise comme opérateur le signe « % ».

Celui-ci peut être accompagné d’un chiffre derrière (« %0 », « %1 », …, « %9 »).

REMARQUE : Par défaut, « % » seul équivaut à « %1 ».

À partir du moment où le signe « % » est utilisé, le « bruit » sera systématiquement ignoré lors de la détection des expressions.

Le nombre qui suit le « % » sert à définir le nombre de mots de type adjectifs et noms que l’on va accepter entre les deux mots composant l’expression.

EXEMPLE :
On se place dans le cas où l’on souhaite repérer toutes les expressions parlant de l’« accueil de l’agence ». Mais on ne sait pas comment les utilisateurs vont le saisir.

Cas 1 : on écrit « Accueil %0 agence »

Toutes les expressions contenant du « bruit » entre les deux mots seront détectées.

  • Accueil de mon agence -> Détecté

  • Accueil de notre agence -> Détecté

  • Accueil de cette agence -> Détecté

  • Accueil déplorable de l’agence -> Non détecté (car un adjectif se trouve entre les deux mots)

  • Accueil parfait dans mon agence -> Non détecté (car un adjectif se trouve entre les deux mots)

Cas 2 : on écrit « Accueil %2 agence »

Toutes les expressions contenant du « bruit » ainsi que deux mots (adjectifs ou noms) entre les deux mots seront détectées.

  • Accueil de mon agence -> Détecté (uniquement du bruit)

  • Accueil déplorable de mon agence -> Détecté (bruit + 1 adjectif)

  • Accueil déplorable et catastrophique de mon agence -> Détecté (bruit + 2 adjectifs)

  • Accueil avec un temps d’attente trop long à l’agence -> Non détecté (bruit + 2 noms + 1 adjectif)
