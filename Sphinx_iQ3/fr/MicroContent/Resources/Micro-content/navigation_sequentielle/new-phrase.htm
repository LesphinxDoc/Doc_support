Insérer un code HTML

Vous pouvez enrichir vos formulaires en utilisant des scripts vous permettant d'effectuer diverses actions.

Pour ajouter des scripts, procédez comme suit :

  1. Accédez à l'onglet Insertion.

  2. Puis cliquez sur Code html depuis le groupe Textes et médias.

  3. Insérez votre script entre les deux balises <script> et </script>.

REMARQUE : Ce n'est qu'une fois l'enquête publiée que le code html sera correctement interprété par le navigateur.

REMARQUE : Pour des raisons de sécurité, l'utilisation des scripts dans les formulaires est par défaut désactivée sur les versions 4.20 et supérieures de SphinxOnline.
Pour autoriser l'utilisation des scripts dans les formulaires, veuillez nous envoyer une demande par e-mail à l'adresse hotline@lesphinx.eu en spécifiant le nom de l'enquête ou le nom du compte concerné.
ATTENTION : L'utilisation de script abaisse le niveau de sécurité.

Vous trouverez ci-dessous des exemples de scripts à utiliser :

Fenêtre "popup"

Il est possible d’afficher une page sous forme de pop-up, à l'aide d'une légende "html" dont la syntaxe est :

Copier 
1
<script>openPopup("cliquez ici", "http://www.....",500,200)</script>

  • cliquez ici : le texte du lien

  • http://www... : l'URL du fichier à afficher

  • 500,200 : la largeur et la hauteur de la fenêtre pop-up

Insertion de fenêtre internet dans le formulaire

Il est possible d'afficher une page web intégrée dans le formulaire en utilisant la syntaxe suivante :

Copier 
1
<script>openUrl("http://www.lesphinx-developpement.fr")</script>

REMARQUE : La taille de la fenêtre est définie par la taille de la fenêtre que vous avez paramétrée dans le formulaire (étendre la zone vers le haut et/ou le bas comme pour une image).

Affichage d’une info bulle

Il est possible d’afficher une info-bulle qui s’affichera au survol d’un texte sélectionné en utilisant la syntaxe suivante :

Copier 
1
<span title="Cliquez sur l'un des post-it pour répondre"> Comment répondre ?</span>

  • Cette syntaxe écrira le texte « Comment répondre ? » en police « normale ».

Copier 
1
<a href="" title="Cliquez sur l'un des post-it pour répondre"> Comment répondre ?</a>

  • Cette syntaxe permet d’écrire le texte « Comment répondre ? » en bleu / souligné pour attirer l’utilisateur à passer sa souris dessus.

Gérer le temps de saisie pour une page spécifique du formulaire

Il est possible de gérer le temps de saisie d’une page du formulaire en particulier, à l'aide d'une légende "html" dont la syntaxe est :

Copier 
1
<script>submitTimerPage('{"mintime": 5, "maxtime": 20, "timeShow": false, "position":"navbar"}')</script>

Chacun des paramètres est optionnel. Voici à quoi ils correspondent :

  • "mintime": 5

Permet d’empêcher le passage à la page suivante trop rapidement. Le bouton de navigation « Suivant » ne s'affichera qu'après 5 secondes.

  • "maxtime": 20

Le temps maximum d'affichage de la page est de 20 secondes, passé ce délai on passe automatiquement à la page suivante.

  • "timeShow": false

Option qui définit si le temps doit être affiché ou non (par défaut cette option est à true).

  • "position":"navbar"

Option qui définit où doit être affiché le temps : "navbar" affiche le temps au niveau de la barre de navigation, "inline" (valeur par défaut) l'affiche là où est placée la légende html dans le formulaire.
