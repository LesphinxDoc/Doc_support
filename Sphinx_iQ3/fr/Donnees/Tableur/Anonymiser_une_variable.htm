Comment fonctionne le modèle d'anonymisation de réponses?

Cette fonctionnalité repose sur un modèle de reconnaissance automatique d'entités nommées, spécifiquement conçu pour identifier et anonymiser les informations sensibles présentes dans les réponses aux questions ouvertes. Contrairement aux modèles de type LLM (Large Language Model), ce modèle n’effectue aucun traitement génératif et aucune donnée n’est transmise à des services externes.

Le modèle est hébergé exclusivement sur notre infrastructure sécurisée, garantissant ainsi une maîtrise complète du traitement des données. Aucune sortie de données n'est effectuée hors de l'environnement iQ3.

Langues prises en charge

Français, anglais, espagnol, portugais, allemand, russe, arabe, italien, ukrainien, norvégien, suédois et danois.

REMARQUE : L’anonymisation s'applique à l’ensemble des observations d’une variable, indépendamment de la langue dans laquelle elles ont été saisies.

Pour anonymiser les réponse d'une variable, procédez comme suit :

  1. (Obligatoire) Se connecter au compte SphinxOnline depuis Sphinx iQ3.

    Procédure pour se connecter au compte SphinxOnline depuis Sphinx iQ3 :

    1. Ouvrez le logiciel Sphinx iQ3.

    2. Cliquez sur Connexion en haut à droit de l'écran.

    3. Sélectionnez l'Adresse URL de connexion (le serveur sur lequel votre compte est hébergé).

      Le menu déroulant permet de sélectionner le serveur sur lequel sera publiée votre enquête. Par défaut, c'est le serveur mutualisé SphinxOnline (www.sphinxonline.com) qui est sélectionné.

      Si votre serveur ne figure pas dans la liste :

      1. Cliquez sur le bouton +.

      2. Sélectionnez "Autre serveur" depuis le menu déroulant URL d'accès au compte.

      3. Insérez l'adresse URL de votre serveur.

      4. Cliquez sur Enregistrer pour valider.

    4. Cliquez sur Suivant.

    5. La plateforme SphinxOnline s'ouvre dans votre navigateur : entrez vos identifiants puis cliquez sur Se connecter.

    6. Une boite de dialogue s'ouvre dans votre navigateur, cliquez sur Ouvrir Sphinx iQ3.

      REMARQUE : Cochez l'option "Toujours Autoriser [URL du serveur] à ouvrir les liens de ce type dans l'application associée" pour éviter l'affichage de cette fenêtre lors des prochaines connexions.

    7. Retournez sur l'application Sphinx iQ3.

      REMARQUE : La connexion à votre compte en ligne depuis iQ reste active pendant une période glissante de 5 jours : chaque nouvelle interaction avec le serveur (publication, import, etc.) réinitialise cette période pour une durée de 5 jours à compter de l'action.

    Vous êtes connecté ; le nom du compte apparaît en haut à droite de l'écran.

    En cliquant dessus, il est possible de :

    • Ouvrir le compte en ligne dans le navigateur.

    • Changer de compte (si le compte personnel est lié à un ou plusieurs comptes collaboratifs).

    • Se déconnecter.

  2. Dans l’onglet Textes, cliquez sur le bouton Anonymiser.

  3. Sélectionnez la variable texte à anonymiser.

  4. Indiquez la longueur minimale des commentaires à anonymiser en nombre de caractères (ex : 2 caractères).

  5. (Facultatif) Renseignez le texte à afficher à la place des données sensibles (par exemple : XXXXX).

  6. Sélectionnez l'emplacement d'insertion de la nouvelle variable :

    • Créer la variable à la suite de la variable sélectionnée,

    • Créer la variable dans la partie (partie à définir),

    • Créer la variable à la fin du questionnaire.

    • Si vous avez déjà anonymisé une variable, vous pouvez Compléter la variable. Cela peut être utile si un répondant a modifié sa réponse ou si de nouvelles observations ont été enregistrées et ne sont, par conséquent, pas encore anonymisées.

      REMARQUE : Par défaut, l'anonymisation n'affectera que les cellules vides de la variable anonymisée en amont. Vous pouvez choisir de renvoyer l'ensemble des données (y compris celles ayant déjà été anonymisées) en cochant l'option Renvoyer les données déjà anonymisées.

  7. Cliquez sur Anonymiser pour terminer.
