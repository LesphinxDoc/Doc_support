TRANSFORMER UNE VARIABLE

La transformation des variables propose plusieurs possibilités : gérer les modalités d'une question fermée, créer des classes pour catégoriser les questions numériques, regrouper des codes ou des dates, extraire les informations contenues dans les questions texte, ou changer le type de la variable. Pour ce faire :

  1. Dans l’onglet Données, cliquez sur le bouton Transformer.

  2. Sélectionnez la variable que vous souhaitez transformer.

  3. Choisissez le type de transformation que vous voulez effectuer.

    CHANGER LE TYPE

    Cette option permet de modifier le type d'une variable, par exemple changer une question texte en question fermée unique.

    REMARQUE : La transformation Changer le type est possible pour tous les types de variables.

    1. Choisissez le nouveau type que vous souhaitez affecter à la variable.

    2. (Facultatif) Cochez la case Voir les options avancées pour accéder aux paramètres relatifs au type de question sélectionné.

    3. Choisissez si vous souhaitez modifier la variable choisie en la recodant (la variable initiale sera perdue) ou si vous voulez créer une nouvelle variable.

      Dans le cas de la création d’une nouvelle variable :

      • Renseignez a minima le nom de cette variable (et éventuellement un libellé).

      • Choisissez l’emplacement d’insertion de la nouvelle variable créée (après la variable sélectionnée, à la fin du questionnaire…).

    4. Cliquez sur Terminer.

    GÉRER LES MODALITÉS

    Cette option permet de renommer, ajouter, ordonner, regrouper ou supprimer des modalités d'une variable, de créer une variable pour chacune des modalités ou d'extraire de l'information sur les variables à réponses multiples.

    REMARQUE : La transformation Gérer les modalités n'est possible que pour les variables de type échelle et fermée (unique et multiple).

    Regrouper, ajouter, renommer, supprimer et ordonner les modalités

    Pour regrouper, ajouter, renommer, supprimer et ordonner les modalités, procédez comme suit :

    1. Sélectionnez l'option Regrouper, renommer, supprimer, ordonner les modalités,

      • Pour regrouper, sélectionnez les modalités qui vous intéressent puis cliquez sur le bouton Regrouper.

        EXEMPLE : Nous souhaitons regrouper les modalités "Plutôt satisfait" et "Tout à fait satisfait" dans une catégorie que nous appellerons "Clients satisfaits" et les modalités "Insatisfait" et "Très insatisfait" dans la catégorie "Clients insatisfaits".

      • Pour ajouter une nouvelle modalité, cliquez sur le bouton Nouveau.

      • Pour renommer une modalité, sélectionnez-la puis cliquez sur le bouton Renommer.

      • Pour supprimer une modalité, sélectionnez-la puis cliquez sur le bouton Supprimer.

      • Pour ordonner les modalités, sélectionnez-les puis utilisez les boutons Monter et Descendre.

    2. Cliquez sur Suivant après modification.

    3. Renseignez le nom de cette variable (et éventuellement un libellé).

    4. Choisissez l’emplacement d’insertion de la nouvelle variable créée (après la variable sélectionnée, à la fin du questionnaire…).

    5. Cliquez sur Terminer pour valider et quitter l’assistant.

    Créer une variable pour chacune des modalités

    Cet assistant permet de créer une variable fermée unique pour chacune des modalités de la variable sélectionnée. Pour ce faire :

    1. Sélectionnez l'option Créer une variable pour chacune des modalités.

    2. Sélectionnez le type à utiliser, deux possibilités s’offrent à vous :

      • Les modalités "Oui" et "Non" : Les nouvelles variables créées contiendront les modalités « Oui » ou « Non » pour chacune des modalités choisies sur la variable d’origine.

        EXEMPLE : Si sur votre variable d’origine, vous proposez deux modalités, par exemple « Toujours » et « Jamais » et que le répondant sélectionne « Toujours ». Les deux nouvelles variables qui seront créées dans votre jeu de données seront « Toujours » qui aura pour valeur « Oui », et « Jamais » qui aura pour valeur « Non ».

      • Une seule modalité du nom de la modalité d'origine : Les nouvelles variables créées contiendront, en fonction des modalités choisies sur la variable d’origine, soit le nom de la modalité choisie, soit une non-réponse.

        EXEMPLE : Si sur votre variable d’origine, vous proposez deux modalités, par exemple « Toujours » et « Jamais » et que le répondant sélectionne « Toujours ». Les deux nouvelles variables qui seront créées dans votre jeu de données seront « Toujours » qui aura pour valeur « Toujours », et « Jamais » qui sera à non-réponses (champ vide).

    Créer une variable contenant le nombre de réponses effectives

    À partir de cet assistant, vous pouvez créer une variable numérique qui contient le nombre de réponses effectives de la variable initiale choisie.

    EXEMPLE :
    Si pour une question le répondant peut faire au maximum trois choix, cette nouvelle variable créée prendra comme valeur 0, 1, 2 ou 3 en fonction du nombre de choix fait par le répondant.

    Pour ce faire :

    1. Sélectionnez l'option Créer une variable contenant le nombre de réponses effectives.

    2. Sélectionnez la valeur à affecter en cas de réponse vide : mettre à "Non-réponse" (cellule vide) ou affecter la valeur numérique 0.

      REMARQUE : Il n’est pas possible de recoder la variable existante, vous devez créer une nouvelle variable.

    3. Choisissez où vous souhaitez intégrer cette variable (après la variable initiale ou à la fin du questionnaire).

    4. Cliquez sur Terminer pour valider et quitter l’assistant.

    Créer une variable à partir des combinaisons de ses modalités

    Pour ce faire :

    1. Sélectionnez l'option Créer une variable à partir des combinaisons de ses modalités.

    2. Sélectionnez l'évaluation à effectuer ;

      • Créer toutes les combinaisons de modalités.

      • Trouver les x meilleurs combinaisons de x modalités.

      • Évaluer une combinaison des modalités.

      EXEMPLE :
      Dans le cas où le répondant aurait sélectionné « Maison » et « Restaurant » à une question lui demandant à quel endroit il est le plus susceptible de boire, la variable créée contiendra, pour cette observation, la modalité « Maison_Restaurant ».

    3. Cliquez sur Suivant.

      REMARQUE : Il n’est pas possible de recoder la variable existante, vous devez créer une nouvelle variable.

    4. Choisissez où vous souhaitez intégrer cette variable (après la variable initiale ou à la fin du questionnaire).

    5. Cliquez sur Terminer pour valider et quitter l’assistant.

    Créer une variable pour chaque rang

    Cet assistant permet de créer autant de nouvelles variables que la variable initiale possède de rangs : si la variable possède deux rangs, deux variables seront créées. Chaque variable contiendra l’ensemble des modalités de la variable d’origine et prendra pour valeur la modalité du rang concerné.

    EXEMPLE : Si pour une question le répondant sélectionne « Maison » en premier et « Restaurant » en second, l’assistant va créer deux variables qui auront pour modalité respectivement « Maison » et « Restaurant ».

    Pour ce faire :

    1. Sélectionnez l'option Créer une variable pour chaque rang.

    2. Cliquez sur Suivant.

    3. Cliquez sur Terminer pour valider et quitter l’assistant.

    METTRE LES NOMBRES EN CLASSES

    Cet assistant permet d’affecter chaque observation à une classe, que l’on va définir, le but étant de pouvoir ensuite utiliser ces classes d’observations pour les analyses.

    REMARQUE : La transformation Mettre les nombres en classes est possible pour les variables de type ouverte numérique.

    EXEMPLE : Nous voulons créer des classes d’âge pour la variable Age (numérique). on souhaite créer les classes moins de 30 ans, De 30 à 39 ans, De 40 à 49 ans et plus de 50 ans.

    Vous pouvez mettre les nombres en classes de deux manières :

    • Soit on définit les limites des classes à la main (bornes des classes personnalisées).

    • Soit on utilise une autre méthode permettant une répartition des observations dans les classes, en fonction d’un nombre de classes fixé.

    Définir les limites des classes

    Pour ce faire :

    1. Sélectionnez l'option Définir les limites des classes.

    2. Définissez les limites des classes en les séparant par des « ; ».

    3. Cliquez sur Suivant,

    4. (Facultatif) Vous pouvez modifier le libellé des classes, créé par défaut, en cliquant sur .

      EXEMPLE : On peut décider de nommer les moins de 18 ans : « Mineurs », ceux entre 18 et 25 ans : « Jeunes actifs » etc…

    5. Cliquez sur Suivant.

    6. Choisissez ensuite si vous souhaitez modifier la variable choisie en la recodant (vous perdrez la variable initiale) ou si vous voulez créer une nouvelle variable.

      Dans le cas de la création d’une nouvelle variable :

      • Renseignez à minima le nom de cette variable (et éventuellement un libellé).

      • Choisissez l’emplacement d’insertion de la nouvelle variable créée (après la variable sélectionnée, à la fin du questionnaire…).

    7. Cliquez sur Terminer pour valider et quitter l’assistant.

    Utiliser une méthode de définition de classes

    Pour ce faire :

    1. Sélectionnez l'option Utiliser la méthode.

    2. Choisissez le méthode de définition à utiliser :

      • Même amplitude : l’écart entre les classes créées sera constant.

        EXEMPLE : Dans notre cas on va obtenir les classes 20-29, 30-39, 40-49 etc…

      • Même valeur : va créer autant de classes qu’il existe de valeurs différentes de la variable sélectionnée.

        EXEMPLE : Dans notre exemple, nous avons choisi la variable Age, si nous avons trois observations dont les valeurs de cette variable sont respectivement 21, 21 et 42, la méthode va créer deux classes : la classe 21, qui regroupera deux observations, et la classe 42 avec une seule observation.

      • Autour de la moyenne : vous permet de créer au choix 3, 5 ou 7 classes d’intervalles, chaque intervalle ayant une « longueur » de ½, 1 ou 2 fois l’écart type. La classe médiane sera l’intervalle contenant la moyenne.

        EXEMPLE : Votre jeu de données possède pour la variable « Age » les valeurs 12, 18, 20, 30, 40. On obtient une moyenne de 25 et un écart-type de 10,18. Vous désirez créer cinq classes autour de la moyenne de 1 écart-type (10,18). Voici les classes qui seront créées :

      • Même effectif : va créer des classes de telle sorte qu’elles contiennent environ le même nombre d’observations (répartition équilibrée des observations).

    3. Cliquez sur Suivant.

    4. (Facultatif) Vous pouvez modifier le libellé des classes, créé par défaut, en cliquant sur .

      EXEMPLE : On peut décider de nommer les moins de 18 ans : « Mineurs », ceux entre 18 et 25 ans : « Jeunes actifs » etc…

    5. Cliquez sur Suivant.

    6. Choisissez ensuite si vous souhaitez modifier la variable choisie en la recodant (vous perdrez la variable initiale) ou si vous voulez créer une nouvelle variable.

      Dans le cas de la création d’une nouvelle variable :

      • Renseignez à minima le nom de cette variable (et éventuellement un libellé).

      • Choisissez l’emplacement d’insertion de la nouvelle variable créée (après la variable sélectionnée, à la fin du questionnaire…).

    7. Cliquez sur Terminer pour valider et quitter l’assistant.

    REGROUPER LES CODES

    REMARQUE : Rappel : la transformation Regrouper les codes est possible pour les variables de type code (par exemple, code postal).

    Pour ce faire :

    1. Sélectionnez la méthode de regroupement à utiliser ;

      • Regrouper avec un dictionnaire : cette méthode vous permet d'utiliser un dictionnaire (fichier .txt) pour regrouper vos codes.

        EXEMPLE : Dans notre cas nous souhaitons regrouper les codes par département dans le but d’effectuer des statistiques par département (ou par région, etc.) durant les analyses.

      • Regrouper de manière personnalisée : cette méthode vous permet de regrouper manuellement vos codes en créant les noms de groupes appropriés.

        EXEMPLE : Sélectionner 73 et 74 et créer le groupe "Pays de Savoie".

    2. (Facultatif) Vous pouvez réduire le code à un certain nombre de caractères.

      EXEMPLE : Si on coche cette option et que l’on met (1 ;2), les codes apparaîtront sous la forme 73 et 74, alors que si on met (1 ;2 ;3 ;4 ;5) ou si on laisse le champ vide, les codes apparaîtront sous la forme 73000, 74000 etc.

    3. Cliquez sur Suivant.

    4. Choisissez ensuite si vous souhaitez modifier la variable choisie en la recodant (vous perdrez la variable initiale) ou si vous voulez créer une nouvelle variable.

      Dans le cas de la création d’une nouvelle variable :

      • Renseignez a minima le nom de cette variable (et éventuellement un libellé).

      • Choisissez l’emplacement d’insertion de la nouvelle variable créée (après la variable sélectionnée, à la fin du questionnaire…).

    5. Cliquez sur Terminer pour valider et quitter l’assistant.

    REGROUPER LES DATES

    Cet assistant permet de regrouper des dates par catégorie/classe.

    REMARQUE : La transformation Regrouper les dates est possible pour les variables de type date.

    EXEMPLE :
    Nous souhaitons regrouper toutes nos dates par année.

    Pour regrouper des dates :

    1. Sélectionnez la méthode de regroupement à utiliser :

      • Regrouper les dates en périodes prédéfinies, du type mois/année, trimestre, semestre etc.

      • Regrouper les dates par périodes personnalisées, à entrer à la main du type JJ.MM.AAAA.

        EXEMPLE : « 01.02.2003 ; 01.02.2004 ; 01.02.2005 » va vous créer quatre périodes, avant le 01.02.2003 ; entre le 01.02.2003 et le 01.02.2004 ; entre le 01.02.2004 et le 01.02.2005 et enfin après le 01.02.2005.

    2. Cliquez sur Suivant.

    3. Choisissez ensuite si vous souhaitez modifier la variable choisie en la recodant (vous perdrez la variable initiale) ou si vous voulez créer une nouvelle variable,

      Dans le cas de la création d’une nouvelle variable :

      • Renseignez a minima le nom de cette variable (et éventuellement un libellé).

      • Choisissez l’emplacement d’insertion de la nouvelle variable créée (après la variable sélectionnée, à la fin du questionnaire…).

    4. Cliquez sur Terminer pour valider et quitter l’assistant.

    EXTRAIRE DE L’INFORMATION DES TEXTES

    Pour ce faire :

    1. Choisissez le type de variable que vous désirez créer : lexicale, lemmatisée, analyse via un dictionnaire thématique.

    REMARQUE : La transformation Extraire de l’information des textes est possible pour les variables de type texte.

    Variable lexicale

    Vous pouvez générer différents types de variables qui auront pour modalités possibles les mots choisis, pour ce faire :

    1. Choisissez les mots à considérer :

      • Tous les mots.

      • Un ensemble de mots (à séparer par des « ; »).

      EXEMPLE : Nous choisissons de considérer les trois mots que nous savons les plus souvent cités (santé, vie et bien-être) à la question « commentaires » qui demande aux répondants de citer les mots qui leur viennent à l’esprit à la vue du mur d’images.

    2. Définissez les mesures lexicales à utiliser.

      Ces derniers vont créer des variables permettant d’analyser le contenu de votre variable texte.

      • La longueur correspond au nombre de mots de la réponse (si une réponse est « la vie est belle », la longueur sera de 4, si l’on prend en compte les mots-outils).

      • La richesse est le nombre de mots différents dans une réponse.

      • La banalité est une moyenne de fréquence des mots d’une réponse (plus les mots sont fréquents plus la banalité sera forte).

      • Enfin l’intensité donne le « taux de présence » des mots choisis, (dans notre cas santé, vie et bien être) dans une réponse.

        EXEMPLE : Si une réponse est « La vie » l’intensité du mot « vie » sera de 50%, car la réponse contient deux mots dont « Vie »  (si l’on prend en compte les mots outils).

    3. Cliquez sur Suivant.

    4. Sélectionnez l'emplacement d’insertion des nouvelles variables.

    5. Cliquez sur Terminer.

    Variable lemmatisée

    Cet assistant permet de créer :

    • Des variables textes dont les contenus seront les textes des variables sélectionnées sous leur forme lemmatisée (infinitif, masculin, singulier).

      EXEMPLE : « Je bois » devient « je boire ».

    • Plusieurs variables textes pour chaque catégorie grammaticale de la variable sélectionnée (verbes, noms, adjectifs).

      EXEMPLE : « Je bois de l’eau », une variable Verbe va être créé contenant la valeur « boire » et une variable Nom contenant la valeur « eau ».

    Pour ce faire :

    1. Sélectionnez les éléments à générer (Texte lemmatisé, catégories grammaticales).

    2. Cliquez sur Suivant.

    3. Sélectionnez l'emplacement d’insertion des nouvelles variables.

    4. Cliquez sur Terminer.

    Analyse thématique

    L'analyse thématique permet de créer des variables identifiant les thèmes principaux de chaque observation.

    Pour ce faire :

    1. Chargez les dictionnaires à utiliser en cliquant sur le bouton Choisir des dictionnaires.

    2. Choisissez les variables à créer :

      • Variable fermée ordonnée sur les thèmes présents.

      • Variables fermées multiples sur les mots importants de chaque thème.

    3. Cliquez sur Suivant.

    4. Sélectionnez l'emplacement d’insertion des nouvelles variables.

    5. Cliquez sur Terminer.

    REMARQUE : Notez que seules les transformations possibles sur la variable choisie seront sélectionnables, les autres apparaîtront grisées.
