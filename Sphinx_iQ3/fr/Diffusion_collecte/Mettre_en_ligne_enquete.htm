PUBLIER / RE-PUBLIER L’ÉTUDE

Cette partie vous permet de mettre en ligne votre enquête sur votre compte SphinxOnline. Celle-ci pourra ainsi être diffusée à tous vos répondants. Les réponses collectées seront enregistrées également sur votre compte en ligne.

Mettre en ligne l’enquête se compose de deux parties distinctes, le cas d’une première publication et le cas d’une publication d’une enquête déjà publiée sur votre compte SphinxOnline au préalable.

Comment y accéder ?

  • Depuis le panneau d’accueil, cliquez sur le bouton Publier l'étude.

  • Ou depuis l'environnement de Conception du questionnaire, onglet Diffusion, cliquez sur le bouton Publier.

PUBLIER L’ÉTUDE

Pour publier une étude sur votre compte en ligne, procédez comme suit :

  1. Cliquez sur Publier.

  2. Connectez-vous à votre compte en ligne :

    1. Sélectionnez l'Adresse URL de connexion (le serveur sur lequel votre compte est hébergé).

      Le menu déroulant permet de sélectionner le serveur sur lequel sera publiée votre enquête. Par défaut, c'est le serveur mutualisé SphinxOnline (www.sphinxonline.com) qui est sélectionné.

      Si votre serveur ne figure pas dans la liste :

      1. Cliquez sur le bouton .

      2. Sélectionnez "Autre serveur" depuis le menu déroulant.

      3. Puis renseignez l'adresse de votre serveur.

      4. Cliquez sur Enregistrer pour valider.

      (Facultatif) Le bouton « Proxy… », vous donne la possibilité d’indiquer vos informations de proxy, passerelle entre votre réseau et internet (Hôte, identifiant et mot de passe). Nous vous invitons à vous rapprocher de votre service informatique pour le paramétrage du proxy.

    2. Cliquez sur Suivant.

    3. La plateforme SphinxOnline s'ouvre dans votre navigateur : si vous n'êtes pas encore connecté en ligne, entrez vos identifiants puis cliquez sur Se connecter.

    4. Une boite de dialogue s'ouvre dans votre navigateur, cliquez sur Ouvrir Sphinx iQ3.

      Cliquez sur l'image ci-dessus pour un aperçu animé

    5. Retournez sur l'application Sphinx iQ3.

      REMARQUE : La connexion à votre compte en ligne depuis iQ reste active pendant une période glissante de 5 jours : chaque nouvelle interaction avec le serveur (publication, import, etc.) réinitialise cette période pour une durée de 5 jours à compter de l'action.

  3. Si vous avez accès à plusieurs comptes (compte personnel + comptes collaboratifs), sélectionnez le compte sur lequel vous souhaitez publier votre enquête.

  4. Renseignez le Nom de l'étude (ce nom sera apparent dans l’URL que vous allez obtenir suite à cette publication et sera visible par les répondants).

    REMARQUE : Le nom de l'étude est limité à 50 caractères et ne doit pas contenir de caractères spéciaux ou d'espaces.

    REMARQUE : Le lien direct du questionnaire est composé de la manière suivante :
    nomduserveur/surveyserver/s/nomducompte/nomdelenquete/raccourci.htm

  5. (Facultatif) Cliquez sur le bouton Editer les options pour paramétrer les options de publication.

  6. Cliquez sur Suivant,

  7. Sélectionnez Publier le questionnaire et cochez la case Publier les réponses de Sphinx iQ, si vous possédez déjà des réponses et que vous souhaitez les avoir en ligne.

    EXEMPLE : Si votre enquête en local possède 50 réponses en local, elles seront publiées si vous cochez cette option. Sinon, seul le questionnaire sera publié sur le serveur.

  8. Cliquez sur Suivant et vérifiez les informations de publication.

  9. Cliquez sur Terminer.

    Une fois votre enquête publiée, vous arrivez sur une boîte de dialogue vous permettant d’accéder aux différents liens relatifs à votre enquête, notamment les différents formulaires de saisie ou de modification.

    Vous pouvez également accéder à votre compte SphinxOnline, soit en cliquant sur le lien votre gestionnaire de compte, soit en cochant l’option Accéder directement au gestionnaire de compte. Votre compte s’ouvrira automatiquement à partir de votre navigateur internet au clic sur OK.

  10. Cliquez sur OK pour fermer la fenêtre.

REPUBLIER L'ÉTUDE

Une enquête publiée en ligne peut être republiée à tout moment pour mettre à jour les formulaires, les réponses et les analyses créées. Pour republier une enquête, procédez comme suit :

  1. Cliquez sur Publier.

  2. Connectez-vous à votre compte en ligne :

    1. Sélectionnez l'Adresse URL de connexion (le serveur sur-lequel votre compte est hébergé).

      Le menu déroulant permet de sélectionner le serveur sur lequel sera publiée votre enquête. Par défaut, c'est le serveur mutualisé SphinxOnline (www.sphinxonline.com) qui est sélectionné.

      Si votre serveur ne figure pas dans la liste :

      1. Cliquez sur le bouton .

      2. Sélectionnez "Autre serveur" depuis le menu déroulant.

      3. Puis renseignez l'adresse de votre serveur.

      4. Cliquez sur Enregistrer pour valider.

      (Facultatif) Le bouton « Proxy… », vous donne la possibilité d’indiquer vos informations de proxy, passerelle entre votre réseau et internet (Hôte, identifiant et mot de passe). Nous vous invitons à vous rapprocher de votre service informatique pour le paramétrage du proxy.

    2. Cliquez sur Suivant.

    3. La plateforme SphinxOnline s'ouvre dans votre navigateur : si vous n'êtes pas encore connecté en ligne, entrez vos identifiants puis cliquez sur Se connecter.

    4. Une boite de dialogue s'ouvre dans votre navigateur, cliquez sur Ouvrir Sphinx iQ3.

      Cliquez sur l'image ci-dessus pour un aperçu animé

    5. Retournez sur l'application Sphinx iQ3.

      REMARQUE : La connexion à votre compte en ligne depuis iQ reste active pendant une période glissante de 5 jours : chaque nouvelle interaction avec le serveur (publication, import, etc.) réinitialise cette période pour une durée de 5 jours à compter de l'action.

  3. Si vous avez accès à plusieurs comptes (compte personnel + comptes collaboratifs), Sélectionnez le compte sur lequel vous souhaitez publier votre enquête.

  4. Renseignez le Nom de l'étude à mettre à jour.

  5. (Facultatif) Cliquez sur le bouton Editer les options pour paramétrer les options de publication.

  6. Cliquez sur Suivant,

  7. Un message s'affichera pour vous indiquer que l'étude existe déjà sur le serveur. Vous devez alors choisir entre deux options en fonction des modifications effectuées :

    Remplacer le questionnaire sur SphinxOnline par celui de Sphinx iQ

    Cette option supprime l'enquête qui se trouve sur SphinxOnline et la remplace par l'enquête Sphinx iQ (formulaires, réponses, analyses...).

    Cochez la case Effacer le fichier de réponses sur SphinxOnline pour publier l’enquête sans les réponses locales (les réponses se trouvant sur l'enquête en ligne seront supprimées).

    L'option remplacer le questionnaire est à utiliser lors de :

    • D'une suppression de modalités / variables.

    • D'une modification du nom des variables.

      REMARQUE : Si votre enquête est en cours, il faut s'assurer d'avoir importé les données (réponses) de l'enquête en ligne dans votre enquête en locale avant de procéder aux modifications et au remplacement de l'étude en ligne.

    Mettre à jour le questionnaire sur SphinxOnline

    Cette option permet de publier de votre enquête Sphinx iQ en la fusionnant avec l'enquête déjà présente en ligne. Les éléments de l'enquête locale qui ne sont pas présents sur l'enquête en ligne y sont ajoutés.

    REMARQUE : Cette option conservera toujours un maximum d'informations (modalités, questions, réponses, analyses) sur l'enquête en ligne.

    Cochez la case Modifier le fichier de réponses sur SphinxOnline si vous souhaitez compléter le fichier de réponses en ligne avec les réponses locales.

    REMARQUE : Si une même observation est présente en ligne et en local, la réponse conservée est la plus récente (vérification basée sur la valeur de la variable DATE_MODIF).

    L'option Mettre à jour est à utiliser lors de :

    • L'ajout de nouvelles modalités ou de nouvelles variables.

    • La modification de libellés de modalités ou de libellés de variables.

    • L'ajout / modification de conditions d'affichage / renvois.

    • La modification du formulaire (la mise en forme, rajout / suppression d'images, textes, etc...).

  8. Cliquez sur Suivant,

  9. S'il existe des vues d'analyses aux noms identiques sur le serveur, vous avez la possibilité de :

    • Les remplacer (par les vues présentes dans Sphinx iQ3) en cliquant sur le bouton Remplacer les vues de SphinxOnline par celles de Sphinx iQ.

    • Les conserver en cliquant sur le bouton Conserver les vues déjà existantes sur SphinxOnline.

  10. Cliquez sur Terminer pour effectuer la republication.
