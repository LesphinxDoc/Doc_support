Notifications Sphinx report

Une notification Sphinx Report est une alerte envoyée directement sur un appareil mobile via l’application Sphinx Report. Elle permet d’alerter l'utilisateur lorsqu’une nouvelle réponse satisfait une condition définie (exemple : note inférieure à 7), afin de recontacter rapidement un client insatisfait par exemple.

Activer et paramétrer la notification dans Sphinx iQ3

  1. Depuis la partie Conception, accédez à l’onglet Diffusion puis cliquez sur Définir des raccourcis.

  2. Cliquez sur l'onglet Notifications SphinxReport.

  3. Cochez la case Activer les notifications push sur l’application mobile.

  4. Cliquez sur .

  5. Renseignez l’adresse e-mail du destinataire (Si plusieurs destinataires, séparez les adresses par un point-virgule).

    REMARQUE : Il est possible de rappeler la réponse à une variable dans le champ Emails des destinataires l’encadrant avec des crochets : exemple : [Email].

  6. Saisissez un titre de notification (65 caractères max) — ex. : Alerte - client insatisfait !

  7. Saisissez une description de la notification (240 caractères max), avec possibilité de rappeler les réponses à des variables — ex. : [Note].

  8. Cochez Envoyer si, puis cliquez sur Modifier pour définir la condition de déclenchement de la notification.

  9. Cliquez sur OK.

  10. Publiez l’enquête sur le compte en ligne.

Configurer l'accès dans SphinxOnline

  1. Accédez au report concerné.

  2. Cochez l’option Accès avec l’application mobile dans la section Paramétrer ma configuration.

  3. Ajoutez les adresses e-mail des utilisateurs dans la section Définir les utilisateurs en utilisant l'Authentification Sphinx. Plus d'informations sur l'Authentification Sphinx.

    ATTENTION : Attention, pour que les notifications push fonctionnent, il est impératif que l’adresse renseignée dans iQ3 et l’adresse renseignée dans les accès restreints soient identiques pour un même utilisateur. Si ce n’est pas le cas, les notifications ne fonctionneront pas.

  4. Cochez l'option Activer l'accès restreint.

  5. Cliquez sur Diffuser, puis sur Envoyer pour diffuser le report.

  6. En tant qu’utilisateur :

    1. Cliquez sur le lien reçu par e-mail.

    2. Définissez un mot de passe.

    3. Connectez-vous au rapport.

    4. Cliquez sur Accès avec l’application mobile (en bas à gauche de l’écran).

Ajouter le report dans l'application mobile

  1. Téléchargez l’application Sphinx Report en scannant le QR code Android ou iOS en fonction du système d’exploitation de votre appareil affiché dans la page Accès avec l'application Mobile.

  2. Ouvrez l’application.

  3. Cliquez sur le bouton + pour ajouter un reporting.

  4. Scannez le QR code du reporting présent dans la page Accès avec l'application Mobile.

  5. Renseignez l’adresse e-mail et le mot de passe.

    Vérification de la notification

    1. Fermez ou quitter l’application.

    2. Effectuez une saisie test répondant à la condition définie.

    3. Vérifiez l’affichage de la notification push sur l’appareil mobile.
