FOIRE AUX QUESTIONS

Comment activer ma clé de licence ?

Accédez à la procédure expliquant comment activer une clé de licence.

Comment éditer le titre de l'étude (Nom de l'onglet Internet) ?

Pour éditer le titre de l'étude, il suffit de procéder comme suit :

  1. Depuis le panneau d'accueil de Sphinx iQ3, cliquez sur l'icône (qui se trouve à droite du nom de l'enquête), ou cliquez sur Fichier, puis sur Propriétés de l'étude.

  2. Renseignez le nouveau titre de l'étude.

  3. Cliquez sur OK pour valider.

  4. Republiez votre enquête.

Le logiciel me demande de rentrer une clé de licence à chaque ouverture, pourquoi ?

Si le logiciel vous demande d'insérer la clé à chaque démarrage, cela veut dire que vous n'avez pas activé votre clé de licence en mode administrateur.

Pour ne plus avoir ce problème, vous devez impérativement lancer le logiciel Sphinx iQ3 en tant qu'administrateur puis rentrer la clé de licence.

Quel est le nombre maximum de modalités que je peux rentrer dans une question fermée ?

Vous êtes limité à 511 modalités par question. Si vous avez une question qui risque de comporter plus de 511 modalités, nous vous recommandons dans ce cas de passer par une question de type liste de codes.

Message "Il y a d'autres utilisateurs connectés à l'étude ..., l'ouverture de l'étude risque de l'endommager" lors de l'ouverture d'une étude, que dois-je faire ?

Ce message s’affiche quand le fichier .lck (qui est créé à l’ouverture de l’enquête) ne se supprime pas.

Cela peut se produire dans le cas d’une fermeture forcée ou incorrecte du logiciel.

Si vous êtes la seule personne à travailler sur cette enquête, il suffit de cliquer sur Oui pour ignorer le message.

Si d'autres personnes sont connectées à l'étude, il est recommandé de vérifier auprès d'eux avant de l'ouvrir de votre côté.

En savoir plus sur les types de fichiers d'une étude Sphinx iQ3.
