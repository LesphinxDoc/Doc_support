CRÉER UN MODÈLE DE PRÉSENTATION DE FORMULAIRE

Créer un modèle de présentation du formulaire permet de définir le format, les propriétés du formulaire ainsi que les styles des objets (options de présentations des questions, polices et couleurs). Cette fonction permet d'avoir un rendu homogène sur tout le formulaire.

De plus, il peut arriver au chargé d'études de réaliser plusieurs questionnaires pour le même client. La création d'un modèle de présentation du formulaire pour la première étude permet au chargé d'études de l'appliquer automatiquement par la suite aux nouveaux formulaires créés. Tous les questionnaires ont ainsi la même mise en forme (logo, couleurs, taille du texte, etc...).

Pour ce faire :

  1. Dans l'onglet Modèles, cliquez sur le bouton Créer un modèle.

  2. Donnez un nom au modèle.

  3. Procédez à la personnalisation du modèle depuis les différents onglets disponibles :

    1. Thèmes

      Vous pouvez :

      • Sélectionner un motif (modèle prédéfini) ou sélectionner une image de fond personnalisée (avec la possibilité de choisir la position de l'image : remplir, centrer, ajuster, étirer et répéter).

      • Personnaliser la couleur de fond, la couleur et l'opacité du formulaire.

      • Rajouter une bordure ainsi qu'un ombrage si nécessaire.

    2. En-tête et pied de page

      Vous pouvez :

      • Ajouter un titre et une image (logo) dans l'en-tête.

      • Ajouter une image de fond dans le pied de page.

    3. Présentation

      Vous pouvez :

      • Paramétrer la représentation visuelle par défaut de chaque type de question.

      • Définir le contenu à afficher (titre, libellé, nom de variable, consigne etc...).

      • Paramétrer la zone de saisie.

      • Paramétrer l'espacement entres les éléments (questions, titres, zones de texte et objets multimédia).

    4. Polices et couleurs

      • Définissez les polices et couleurs à utiliser pour chaque objet (question, tableau , partie, texte et bouton).

  4. Cliquez sur OK pour valider.

    Après validation, un nouveau formulaire sera ajouté à la liste des modèles prédéfinis. Il est à tout moment possible de modifier ou de supprimer le modèle créé, et de créer de nouveaux modèles.

REMARQUE : Notez qu'il est possible de récupérer un modèle de présentation d'une autre étude.

Pour ce faire :

  1. Depuis l'onglet Modèles, cliquez sur Importer un modèle.

  2. Sélectionnez l'étude.

  3. Sélectionnez le modèle à importer depuis la liste.

  4. Cliquez sur OK pour valider.

Notez que vous avez également accès à des modèles prédéfinis que vous pouvez utiliser pour personnaliser votre formulaire.

Pour ce faire :

  1. Depuis l'environnement de Conception du questionnaire, cliquez sur l'onglet Modèles.

  2. Sélectionnez un modèle à utiliser depuis la liste.

ou

  • Depuis l'environnement de travail, sélectionnez un modèle à partir du menu situé à droite.
