PROPRIÉTÉS DU FORMULAIRE

Les propriétés du formulaire permettent le paramétrage de plusieurs options propres à un formulaire. On y gère le nom du formulaire et certains aspects graphiques (type et taille de formulaire, gestion des modèles), mais aussi de paramètres liés à la saisie en locale ou en ligne, ainsi que les contraintes d'intégrité permettant la validation, ou non, du formulaire.

Pour accéder aux propriétés du formulaire, procédez comme suit :

  1. Depuis l'onglet Formulaires, cliquez sur le bouton Propriétés.

  2. Paramétrez les options depuis les onglets Définition, Internet et Contrôles.

    Onglet Définition

    Vous pouvez :

    • Modifier le nom du formulaire.

    • Choisir le type du formulaire (Web, papier, écran, scanner).

    • Modifier la taille du formulaire (800*600, 1024*768, taille personnalisée, etc...).

    • Sélectionner un modèle de formulaire depuis la liste disponible ou créer un nouveau modèle en cliquant sur Créer un modèle. Plus d'informations sur la création de modèle de présentation.

    • Choisir la méthode selon laquelle la numérotation des variables sera effectuée.

      • La présentation du formulaire : les questions sont numérotées selon l'ordre de présentation sur le formulaire courant.

      • L'indice hiérarchique : les questions sont numérotées selon un indice hiérarchique.

      • Le numéro des variables : les questions sont numérotées selon l'ordre de présentation dans la liste des variables.

      • Pas de numérotation : aucune numérotation n'est appliquée aux questions (option sélectionnée par défaut).

    Onglet Internet

    1. Mode de navigation

      Cette partie vous permet de paramétrer le passage à la page suivante.

      • Navigation standard : Le passage à la page suivante se fait à l'aide de la barre de navigation. Il est possible de personnaliser le style et la couleur de la barre de navigation.

      • Navigation séquentielle : le passage à la page suivante se fait automatiquement après que le répondant a renseigné les questions à la page courante.

        Cliquez sur l'image pour un aperçu animé

    2. Mise en forme smartphone spécifique

      • Cochez l'option Activer la mise en forme smartphone afin de personnaliser l'affichage du questionnaire sur les smartphones.

    3. Temps de saisie

      • Cocher la case Limiter le temps de saisie à permet de limiter la saisie à x secondes.

      • (Facultatif) Il est possible de rediriger le répondant vers un site en insérant le lien dans le champ Lien optionnel.

      • Cocher la case Indiquer le temps écoulé permet d'afficher un compte à rebours dans le formulaire.

    4. Redimensionnement automatique

      • Cocher la case Adapter automatiquement le formulaire à la largeur du navigateur internet permet d'activer le responsive design.

      • Cocher la case Adapter automatiquement la hauteur du formulaire au nombre de questions affichées permet de supprimer l'espace vide entre les questions et les boutons de navigation.

    5. Transition des pages

      • Sélectionnez le mode de transition des pages : Fondu, Carrousel ou Aucun (mode défini par défaut, pas d'effet).

    Onglet Contrôles

    Cette partie vous permet de mettre en place des contraintes de navigation afin d'alerter le répondant et de bloquer la progression du questionnaire dans certains cas. Plus d'informations sur la mise en place d'une contrainte de saisie.
