CHANGER LE MODE DE NAVIGATION

Il est désormais possible de définir le mode de navigation à utiliser pour le passage à la page suivante lors d'une saisie d'un questionnaire. Vous pouvez choisir entre deux modes de navigation :

  • La Navigation standard : Le passage à la page suivante se fait à l'aide de la barre de navigation. Il est possible de personnaliser le style et la couleur de la barre de navigation.

  • La Navigation séquentielle : Le passage à la page suivante se fait automatiquement, après que le répondant a renseigné les questions de la page courante.

    Cliquez sur l'image pour un aperçu animé

    REMARQUE : Le répondant aura toujours la possibilité d'utiliser une barre de navigation (située en bas à droite du formulaire) pour aller à la page suivante, revenir à la page précédente en navigation séquentielle.

Pour choisir un mode de navigation, procédez comme suit :

  1. Accédez à l'environnement de conception du questionnaire.

  2. Depuis l'onglet Formulaires, sélectionnez le mode de navigation à utiliser.
