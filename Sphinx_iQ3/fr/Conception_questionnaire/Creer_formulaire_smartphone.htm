CRÉER UN FORMULAIRE SMARTPHONE

Il est désormais possible de créer un formulaire spécifique adapté aux appareils mobiles dans Sphinx iQ3.

Ceci vous permettra de personnaliser l'affichage de votre questionnaire (présentation des questions, alignement et taille des objets, etc...) pour les répondants qui y accéderont via un smartphone tout en gardant l'affichage initialement prévu pour ceux qui répondent depuis un ordinateur.

EXEMPLE : Nous avons une question de type Glisser-déposer, ce type de présentation n'est pas vraiment adapté à l'utilisation sur un smartphone, l'idée serait donc de générer un formulaire Smartphone et de changer le type de présentation de la question (en cases à cocher par exemple).

Pour créer un formulaire Smartphone, procédez comme suit :

  1. Depuis l'environnement de conception, onglet Formulaires, cliquez sur Mise en forme spécifique.

  2. Deux icônes sont alors rajoutées au niveau du formulaire, cliquez sur le bouton + à droite de l'icône .

    Le contenu présent dans le formulaire écran sera repris dans le formulaire smartphone.

  3. Procédez à la personnalisation de votre formulaire Smartphone.

    Si par la suite vous avez rajouté une nouvelle question ou un autre élément dans le formulaire web, vous devez également rajouter cette question dans le formulaire smartphone ou directement cliquer sur le bouton pour régénérer le formulaire smartphone.

    ATTENTION : Veuillez ne pas utiliser cette option si vous avez déjà commencé à personnaliser votre formulaire smartphone.
    En effet, l'option Régénérer le formulaire smartphone permet de reprendre exactement ce qu'il y'a dans le formulaire écran (présentation des questions, couleurs, taille des polices etc...) ce qui risque d'écraser toutes les modifications effectuées précédemment.

  4. Cliquez sur pour lancer une vérification des formulaires.

    Ou depuis l'onglet Formulaires, bouton Vérifications des formulaires.

    Cette option consiste à lister les différences entre le formulaire ordinateur et smartphone. Ceci vous permettra d'identifier la liste des variables absentes sur chaque formulaire et s'il y a éventuellement un chevauchement de variables.

    EXEMPLE : Dans l'exemple ci-dessus, nous pouvons voir que la variable 1. Lieu_de_sejour est absente dans le formulaire smartphone et qu'il y a chevauchement de variables dans la page 7.

    (Si besoin) Il suffit de rajouter les variables manquantes et les replacer en cas de chevauchement puis cliquer sur Relancer la vérification.

Pour revenir sur le formulaire Écran, il suffit de cliquer sur l'icône .
