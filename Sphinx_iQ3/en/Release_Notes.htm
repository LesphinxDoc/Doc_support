SPHINX iQ3 RELEASE NOTES

Below you will find the new features of the Sphinx iQ3 software.

Sphinx iQ3 v 8.14.2

[10/04/2026]

New features:

  • AI

    • This new version introduces significant new features that will enhance usability and the day-to-day user experience. A whole new world of possibilities opens up with a new feature for AI-generated variables. By writing a custom prompt, you can ask the AI directly to perform a task on a variable (for example, analyse emotional tone, correct spelling mistakes, create a summary, classify by topic, detect contact details, etc.).

    • Ability to trigger an automatic AI action via a questionnaire button that has been pre-configured using a custom prompt.

    • Ability to generate an AI-calculated variable by writing a custom prompt from the ‘Analysis and Calculation’ tab, ‘Calculated Variable’, then ‘AI Calculation’.

  • Questionnaire

    • Addition of a dynamic filtering option for "Code" type questions. Each question can now automatically filter the options offered in the next question based on the previous answer, using a cascade logic. The option is available for code type questions in "Code list" format, via the "Pre-filter the list by variable" tick box.

What's new in Dataviv'?

  • General

    • Improvements to the "Quick Overview" summary view, allowing users to view a flat breakdown of results with a single click.

    • New maps added for the following countries: Costa Rica, Ecuador, Guatemala, Panama, Peru, the Dominican Republic, El Salvador and Uruguay.

  • Interface / Usability

    • Redesigned look and feel of the view manager.

    • Added 16 new view templates in various formats: dashboard, report, A4 and infographic.

  • AI

    • Ability to create a new variable via AI by entering a custom prompt directly in the “calculate a variable” section when editing a view. For more information, please see our best practice guide https://infos.lesphinx.eu/DOC/IA/en/modeles_prompts.htm.

Fixes:

  • Missing response synchronization message.

  • Error 002 when publishing the current view.

  • Minor bug fixes.

Sphinx iQ3 v 8.13.1

[20/11/2025]

New feature:

  • The AI rephrasing assistant in analysis views has been enhanced and now allows you to shorten, lengthen, correct mistakes, list key concepts, or change the tone of your text.

Improvements:

  • Improved accessibility of questionnaires: automatic adjustment of icon colors to match the text on form buttons.

  • Update of the default form template.

  • Enhanced data anonymization service with new options.

What's new in Dataviv'?

  • General

    • Optimized display performance in views for faster loading.

  • AI

    • Enhanced text zone rephrasing assistant in analysis views (shorten, lengthen, correct mistakes, list key concepts, or change the tone).

  • Custom Tables

    • Improved dynamic custom tables by enabling inter-column calculations.

  • Visualization

    • Improved accessibility of textual and semantic analyses when coloring verbatim by orientation. Color contrasts have been reworked to increase readability and accessibility of orientation-colored verbatim.

    • Added a filter allowing users to define a rolling time period on a profile (view, chart, or table) based on a “date” variable. Results can now be displayed over a dynamic time interval (e.g., last week), recalculated daily instead of being fixed.

    • It is now possible to define and edit “rolling period” profile.

Fixes:

  • Minor bug fixes.

Sphinx iQ3 v 8.12.1

[04/08/2025]

New feature:

  • Anonymization of text variables. It is now possible to anonymize an entire corpus of text data in just a few clicks. This feature facilitates the processing of corpora containing sensitive data, thereby ensuring their confidentiality.

Improvement:

  • Accessibility of forms. The forms have been optimized to meet the requirements of the General Accessibility Improvement Framework (RGAA 4.1.2.)

What's new in Dataviv'?

  • General

    • Improved view display performance for faster loading.

  • AI

    • Addition of a button to directly copy the interpretation of an analysis to a text box in the view.

    • Enhanced information message: clarification on the use of data by AI — only data selected for interpretation is processed.

    • AI-powered real-time coding in the “verbatim coding” analysis (option available only in the online version). This option allows you to automatically code new, uncodified verbatim as responses are received.

    • Addition of an automatic variable "origine_codification" to identify whether a verbatim has been encoded by AI or manually.

    • New functionality to rephrase content from a textbox in a view. The formatting of the text (color, size, etc.) is used, as well as the calculations and merge fields. Feature only available in the online version.

  • Custom Tables

    • Option to hide columns/rows that are empty when applying a filter or a display condition.

  • Visualization

    • Ability to share a view with a filter applied by default (closed variables only).

  • Textual and semantic analysis

    • Improved the "Keywords by Context" analysis with a new filtering option on specific words, allowing you to filter out those words that are over-represented in the context or class.

Bug fixes:

  • Minor bug fixes.

Sphinx iQ3 v 8.11.2

[16/04/2025]

New feature:

  • New functionality allowing users to automatically generate questionnaires using AI in just a few clicks. The questionnaire generation comes with examples and is fully customizable. Users can adjust or regenerate the AI-generated content as they wish. To access this feature, an internet connection and an online account login via iQ3 are required.

Improvement:

  • Enhanced copy/paste functionality for questions, now allowing the inclusion of configuration hints (e.g. adding instructions, marking questions as mandatory, defining variable names and types). This saves time by configuring the questionnaire before it is finalized.

What's new in Dataviv'?

  • AI

    • New feature enabling interpretation of analysis results using the AI assistant.

    • Easy coding support (codebook creation and verbatim labeling) using the AI assistant.

  • Custom Tables

    • Improved custom tables by allowing dynamic behavior to be configured on both columns and rows. A new column or row is created each time a new value is added to a variable identified as dynamic.

Bug fixes:

  • Study creation via external data import fails in certain cases.

  • Smartphone form generation incorrectly handles left and right margins.

  • In smartphone-specific layouts, navigation buttons appear above the footer.

  • The "Automatically generate expressions" option does not work as expected.

  • Results do not appear in custom tables when using a dynamic date variable with monthly grouping.

  • Word export encounters issues when the form includes a "Commune" type question.

  • When importing a view, dashboard filters are not transferred.

  • Minor bug fixes.
