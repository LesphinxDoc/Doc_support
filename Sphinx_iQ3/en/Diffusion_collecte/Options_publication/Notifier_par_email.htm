NOTIFy by EMAIL

The Notify by email function allows you to set up an automatic email to be sent when the respondent registers their response to the survey.

It is possible to define several emails that can be sent or not depending on a response or a profile.

EXAMPLE: A service company sends a satisfaction survey to customers once the service is over. To respond more quickly in case of poor notes detected (in order to recall the customer to understand and find a solution), the administrator wants to receive an email each time a customer gives a score below 6 in the survey.

To set up an email notification, proceed as follows:

  1. From the Questionnaire design environment, Distribution tab, click on Notify by email.

  2. Check the Enable notifications box.

  3. Click on button to create a new email.

  4. Fill in the name and the sender's email, the receiver's email, the copy mails and the subject.

    WARNING: Following changes to the sending of mailings:
    If you have not validated your own sending domain or you are using an unconfirmed sender address,
    e-mail notifications are now sent with a sender address of the form :
    no-reply.servername.AccountName@sphinxonline.com
    This address replaces the one you defined in the "From:" field in the email notification.
    Note that it is still necessary to fill in an email address in the "From" field for the notification to quit.
    -If you have defined several recipient addresses (separated by semicolons) these people will no longer see the other recipients.
    -The addresses defined in the "To:" and "cc:" fields will receive the notification as the only Recipient of the message.

    NOTE: It is possible to use merge fields (e.g. Email variable to be recalled in the To field, to automatically send an email to the respondent following his answer. The name of the variable containing the respondent's email must be recalled between [ ].

  5. Write the email content to be sent.

    It is possible to customize the message with information from the survey by using the merge fields.

    EXAMPLE: We retrieve the name, email the phone number so that the administrator can immediately contact the customer without having to search the database.

  6. Set a sending profile (if necessary) to send the email only to a certain target.

    EXAMPLE: We are trying to send mail only if the client has given a response of less than 6 (variable NOTE).

    To do so:

    1. Check the Send if option.

    2. Click Modify....

    3. Choose the profile to be used.

  7. Check the box One sending per respondent if you need to send the notification only once.

  8. Click on OK to validate.
