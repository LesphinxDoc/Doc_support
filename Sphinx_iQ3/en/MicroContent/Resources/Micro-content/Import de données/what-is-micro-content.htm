CREATE A STUDY BY IMPORT DATA

Tab-delimited files (.xlsx, .csv, .txt)

To import a data table in .xlsx or .csv / .txt format, proceed as follows:

  1. From the Home screen, click on Create a Study.

  2. Click on TAB-DELIMITED FILES.

    NOTE: Make sure the contents of your file are in raw format (i.e. without cell formatting) to avoid possible import issues.

  3. Select the file to import.

    NOTE: In the case of an Excel file, you have to select the sheet to use.

  4. Click on Next.

  5. Proceed to the configuration of the import parameters;

    • Determine the number of lines to ignore at the beginning and at the end.

    • Indicate that the 1st row contains the variable names.

    • Indicate that the 2nd line contains the variable labels.

    • Determine the blank rows to ignore (at the beginning, inside or at the end).

    • Determine the characters to be used to replace the non-responses.

    • Determine the separator to use to identify multiple questions (by default it is the semicolon).

  6. Click on Next.

  7. (Optional) Change the type and name of the variables if necessary.

  8. Click on Next.

  9. In case of possible errors or inconsistencies detected, identify them in order to correct them either by directly modifying your file or:

    By selecting the Automatically rectify data option.

    By selecting the option Put data in unanswered.

  10. Click on Finish to finalize the data import operation.

Statistical study (SPSS, Triple-S)

To import data from a Spss or Triple-S study, do the following

  1. From the Home screen, click on Create Study.

  2. Click on STATISTICAL STUDY.

  3. Click on Browse to select the file to import.

  4. Click on Next.

  5. Click on Finish to validate the import.

Web data (Google search engine, Google scholar)

To import data from a Google/ Google scholar search engine, proceed as follows:

  1. From the Home screen, click on Create Study.

  2. Click on Web data & social networks.

  3. Indicate the subject of your search in the Subject field.

  4. Check the search engines to be used : Google and Google scholar.

  5. Set the maximum number of responses per source queried and per language.

    For Google scholar, it is possible to define parameters to refine the search.

    • Responses containing (All words, the exact expression, at least one of the words, None of the words).

    • Only responses published before, after or between X dates.

    • Download document contents.

  6. Select the languages to be used.

  7. Click on Next.

  8. Click on Finish to validate the import.
