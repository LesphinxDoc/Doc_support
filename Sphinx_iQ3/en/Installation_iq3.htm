Authorization requirements

User access rights

Our software, Sphinx iQ3 and SphinxScan, require the following access rights:

  • Read access to the %PROGRAMDATA%\Le Sphinx Développement directory (and its sub-directories).

  • Full control over the following directories:

    • %APPDATA%\Le Sphinx Développement (and its sub-directories).

    • %LOCALAPPDATA%\Le_Sphinx_Développement (and its sub-directories).

    • Software installation directory (and its sub-directories).

  • Read rights on the registry.

It is possible that the license key may become temporarily inaccessible due to a system-related problem, for example, if the access rights of the user running Sphinx iQ3 or SphinxScan are changed for any of the following:
- Sphinx entries in the registry
- Sphinx files stored in the installation directory
- %APPDATA% et/ou %PROGRAMDATA% directories

To install or modify the Sphinx iQ3 and SphinxScan license, you need write access to the %PROGRAMDATA%\Sphinx Développement directory (and its sub-directories) and registry modification rights.

Exchanges between Sphinx iQ3 and the SphinxOnline server

The Sphinx iQ3 software must be able to communicate with the SphinxOnline server in order to:

  • Determine whether it has the right to run if the license used is of the floating type,

  • Display news and check the availability of a new version,

  • Test the survey (by clicking on the "Test" button), a publication is made on the SphinxOnline server with the structure of the survey (without the data).

To do this, you need to authorize flows on:

  • 217.182.188.204: www.sphinxonline.com

  • 217.182.188.203: www.sphinxonline.net

Publishing a Sphinx iQ3 survey

Publishing a survey from Sphinx iQ3 on a server requires opening the HTTPS flow between the Sphinx iQ3 software and the publication server used.

This publication server can be the main SphinxOnline shared server (www.sphinxonline.com) or any other shared server (or a dedicated server or a connect server).

Please note that when a survey is published, a password-protected, encrypted ZIP archive is also uploaded online (which potentially contains the survey data).

Analysis module (DATAVIV)

Using the analysis module of the Sphinx iQ3 software involves client/server network exchanges entirely locally on the machine running it:

Sphinx iQ3 is made up of several application bricks which exchange data via 3 different network protocols:

  • Net.tcp for the Dataserver,

  • Http for the export service and access to the analysis module,

  • Websocket for the analysis view export service.

    These exchanges are always made using the host name "localhost".

Each application brick uses a listening port determined dynamically when the software is launched from the available TCP ports between 1024 and 65535.

Please ensure that your anti-virus/firewall software solution, often installed on the machine running Sphinx iQ3, does not block any of these local network flows for Sphinx iQ3 to be fully functional.

Single-user license installation

A single-user license is associated with a key that allows individual installation of the software.

You can have a single-user license for a defined number of users (number of possible activations).

To install a single-user license, proceed as follows:

  1. Download the installation file of the « SetupSphinxiQ3.exe » software.

  2. Open the file explorer.

  3. Display the contents of the download folder *.

    * the directory where the downloaded files are stored is defined in the Internet browser.

  4. Double-click on the « SetupSphinxiQ3.exe » icon.

    NOTE: You have to be in administrator mode to install and activate the software.

  5. Click on Next.

  6. (Optional) Choose the installation directory of the software files by clicking on the Modify button.

    NOTE: We recommend you keep the default directory: C:\Program Files\SphinxiQ3.

  7. Click on Next.

  8. Click on Install,

    A message confirms that the installation was completed successfully.

  9. Click on Finish.

Key activation

The first time you open Sphinx iQ3, it will run in demo mode. To access the full version, you will need to enter your installation key. To activate your license key, proceed as follows:

  1. Launch your software in administrator mode.

  2. Select the option You have an installation key.

  3. Enter the installation key that was sent to you by email.

  4. Click on Next.

    • If an Internet connection is detected, activation is performed automatically.

    • In case of absence of internet connection (no internet access, network problem or other), a window indicating that the software has not been activated appears:

      If the Internet connection is not possible:

    1. Select the option Activate by phone,

    2. Note the C1 and C2 codes and provide them, together with your customer code, by phone at 04 50 69 82 98 or by email at contact@lesphinx.eu

    NOTE: This activation is mandatory. As long as it is not done, your software will run in Demonstration mode.

    If you encounter a problem during the installation, note the error number and contact us at: 04 50 69 82 98.

Update Sphinx iQ3

If you have a maintenance contract, perform minor updates of your software by clicking on the Search for updates button from the home panel.

NOTE: You must first launch your software in administrator mode to carry out the update.

The search for updates is performed directly when you open Sphinx iQ3, provided you have Internet access.

Uninstall or move a single-user license

Move a single user license:

The Sphinx user license is installed on computer A, we want to move it to computer B. To move a license, proceed as follows:

  1. Check that you are in possession of your installation key.

  2. Open your software on the first computer.

  3. Click on license from the home panel.

  4. Select "You want to deactivate the license".

    NOTE: Please ensure that your computer is connected to the internet before deactivating the license.

  5. Click on Next,

  6. Activate your license on the second computer (see procedure above).

Uninstall the software on a desktop:

To uninstall the Sphinx iQ3 software on a desktop, proceed as follows:

  1. From the Windows Control Panel, click on Uninstall a program.

  2. Select the Sphinx iQ3 software from the list of programs.

  3. Click on Yes in the dialog that appears.

    The installation key is deactivated automatically when the software is uninstalled. It is therefore necessary to have an active internet connection at this time.

    NOTE: Uninstalling the software does not affect your survey files.
    Removing Sphinx iQ3 from a workstation does not delete any associated working files (survey files, databases, exports, etc.).
    These files remain on the local drive unless manually deleted by the user. We recommend backing them up regularly, especially if you plan to reinstall the software or switch workstations.
