DATA management

Data management provides a detailed overview of the data and possibly add or modify, delete, transform them. It is divided into four sections:

  • The spreadsheet tabulates the responses made by the respondents.

  • Data qualification allows us to identify unusual observations and possibly modify certain data (non-responses, poorly documented observations, etc.) in order to establish the overall quality of the data set.

  • Data adjustment consists of defining weights for each respondent according to the category to which they belong,

  • Data preparation allows for the transformation and combination of variables, or the creation of new variables based on personalized calculations. It is also possible to proceed with mergers, imports, etc.

The spreadsheet returns the data filled in by the respondents in the form of a table with n rows and m columns in which "n" corresponds to the number of observations and "m" to the number of variables in the study. Its usefulness is demonstrated in the data management phase to visualize, verify, transform, export data, and prepare them for analysis.

How to access it?

  1. From the home panel, click on the Data Management stage.

  2. Then on Spreadsheet.

ENVIRONMENT

The environment is made of:

  1. A central work area, in which a column corresponds to a variable of the survey. For each variable, it is possible to perform the following operations:

  2. A horizontal ribbon (banner) with four tabs (Home, Data, Texts, and Display).

  3. A lateral explorer with three parts (Variables, Filters, Languages).

    • The Variables section of the explorer lists the variables of the study so that they can be displayed or hidden in the central work area,

    • The Filters section allows you to create and select a sample to display observations on a given profile,

      EXAMPLE: For a survey distributed in several countries, display only the observations of French respondents, or more simply display only the responses of men.

    • The Languages section allows you to change the language of the data displayed, in the case of a multilingual survey.
