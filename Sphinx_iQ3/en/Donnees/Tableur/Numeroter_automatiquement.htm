AUTOMATICALLY NUMBER THE OBSERVATIONS

Automatically number option allows you to rank your observations. It is possible either to number the observations, by creating a new variable which values will be the numbers of observations, or by « reconstituting » the sections. This second option allows you to separate your observations in x sections.

EXAMPLE:
You have 100 observations, you reconstitute 4 sections, this will create a new variable « Section » which will have for value « Section_1 » for the 25 first observations, « Section_2 » for the 25 following etc., through « Section_4 ».

This option is used especially for the text variables, interview type.

In this case, each observation corresponds to a sentence of the interviewee. However, you may want to compare what was said at the beginning of the speech, in the middle and at the end (for example, by analyzing the most quoted words for each part). Separating the observations by section allows you to do this type of analysis.

To do so:

  1. From the Data tab, click on Preparation.

  2. Click on Automatically number.

  3. Select the option to use for numbering:

    • Automatically number to create a variable that will contain for each observation its unique number.

    • Reconstitute to separate your observations into sections. All sections will contain approximately the same number of observations (within one observation).

    You can create your sections for all the observations or for each value of a variable, for example on a text variable in the case of an analysis of an interview.

  4. Click on Next.

  5. Choose at which position you want the created variable to appear.

    • Create the variable in the beginning of the questionnaire.

    • Create the variable at the end of the questionnaire.

  6. Click on Finish to validate and quit the assistant.
