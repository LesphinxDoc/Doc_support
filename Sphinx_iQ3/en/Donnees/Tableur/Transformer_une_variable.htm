TRANSFORM a VARIABLE

The variable transformation offers several possibilities: manage the modalities of a closed question, create classes to categorize numerical questions, group codes or dates, extract information from text questions, or change the type of the variable. To do this:

  1. From the Data tab, click on the Transform button.

  2. Select the variable you need to transform.

  3. Choose the transformation type you need to do.

    CHANGE THE TYPE

    This option allows you to change the type of a variable, for example change a text question to a single closed question.

    NOTE: The Change the type transformation is possible for all types variables.

    1. Choose the new type you want to assign to the variable.

    2. (Optional) Check the See advanced options checkbox to access the settings for the selected question type.

    3. Choose if you would like to modify the chosen variable by recoding it (the initial variable will be lost) or if you would like to create a new variable.

      In the case of a new variable creation:

      • Fill in at least the name of this variable (and possibly a label).

      • Choose the location where the new variable will be inserted (after the selected variable, at the end of the questionnaire...).

    4. Click on Finish.

    MANAGE MODALITIES

    This option allows you to rename, add, sort, group, or delete terms of a variable, create a variable for each term, or extract information on multiple response variables.

    NOTE: The Manage modalities transformation is only possible for scale and closed variables (single and multiple).

    Regroup, add, rename, delete and sort modalities

    To group, add, rename, delete and sort terms, follow these steps:

    1. Select the option Regroup, rename, delete, sort the modalities.

      • To regroup, select the modalities you are interested in and click on the Regroup button.

        EXAMPLE: We intend to regroup the modalities "Quite satisfied" and "Completely satisfied" in a category that we will call "Satisfied clients" and the modalities "Dissatisfied" and "Completely insatisfied" in the category "Insatisfied clients".

      • To add a new modality, click on the New button.

      • To rename a modality, select it and click on the Rename button.

      • To delete a modality, select it and click on the Delete button.

      • To sort the modalities, select them and then use the Move Up and Move Down buttons.

    2. Click on Next after modification.

    3. Enter the name of this variable (and possibly a label).

    4. Choose the location where the new variable will be inserted (after the selected variable, at the end of the questionnaire...).

    5. Click on Finish to validate and quit the assistant.

    Create a variable for each of the modalities

    This assistant allows you to create a single closed variable for each of the modalities of the selected variable. To do so:

    1. Select the option Create a variable for each of the modalities,

    2. select the type to be used, two possibilities are offered to you:

      • The modalities "Yes" and "No" :The new variables created will contain the "Yes" or "No" modalities for each of the modalities selected on the original variable.

        EXAMPLE: If, for example, on your original variable, you propose two modalities, for example "Always" and "Never", and the respondent selects "Always". The two new variables that will be created in your dataset will be "Always" which will have the value "Yes", and "Never" which will have the value "No".

      • A single modality with the name of the original modality : The new variables created will contain, depending on the modalities chosen on the original variable, either the name of the chosen modality or a non-response.

        EXAMPLE: if on your original variable, you propose two modalities, for example "Always" and "Never" and the respondent selects "Always". The two new variables that will be created in your dataset will be "Always" which will have the value "Always", and "Never" which will be non-response (empty field).

    Create a variable containing the number of actual responses

    From this assistant, you can create a numerical variable that contains the number of actual responses for the chosen initial variable.

    EXAMPLE: if for a question the respondent can make a maximum of three choices, this new variable created will take as value 0, 1, 2 or 3 depending on the number of choices made by the respondent.

    To do so:

    1. Select the option Create a variable containing the number of actual responses.

    2. Select the value to assign in case of an empty response: set to "Non-response" (empty cell) or assign the numerical value 0.

      NOTE: it is not possible to recode the existing variable, you have to create a new variable.

    3. choose where you want to integrate this variable (after the initial variable or at the end of the questionnaire).

    4. click on Finish to validate and quit the assistant.

    Create a variable from combinations of its modalities

    To do so:

    1. Select the option Create a variable from combinations of its modalities,

    2. Select the assessment to be performed;

      • Create all combinations of modalities,

      • Find the x best combinations of x modalities,

      • Evaluate a combination of modalities,

      EXAMPLE:
      In the case that the respondent selected " House " and " Restaurant " to a question asking them where they are most likely to drink, the variable created will contain, for that observation, the " House_Restaurant " modality.

    3. Click on Next.

      NOTE: it is not possible to recode the existing variable, you have to create a new variable.

    4. Choose where you want to integrate this variable (after the initial variable or at the end of the questionnaire).

    5. Click on Finish to validate and quit the assistant.

    Create a variable for each rank

    This assistant allows you to create as many new variables as the initial variable has ranks (If the variable has two ranks, two variables will be created). Each variable will contain all the modalities of the original variable and will take for value the modality of the concerned rank.

    EXAMPLE: If for a question the respondent selects " House " first and " Restaurant " second, the assistant will create two variables which will have for modality respectively " House " and " Restaurant ").

    To do so:

    1. Select the option Create a variable for each rang.

    2. Click on Next.

    3. Click on Finish to validate and quit the assistant.

    GROUP NUMBERS INTO CLASSES

    This assistant allows you to assign each observation to a class, which you will define, the goal being to be able to use these classes of observations for the analyses.

    NOTE: The transformation Group numbers into classes is possible for variables of numerical open type.

    EXAMPLE: We need to create age classes for the variable Age (numeric). We will create the classes less than 30 years old, From 30 to 39 years old, From 40 to 49 years old and 50 years old and over.

    You can group numbers into classes in two ways:

    • Either you define the limits of the classes by hand (custom class limits).

    • Or you can use another method allowing a repartition of the observations in the classes, according to a fixed number of classes.

    Define the limits of classes

    To do so:

    1. Select the option Define the limits des classes.

    2. Define the class limits by separating them with « ; ».

    3. Click on Next.

    4. (Optional) You can change the label of the classes, created by default, by clicking on .

      EXAMPLE: We can decide to name those under 18: "Minors", those between 18 and 25: "Active youth" etc...

    5. Click on Next.

    6. Then choose if you want to modify the chosen variable by recoding it (you will lose the initial variable) or if you want to create a new variable.

      In the case of the creation of a new variable :

      • Fill in at least the name of this variable (and possibly a label).

      • Choose the place where the new variable will be inserted (after the selected variable, at the end of the questionnaire...).

    7. Click on Finish to validate and quit the assistant.

    Use a class definition method

    To do so:

    1. Select the option Use the method.

    2. Choose the definition method to use:

      • Same amplitude : the gap between the classes created will be constant.

        EXAMPLE: in our case we will get the classes 20-29, 30-39, 40-49 etc...

      • Same value : will create as many classes as there are different values of the selected variable.

        EXAMPLE: in our example, we have chosen the variable Age, if we have three observations whose values of this variable are respectively 21, 21 and 42, the method will create two classes: class 21, which will group two observations, and class 42 with one observation.

      • Around the mean : allows you to create your choice of 3, 5, or 7 classes of intervals, each interval having a "length" of ½, 1, or 2 times the standard deviation. The median class will be the interval containing the mean

        EXAMPLE: your dataset has for the variable "Age" the values 12, 18, 20, 30, 40. We obtain a mean of 25 and a standard deviation of 10.18. You want to create five classes around the mean of 1 standard deviation (10.18). Here are the classes that will be created:

      • Same frequency : will create classes so that they contain approximately the same number of observations (balanced observation distribution).

    3. Click on Next.

    4. (Optional) You can change the label of the classes, created by default, by clicking on .

      EXAMPLE: We can decide to name those under 18: "Minors", those between 18 and 25: "Active youth" etc...

    5. Click on Next.

    6. Then choose if you want to modify the chosen variable by recoding it (you will lose the initial variable) or if you want to create a new variable.

      In the case of the creation of a new variable :

      • fill in at least the name of this variable (and possibly a label),

      • choose the place where the new variable will be inserted (after the selected variable, at the end of the questionnaire...),

    7. Click on Finish to validate and quit the assistant.

    GROUP CODES

    NOTE: Reminder: The Group codes transformation is possible for variables of type code (for example, postal code).

    To do so:

    1. Select the grouping method to use;

      • Regroup with a dictionary : this method allows you to use a dictionary (.txt file) to group your codes.

        EXAMPLE: In our case we need to group the codes by department in order to perform statistics by department (or by region, etc.) during the analyses.

      • Grouped in a customized manner : this method allows you to manually group your codes by creating the appropriate group names.

        EXAMPLE: Select 73 and 74 and create the group " Land of Savoy ".

    2. (Optional) You can reduce the code to a certain number of characters.

      EXAMPLE: If you check this option and enter (1;2), the codes will appear as 73 and 74, whereas if you enter (1;2;3;4;5) or leave the field empty, the codes will appear as 73000, 74000 etc,

    3. Click on Next.

    4. Then choose if you need to modify the chosen variable by recoding it (you will lose the initial variable) or if you need to create a new variable.

      In the case of the new variable creation :

      • fill in at least the name of this variable (and possibly a label),

      • choose the location where the new variable will be inserted (after the selected variable, at the end of the questionnaire...),

    5. Click on Finish to validate and quit the assistant.

    GROUP DATES

    This assistant allows you to group dates by category/class.

    NOTE: The transformation Group dates is possible for variables of type date.

    EXAMPLE: We would like to group all our dates by year.

    To group dates:

    1. Select the grouping method to use:

      • Grouped into pre-defined periods, of type month/year, in quarter, in semester etc.

      • Grouped into customized periods, to be entered by hand, type DD.MM.YYYY.

        EXAMPLE: « 01.02.2003 ; 01.02.2004 ; 01.02.2005 » will create four periods, before 01.02.2003; between 01.02.2003 and 01.02.2004; between 01.02.2004 and 01.02.2005 and finally after 01.02.2005.

    2. Click on Next.

    3. Choose if you need to modify the chosen variable by recoding it (you will lose the initial variable) or if you need to create a new variable.

      In the case of the new variable creation :

      • Fill in at least the name of this variable (and possibly a label),

      • Choose the location where the new variable will be inserted (after the selected variable, at the end of the questionnaire...),

    4. Click on Finish to validate and quit the assistant.

    EXTRACT INFORMATION from TEXTS

    To do so:

    1. Choose the type of variable you would like to create: lexical, lemmatized, analysis via a thematic dictionary.

    NOTE: The Extract information from texts transformation is possible for text variables.

    Lexical variable

    You can generate different types of variables that will have as possible modalities the chosen words, to do this :

    1. Choose the words to consider:

      • All words,

      • A set of words (to separate by « ; »),

      EXAMPLE: we choose to consider the three words we know are most often cited (health, life, and well-being) in the "comments" question that asks respondents to name the words that come to mind when they see the video wall.

    2. Define the lexical measures to be used,

      These will create variables to analyze the content of your text variable.

      • the length corresponds to the number of words of the answer (if an answer is "life is beautiful", the length will be 4, if we take into account the tool words),

      • the richness is the number of different words in an answer,

      • the banality is an average of the frequency of words in a response (the more frequent the words, the stronger the banality),

      • finally intensity gives the "presence rate" of the chosen words, (in our case health, life and well-being) in a response,

        EXAMPLE: if an answer is "Life" the word "life" intensity will be 50%, because the answer contains two words including "Life" (if we take into account the tool words).

    3. Click on Next,

    4. Select the insertion location for the new variables,

    5. Click on Finish.

    Lemmatized variable

    This assistant allows you to create:

    • Text variables whose contents will be the texts of the selected variables in their lemmatized form (infinitive, masculine, singular),

      EXAMPLE: « she drinks» becomes «she drink».

    • Several text variables for each grammatical category of the selected variable (verbs, nouns, adjectives)

      EXAMPLE: «I drink water», a Verb variable will be created containing the value « drink » and a Noun variable containing the value « water ».

    To do so:

    1. Select the elements to generate (lemmatized text, grammatical categories),

    2. Click on Next,

    3. Select the insertion location of the new variables,

    4. Click on Finish.

    Analyzed thematic

    Thematic analysis creates variables that identify the main themes of each observation.

    To do so:

    1. Load the dictionaries to be used by clicking on the Choose dictionaries button,

    2. Choose the variables to create:

      • Ranked closed variable on the themes present,

      • Closed multiple variables on key words from each theme,

    3. Click on Next,

    4. Select the insertion location of the new variables,

    5. Click on Finish.

    NOTE: Note that only the possible transformations on the chosen variable will be selectable, the others will appear grayed.
