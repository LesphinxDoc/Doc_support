ADJUST / DEFINE QUOTAS

Despite all the efforts made to select the individuals, during the e-mailing phases for example, it is possible that a sample is "biased", i.e. that its composition is not satisfying, because it does not correspond to the representativeness criteria that we had previously defined.

EXAMPLE:
We thought we would reach 60% women and 40% men and this is not the case. The sample needs to be "adjusted".

To set up this operation, proceed as follows:

  1. On the Data tab of the spreadsheet, click on the Adjust button.

  2. Click on Add to select the variable on which you wish to adjust the sample from the Simple Quota menu.

    If you wish to cross-quota, select the Cross-quota option, then select your variables.

  3. Click OK.

  4. Indicate the percentage you would like to obtain for each modality.

    EXAMPLE:
    In our example, we have now 17% of French respondents as our objective is to have 20% of the probed French people. The same for the other nationalities. As the goal is to make the sample representative of the population surveyed on this criterion.

    NOTE: By default, non-responses are ignored. If you wish to take them into account, click on Options... then uncheck the Ignore non-responses box.
    Non-responses will be displayed in addition to the other modalities of your quota variable.

    If you wish to fix the adjusted headcount, simply check the Fix adjusted frequency option and define the headcount.

  5. Select the calculation method to be used:

    • The Weighting adjustment method allows you to assign a weight to each observation.

      EXAMPLE:
      If your sample does not contain enough French respondents, each observation that contains the value France for the country of origin variable will be assigned a weight greater than 1. On the other hand, since we have 33% Spanish respondents, observations that contain the value Spain for the country of origin variable will be assigned a weight less than 1.

    • The Extract a sample method consists in extracting a sample which allows to assign to the new variable Adjustment the modalities 1 or 0, (1 corresponding to the observations retained to represent the sample).

  6. Click on Finish.

A new variable "Adjustment" will be created (this variable can be used as a profile in the dashboards): you will be able to view the dashboards on the new sample created representative, by adjustment, of the population studied.

Quota calculation method

On the basis of the variables to be adjusted, we start with the distribution of individuals on each response modality (or cross-tabulation of modalities) and attempt to "calibrate" the sample iteratively.

The target number to be obtained is indicated next to the gross number of individuals for each modality.

The software program begins by finding the coefficient to be applied to each category in order to reach the target distribution. It then assigns to each individual, according to his responses to each of the adjustment variables, a combination of the coefficients found for the modalities that concern him. This operation is repeated on the distribution obtained, until the target number of all modalities is reached.

A loop is performed (maximum 100 times) until the stopping criterion (coefficient of difference between the desired value and the current value) is reached.

Between 1 and 10 loops: stop if coeff <= 1.001, between 10 and 100 loops: stop if coeff <= 1.01
