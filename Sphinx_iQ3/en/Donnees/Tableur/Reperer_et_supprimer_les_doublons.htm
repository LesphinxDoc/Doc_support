IDENTIFY AND DELETE DUPLICATES

It can sometimes be useful to identify duplicates, or even to delete them. Duplicates can be present in several cases:

EXAMPLE:
A person has answered twice to the questionnaire (once by post and once online).
A fusion with another data base which has been realized and duplicates appear.
When we have a customer targeting file for an emailing, it can happen that we have several times the same email address for different people (husband and wife can have a common email address). We therefore have two contacts (Mr. and Mrs.) and we only want to send one mailing per household. In this case, you need to identify the duplicates on the email address and delete one of the two contacts (Mr or Mrs).

Identifying duplicates creates a variable called POSITION that allows the observations to be categorized.

It has four possible values: Single to indicate observations that are not duplicates, Mini, Maxi and possibly Inter to indicate observations that have duplicates.

The observations are deleted by eliminating the first or last answers according to the user's choice.

In all cases, duplicates are identified by means of one or more observation identification variables (identifier, key, email address, client code, etc.).

To identify or delete duplicates, proceed as follows:

  1. In the Data tab, click on the Remove duplicates button.

  2. Select the action to use: Identify duplicates or Delete duplicates.

IDENTIFY DUPLICATES

  1. Select the variable(s) which responses are potentially affected by duplicates.

    NOTE: It is recommended to identify the duplicates variable by variable, and to repeat this manipulation as many times as necessary.

  2. Set the order in which the observations will be displayed when identifying duplicates.

    it is possible to sort them according to their order of saving, or according to the value of a selected variable.

    If you have chosen to determine the position of the duplicates with respect to the order of saving the observations , an IDEM variable will be created, in which the number of the first identical observation with respect to the selected variable will appear.

    A second variable POSITION will tell you the "status" of each observation. This variable has four possible modalities:

    • Single : means that the observation has no duplicates.

    • Mini : means that the observation is the first observation of a list of duplicates.

    • Inter : the observation is an intermediate duplicate of the list of duplicates.

    • Maxi : the observation is the last observation of a list of duplicates,

    NOTE: Note that you can list the duplicates either by the order in which the observations were saved (for three duplicates, the observation containing the MINI modality will therefore be the one that was saved first) or by the value of a variable to select, for example the variable CLE, so the duplicates will be classified according to the value of this variable.

  3. Click on OK to validate your choice and display the result in the central area.

DELETE DUPLICATES

  1. Select the variable which responses are affected by duplicates and that you want to delete.

    NOTE: It is recommended to delete the duplicates variable by variable, and to repeat this manipulation as many times as necessary.

  2. Determine whether you want to keep the first or the last answer.

    • In the case of two duplicates, it is possible to either keep the first response (Mini) or the last (Maxi) when deleting the duplicates. When you click OK, it will generate a new survey file so as not to overwrite your current data.

    • If there are three or more duplicates (e.g., the same email is in the database three times), then it is necessary to delete all observations listed as "Inter" and delete the "MinI" or "Maxi" observation.

  3. Click on OK to validate your choice.
