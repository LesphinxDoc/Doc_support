SETTING A PREDEFINED CALCULATION

Calculate a variable

Setting up a predefined calculation consists of using the functions offered by Sphinx iQ3 to calculate and create a new variable (mean, standard deviation, etc.). To use this function, proceed as follows:

  1. In the Data tab, click on the Calculate button.

  2. Click on Calculate a new variable.

  3. Choose a calculation function to perform.

  4. Select the variables where you need to calculate the value mean.

    EXAMPLE:
    We are going to calculate the mean of the values of 4 variables. We would like to obtain the mean expenditure (accommodation, alimentation, restaurant and leisure).

    This screen shows you the calculated value of the mean expenditure for each observation.

  5. Set the name and the label of the new variable that will be created,

  6. Choose where you want to insert this variable in the central work area ( at the beginning, at the end, before the variable).

Learn more about the different calculation formulas.

Recalculate a variable

If since your last calculation, there have been new answers to your questionnaire, you have to redo all the calculations, to do so:

  1. In the Data tab, click on the  Recalculate button.

  2. Click on Yes.

    All variables already calculated will be automatically updated.
