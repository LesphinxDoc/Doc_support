Abs: Calculation of the absolute value of a variable

Description:

Returns for each observation, the absolute value of the indicated variable.

Syntax:

Abs(number)

EXAMPLE:
To obtain the absolute value of the variable "mark" bearing the number 1, write:
Abs (mark) or Abs (V1)

Variable type

Value taken into account

Observation value

Closed scale

Round: Returns the value of a rounded number

Description:

Returns the value of a number rounded to the nearest integer / to the specified number of fractional digits.

Syntax:

Round(number, decimals)

EXAMPLE:
To obtain the value of the variable « note » rounded to 3 digits after the decimal point, write

Rnd: Calculation of a random number

Description:

Returns for each observation, a random number.

Syntax:

Rnd()
Rnd(inf, sup)

EXAMPLE:
To get a random number in the interval ] 0,1 [, write:
Rnd()
To obtain a random integer number in the interval [1,10], write:
Rnd(1,10)

NOTE: The random value will be automatically recalculated when saving the answer or when it is used elsewhere (on another page) in the calculation of another variable etc... To block the calculation of the random value, simply indicate in the formula that the calculation should only be performed if this variable is non-response.
Example:
If V1. estnonreponse then
V= Rnd(1,10)
End

Use case:

  • Test data collection protocols: we want to compare the quality of responses collected with two different forms: the first includes images and the second includes videos for example. We send randomly one of the two forms to respondents using Rnd function. We then compare the results of both sub-samples.

  • Evaluation of a series of products: to collect the opinion of respondents about three different products, we produce a three-page form, each shows the product image and the questions related to it. To neutralize the anchoring effect due to the presentation order, the pages are returned in random order.

– : Subtraction

Description:

Returns for each observation, the subtraction of two numbers (or the negative value of a numerical expression).

Syntax:

Number1 - Number2

EXAMPLE:
To obtain the difference between the variable TotalExpenditure and AccommodationExpenditure , write:
TotalExpenditure -AccommodationExpenditure

* : Multiplication

Description:

Returns the multiplication of ‘number1’ by ‘number2’.

Syntax:

Number1 * Number2

EXAMPLE:
To obtain the product of the variables RestaurantBudget and NumberClient, write:
RestaurantBudget * NumberClient

/ : Division

Description:

Returns the division of 'number 1' by 'number 2'.

Syntax:

Number1 / Number2

EXAMPLE:
To obtain the ratio between the variables RestaurantBudget and GlobalBudget , write:
RestaurantBudget / GlobalBudget

\ : Integer division

Description:

Returns the integer division of 'number 1' by 'number 2'.

Syntax:

Number1 \ Number2

EXAMPLE:
To obtain the integer part of the ratio between the variables RestaurantBudget and GlobalBudget , write:
RestaurantBudget \ GlobalBudget

^ : Exponent

Description:

Returns the raising to the power of 'number' by 'exponent ' .

Syntax:

Number ^ exponent

EXAMPLE:
To obtain the squaring of the variable expenditure, write:
expenditure^2

+ : Addition

Description:

Returns the addition of 'number 1' and 'number 2'.

Syntax:

Number1 + Number2

EXAMPLE:
To obtain the sum of the variables AccommodationExpenditure and RestaurantExpenditure, write:
AccommodationExpenditure + RestaurantExpenditure

Mod: Remainder of division

Description:

Returns the remainder of the integer division of 'number 1' by 'number2'.

Syntax:

Number1 Mod Number2

To obtain the remainder of the division of AccommodationExpenditure and GlobalExpenditure

AccommodationExpenditure Mod GlobalExpenditure
