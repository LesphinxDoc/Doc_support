LOGICAL OPERATORS

And: Verifying the conjunction of two expressions

Description:

Returns the logical conjunction of 'expression 1' and 'expression 2'.

Syntax:

Expression1 And Expression2

EXAMPLE:
To verify in each observation, the presence of "Renault" in the variable "Brand" and "Airbags" in the variable "Options", write:
(Brand In "Renault") And (Options In "Airbags")

The formula returns 1 if the combination is verified and the value 0 in the opposite case.

Not: Verifying the negation of an expression

Description:

Returns the logical negation of an expression.

Syntax:

Not (Expression)

EXAMPLE: To check for each observation that "Renault" is not an answer to the variable "Brand" write:
Not (Brand In "Renault")

The formula returns the value 1 if the negation is verified and the value 0 in the opposite case.

False: Verifying whether an expression is false

Description:

Verifies whether the indicated expression is false.

Can be used as a Boolean constant (equal to 0)

Syntax:

Expression1 = False

EXAMPLE:
To verify whether the expression "Brand In Renault" is false, write:
(Brand In "Renault") = False
The equivalent of NOT (Brand In "Renault")

The formula returns the value 1 if the brand is different from Renault and 0 in the opposite case.

NonResponse: Verifying the value NonResponse for a variable

Description:

Numerical value to NonResponse.

Syntax:

NonResponse

EXAMPLE:
To verify whether a variable (V1) is at NonResponse, write :
If V1 = NonResponse Then …
The equivalent of
If V1.EstNonReponse Then …
