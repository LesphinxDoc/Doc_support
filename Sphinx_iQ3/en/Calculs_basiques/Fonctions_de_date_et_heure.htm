DATE AND TIME FUNCTIONS

Age: Calculating the time between two dates

Description:

Returns for each observation, the time between two dates. This is expressed in the desired unit (month, day or year if the unit is not specified).

Syntax:

Age(variable date1, "unit")
Age(variable date1, variable date2, "unit")
The unit is optional. If it is not set, the result is expressed in years.
The Syntax of the units is as follows:
"aa" or "yy" : integer number of years
"aa.a" or "yy.y" : decimal number of years
"mm" : integer number of months
"mm.m" : decimal number of months
"jj" or "dd" : integer number of days
"jj.j" or "dd.d" : decimal number of days

EXAMPLE:
To obtain the age calculated from the date of today and the variable birth, write:
Age (birth)
To obtain the previous result in years, write:
Age (birth, "yy")
To obtain the seniority of contributor, write:
Age ([date hiring], [starting date])

Authorized variables and values taken into account:

This function applies to dates variables.

AddYears: Adding years to the value of a variable / to a specific date

Description:

Returns the date increased by the number of years specified in the parameter, for each record.

Syntax:

AddYears(date, number)

EXAMPLE:
To add 2 years to the values of the variable birth, please write: AddYears(birth,2)
To add 2 years to a specific date, please write: AddYears("12/04/2022", 2)

Authorized variables and values taken into account:

This function applies to dates variables.

Syntax:

EXAMPLE:

Week: Returning the week number of a date variable

Description:

Returns for each observation, the week of the indicated variable. It is expressed as a number between 1 and 53.

The retention rule for determining the first week of the year is the language of the survey: a survey with French as a reference language considers that the first week starts on the first day of the year.

Syntax:

Week(date)

EXAMPLE:
To obtain the week number of the date variable bearing the number 1, write:
Week (date) or Week (V1)
To obtain the number of the current week, write:
Week (now)
