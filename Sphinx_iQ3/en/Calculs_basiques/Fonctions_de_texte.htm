STRING FUNCTIONS

With: Verification of the presence of a list of words in a text

Description:

Verifies the presence of a list of words or parts of words in the indicated string.

Syntax:

Text with "word1 ; word2 ; word3"

EXAMPLE:
To verify the presence the words "red", "reddish", "blue" in the variable V1, write:
V1 with "red ; blue"

The formula returns 1 if one of the words (or parts of words) is present in the text and the value 0 in the opposite case.

WithList: Verification of the presence of a word in a text

Description:

Verifies for each observation of the text variable, the presence of a word or series of words.

Syntax:

WithList(text, "list of words", ignore)
Ignore is optional. It takes two values:
True to ignore case and accents.
False to consider the breakage and the accents (default).

EXAMPLE:
WithList (DescriptionCar, "red ; blue") returns the value « 1 » if the observation contains the word « red » or « blue », otherwise the value « 0 ».
WithList (DescriptionCar, "mercedes", true) returns the value « 1 » if the observation contains the words « MERCEDES » or « mercedès », otherwise the value « 0 ».

String: Returning a repetition of the indicated character

Description:

Returns a string containing the indicated character, repeated as many times as specified by the length.

Syntax:

EXAMPLE:

Val: Returns the number contained in a text

Description:

Returns the numerical value contained in 'text'.

Syntax:

EXAMPLE:

Like: Comparison of an expression with a text

Description:

Compare the text with the expression specified (breakage insensitive).

Syntax:

Text Like "expression"

EXAMPLE:
To compare the "compact and convenient" expression with the value of the variable V1, write:
V1 Like "compact and convenient"

The formula returns the value 1 if the expression is identical with string and 0 in the opposite case.

Containing: Returning the position of a word or a part of one word in text

Description:

Returns the position of the first occurrence of 'text 22' in 'text1' (breakage insensitive).

Syntax:

text1 Containing text2

EXAMPLE:
To know the position of the extension '.com' in the email variable, write:
mail Containing ".com"

The formula returns the string position when found and 0 in the opposite case.

Description:

Verifies for each observation of the variable text, the presence of a word or expression and returns the position.

Syntax:

InStr([start], text, "succession of words ", ignore)
Start is optional. It indicates the position from which the verification begins.
It is an integer whose default value is 1.
Ignore is optional. It takes two values:
True to ignore case and accents.
False to consider the breakage and the accents (default).

EXAMPLE:
InStr(2, DescriptionCar, "options") returns an integer that indicates the position of the word options, otherwise 0.

FormatDuration: Calculating a time slot

Description:

Returns a string that stands for a time slot while taking into account the unit used and the format to apply.

The parameter "unit" is optional. Its possible values are "d" or "j" for days, "H" or "h" for hours, "m" for minutes, "s" for seconds.

The parameter "format" is optional. By default, the number is converted into a compact string where null values are ignored.

The customized format syntax is that of C# programming language.

Syntax:

FormatDuration(number, [unit], [format])

EXAMPLE:
FormatDuration(24.25) => 24j6h
FormatDuration (24.25, "h") => 1j15min
FormatDuration (24.00, "s") => 24s
FormatDuration (50.00, "h", "dd\ \d\a\y\s\ hh\ \h\o\u\r\s") => 02 days 02 hours

Str: Adding a unit for a number

Description:

Returns a string that represents the 'number' according to the default format (10.60 becomes 10.6) or a specific format (eg:% or €).

Syntax:

Str(number)
Str(number, [Format])
Format is optional. See the summary of the possible formats :
Using Standard Numeric Format Strings
Using Customized Numeric Format Strings

EXAMPLE:
To express the content of the "SatisfactionRate" variable as a percentage, write:
Str(SatisfactionRate, "p")

learn more about the numbers definition

Authorized variables and values taken into account:

The function is applied on numerical and scale variables.

In: Verification of the presence of an expression or a list of expressions in a text

Description:

Returns the result of the comparison of the 'text' with a 'list' (strings separated by semicolons).

The formula returns 1 if one of the chains is present and the value 0 in the opposite case.

Breakage insensitive.

Syntax:

Text In List

EXAMPLE:
To verify the presence of the expressions « compact and convenient »,« Sports car» in the variable opinions (text), write:
opinions In "compact and convenient ; Sports car"
To verify the presence of a response among different modalities of a satisfaction variable (Closed), write:
Satisfaction In "Somewhat satisfied ; Very satisfied "

The formula returns the value 1 if one of the expressions is present and the value 0 in the opposite case.

Replace: Replacing a character string in a text

Description:

Replaces for each observation, the occurrences of the indicated expression by another.

Syntax:

Replace(string, expression1, expression2, ignore)
Ignore is optional. It takes two values:
True to ignore case and accents.
False to consider the breakage and the accents (default).

To replace « red » by « blue » in the text « red with lots of options », write:

Replace(red with lots of options, "red", "blue")

Scinde

Description:

Splits 'string' in a table using 'separator'.

Syntax:

Scinde(string, separator)

&: Returning the concatenation of two texts

Description:

Concatenates, for each observation, the indicated texts.

Syntax:

Text1 & Text2

EXAMPLE:
To concatenate the texts "Peter" and "Martin" by entering a space between the two words, write:
Peter & "  " & Martin
To concatenate the variables 1 and 2 by inserting a "/" between their content, write:
