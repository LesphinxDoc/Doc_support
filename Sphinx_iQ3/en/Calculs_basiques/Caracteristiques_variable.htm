Ranking: Obtain the ranking (calculation of rank) of a modality

Description:

Returns the ranking (the rank calculation) of the value of variable 1 for the formula according to the value of the filter applied to variable 2.

In order for the calculation to be performed, it is imperative that the analysis be filtered on a response mode of variable 2.

NOTE: This calculation only applies to text boxes and custom table cells.

Syntax:

Variable1.Ranking(formula,Variable2)
Variable1.Ranking(formula,Variable2,suffix)
Variable1.Ranking(formula,Variable2,suffix,rounding,exaequo)

  • Variable1 is a numerical variable or scale or NPS,

  • Variable2 is a single closed variable or text.

  • Formula is the requested calculation (Average or Sum or ScoreNps or Count).

  • Suffix (optional) is a string that will precede the result and can contain the keyword {total}, which will be replaced by the total number of valid values used in the calculation of the ranking. The default value is " / {total}".

  • The parameters rounding and exAequo are optional booleans, true by default, allowing you to indicate whether you want the calculations to be performed using rounding and whether you want to display exAequo.

EXAMPLE: To obtain the ranking of an answer option of the variable Agency in relation to the NPS score of the variable Reco, write :
Reco.Ranking(ScoreNps, Agency) and filter on the desired answer option of the variable Agency.

Correlation: Calculation of correlation between two variables

Description:

Calculate the level of association / dependence between the two indicated variables (numerical or scales compulsorily).

The returned result varies between 0 (independence) and 1 (strong association) in absolute value.

Syntax:

Variable1.Correlation("variable2")

EXAMPLE:
To obtain the correlation between the variables "seniority" and "mark" bearing the numbers 1 and 10, write: seniority.Correlation ("mark") or V1.Correlation ("V10")

Variable type

Value taken into account

Numerical

Observation value

Scale

If the variable contains a weight so the value taken into account is the weight associated with the answered modality, if not, the value is the index of the modality.

Frequency: Calculation of the frequency of a variable or a modality

Description:

Returns the frequency of the variable or the indicated modality.

Syntax:

Variable.Frequency
Variable.Frequency("list of modalities", "profil")
Profile is optional.

Learn more about the variables definition

EXAMPLE:
To obtain the frequency of the variable « Brand » bearing the number 1, write :
Brand.Frequency or v1.Frequency
To obtain the frequency of the modality « BMW » of the variable « Brand », write:
Brand.Frequency ("BMW")
To obtain the frequency of the modality « BMW » having received a mark > 10, write:
Brand.Frequency ("BMW","Mark>10")
To obtain the sum of the frequencies of the modalities « Peugeot and Citroën », write:
Brand.Frequency("Citroen;Peugeot")
To obtain the sum of the frequencies of the 1st and of the 2nd modality, write:
Brand.Frequency("\3;\5")
To obtain the frequency of the value « 25/12/2014 » of the variable Date, write:
Date.Frequency("25/12/2014")
To obtain the frequency of the value « 75000 » of the variable Code, write:
Code.Frequency("75000")

Percentage: Calculation of the percentage of the indicated modality, Non-responses excluded

Description:

Returns the percentage of « modality » for the indicated «variable », after excluding Non-responses.

Syntax:

Variable.percentage("list of modalities", "profile")
Variable.percentage("index of modalities", "profile")
Profile is optional.

Learn more about the variables definition

EXAMPLE:
To obtain the frequency of the 1st modality « BMW » of the variable « Brand », write :
Brand.percentage ("BMW") or Brand.percentage ("1")
To obtain the frequency of the modality « BMW » in the vehicles marked > 10, write :
Brand.percentage ("BMW","Mark>10")
To obtain the frequency of the modalities « Peugeot and Citroën », write :
Brand.percentage("Citroen;Peugeot")
To obtain the frequency of the first and second response options, write :
Brand.percentage("\1;\2")
To obtain the frequency of the value « 25/12/2014 » of the variable Date, write :
Date.percentage("25/12/2014")
To obtain the frequency of the value « 75000 » of the variable Code, write :
Code.percentage("75000")
