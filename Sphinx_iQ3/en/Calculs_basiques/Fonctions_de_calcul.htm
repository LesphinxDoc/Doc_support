CALCULATION FUNCTIONS

StDev: Calculation of the standard deviation of several variables

Description:

Returns for each observation, the standard deviation between the indicated variables regardless of Non-responses.

Syntax:

StDev("List of variables")

EXAMPLE:
To obtain the standard deviation of the variables "security", "safety distance", write:
StDev ("security ; [Safety distance]")
To obtain the standard deviation of the variables 1, 2, 4, 5, 6, 20, write:
StDev ("V1 ; V2 ; V4-V6 ; V20")

Authorized variables and values taken into account:

Variable type

Value taken into account

Numerical

Observation value

Closed scale

If the variable contains a weight so the value taken into account is the weight associated with the answered modality, if not, the value is the index of the modality.

Closed unique

Same as the closed scale question

Closed multiple

The value taken into account is the sum of the weights associated with the answered modalities if a weight is set, otherwise the value is the sum of the index of the answered modalities.

Note: For the closed variables, the modalities for which the weight hasn't been set do not count in the calculations.

NumberOfObservations: Calculation of the number of observations of the survey or profile

Description:

Returns the number of survey observations, or a specific profile. When this function is used in a dashboard, it returns the number of observations of the active sub-sample.

Syntax:

NumberOfObservations
NumberOfObservations ("profile")

EXAMPLE:
To obtain the number of survey observations (total sample), write:
NumberOfObservations
To obtain the number of observations corresponding to « BMW », the 1st modality of the variable Brand, write :
NumberOfObservations("Brand in \"BMW\"") or NumberOfObservations("v1 in \"1\"")
To obtain the number of observations corresponding to profile « mark <10 », write:
NumberOfObservations("mark < 10")

Sum: Calculation of the sum of several variables

Description:

Returns, for each observation, the sum of values taken by the indicated variables.

Syntax:

Sum("List of variables")

EXAMPLE:
To obtain the sum of the variables "security" , "safety distance", write:
Sum(security ; [safety distance]’’)
To obtain the sum of the variables 1, 2, 4, 5, 6, 20, write:
Sum (’’V1 ; V2 ; V4-V6 ; V20’’)

ExternTable: Recovery of a value in a code file

Description:

Returns for each observation, the value of 'Column' for the row corresponding to the value of 'variable'.

Syntax:

ExternTable(file, value, columns)

EXAMPLE:
To obtain the name of the country corresponding to the car Brand registered in the variable Brand, write:
ExternTable("country.txt",brand,"country")
