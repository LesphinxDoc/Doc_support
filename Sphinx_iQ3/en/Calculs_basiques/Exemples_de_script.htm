Display the absolute frequency of a variable modality according to a profile

Absolute frequency of BMW brand for men.

Copy 
1
brand.Frequency("BMW","gender=\"1\"")

Absolute frequency of BMW brand for men using diesel.

Copy 
1
brand.Frequency("BMW","gender=\"1\" and fuel=\"diesel\"")

Absolute frequency of BMW brand for men using any type of fuel.

Copy 
1
brand.Frequency("BMW","gender=\"1\" and fuel in \"1;2;3;4;5\"")

Backslashes before the modalities numbers are used to specify that you are using the number of a modality, not its label (useful particularly when the labels include numbers as it would be the case for a rating between 0 and 10 for instance).

To filter with several modalities, you need to use the keyword in followed by the list of modalities divided by semi-colons framed by quotation marks.

If you apply a function (percentage, for example) to a profile, you have to frame the profile with quotation marks. So if you need to use quotation marks in the profile definition expression, you need to "escape" them with a backslash (\)/
