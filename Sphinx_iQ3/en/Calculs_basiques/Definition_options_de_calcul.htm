DEFINITION AND CALCULATION OPTIONS

Variables definition

A variable can be called by its name or by its number preceded by the letter "V". Example: "security" or "V1".

A variable which name contains a space must be written in brackets.

Example [Safety distance]

In a closed variable, the modalities are referenced by index: the first modality corresponds to the index 1, the second to the index 2 ...

Defining a list of variables 

A list of variables must be written in quotation marks. The variables that it contains can be separated by « ; » or by « - » :

V1 ; V3 (takes into account the variables 1 and 3 only)
V1-V10 (Takes into account the variables from 1 to 10)

Syntax and numbers treatment

A number is an integer or decimal. It comes from an input or a calculation performed on variables.

The calculations made on decimal numbers are not based on round numbers but take into account all the digits after the decimal point. However, the returned results are limited to two digits after the decimal point by default; the user can change this setting in the variable definition dialog (write my questionnaire step , for example) if desired.

Syntax and dates treatment

A date can be expressed as a string of character type "03/24/2014 14:52:59" or #03/24/2014#. The delimiters " and # are valid.

It can also correspond to the value returned by a variable type Date or any function or complex expression that returns a date. For example, the current date returned by the Now() function .

Syntax and texts treatment

A text can be expressed as a string of character type "What a beautiful day!".

It can also correspond to the value returned by a Text variable or any function or complex expression that returns a string. For example, the string returned by the Right() function.

Calculation options

calculation options allow to specify the following three elements:

  • The desired treatment of non-responses (ignored or replaced).

  • The desired treatment of scale variables (numerical if we want to use them in the calculation functions or closed).

  • The ability to generate new modalities when creating closed questions.

Non-responses treatment

When a calculation contains variable which value is non-response, it is possible to:

  • Not to perform the calculation for the observation and keep the existing result (from a previous calculation).

  • Put the calculation result at Non-Response for the observation.

  • Perform the calculation by replacing the non-response by:

    1. The value 0 (if numerical variables) or empty string (other types of variables).

    2. The mean (if numerical variables) or the most cited string (other types oh variables).

      Replacement of non-response does not occur:

      • In mathematical functions implying a variable list, for example mean ("variable1; variable2").

      • In the properties that make calculations on all the observations, for example variable.mean.

      • In comparison tests involving variables, for example variable1 < 5.

      • In the functions date and time.

However, displaying results takes into account the non-response replacement options chosen. Concretely, a mean of two non-response is a non-response. If we choose the option:

  • « Do not perform the calculation for the observation », the result returned will be a non-response.

  • « Calculate the value by replaying the non-response by 0 », the result returned will be 0.

Similarly, calculations made from the results include replacement options for non-responses. For example, the calculation "10+mean of two non-responses" provides:

  • Non-response if the option « Do not perform the calculation for the observation » is retained.

  • 10 if the option « Calculate the value by replaying the non-response by 0 » is retained.
