THE CONTEXTS OF USE

The scripting language can be used in different environments Sphinx such as the form (to set automatic variables), the spreadsheet (to create ex-post variable ) or even the dashboard (for creating customized indicators).

You will find in this documentation all the information needed to quickly learn this language.

Calculation of a new variable

The formula to write a is function that will be assessed for each observation. This formula involves the values of other variables, the statistical properties of these variables, constants, control structures, etc. The result of this function is a number or a string of characters. Depending on the nature of the result, the created variable will be numerical, nominal (closed) or other.

Profiles and sub-samples

The formula is a Boolean expression. If it is true, the corresponding observation will be in profile. This expression can cover variable comparisons between each other or comparisons with constants.

EXAMPLE:
Month(DATE) = Month(Now())
The observations for which the variable DATE is in the current month.
TOEXPORT > TO* 0.2
The observations for which the turnover from exports exceeds 20% of turnover.

Calculated legend

A calculated legend is a character string in which some parts are interpreted and calculated 1 Automatic legends are also used to display in a dashboard dynamic elements such as the date, the name of the data file, the population studied, the current page, etc.. These parts to be interpreted must be placed in square brackets.

EXAMPLE:
In summary, the study population had an average age of [AGE.MEAN]. The respondents believe that the candidate "[CANDIDATES.Mode]" is favorite. The latter collects [SATISFACTION.Percentage("yes")]% of positive opinions.

Composed table

In a composed table, in each row and each column is assigned either the set of all observations or a profile that limits the concerned observations by the corresponding cell.

The number to make appear in this cell may be a number of observations or the result of a calculation in basic language. The expression will be evaluated for each cell profile.

EXAMPLE:
Cross table of means :
The table is created with two variables V1 and V2 to cross, one in the row and one in the column. The associated calculation is : NoteSatisfaction.Mean
The first cell of the table contains the mean of the variable NoteSatisfaction for the observations that have the first modality of V1 and the first modality of V2, and so on.

The calculation can be different for each table cell. In this case, we will write a row of expressions for each row of the compound table and separate the expressions related to the different columns by semicolons.
