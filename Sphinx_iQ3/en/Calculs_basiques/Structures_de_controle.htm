CONTROL STRUCTURES

Do

Description:

Repeats a group of instructions as long as the execution conditions are satisfied.

Syntax:

Do

          < instructions >

Loop While < condition >

Repeated as long as the condition is true.

EXAMPLE:
To calculate the number of occurrences of a "f" character or word in V1 :
TextAfter = V1
Character = "f"
NumberOfTimes = 0
Hint = 1
DesiredResult = 3
Do While Hint <> 0
Hint = InStr(TextAfter,Character)
If Hint > 0 then
NumberOfTimes = NumberOfTimes + 1
TextAfter = Mid(TextAfter, Hint)
EndIf
Loop
Select Case DesiredResult
Case 1
V = NumberOfTimes
Case 2
V = TextAfter
Case 3
V = Str(NumberOfTimes) & " : " & TextAfter
EndSelect

Until

Description:

Repeats a group of instructions until the execution conditions are satisfied.

Syntax:

Do Until <condition>

           <instructions>

Loop

Repeated until the condition becomes true.
For

Description:

Repeats a group of instructions as many times as specified.

Syntax:

For <counter> = <first> To <last> [Step <step>]         

       < instructions >

Next [<counter>]

Repeated as long as the condition is true.
Select Case

Description:

Executes a group of instructions if the execution conditions are satisfied.

Syntax:

Select Case <expression>

 

      Case 
       <instructions1>

repeated zero or several time.

       CaseElse
       <instructions2>

repeated zero or one time.

EndSelect

 

Examples:

Example

Comments

Select Case [Mark]

Case 20

V = "Excellent"

CaseElse

V = "To Study"

EndSelect

A variable is created based on the value of Mark.

If Mark of the observation is 20 then the variable takes the value "Excellent", otherwise it takes the value "To Study".

ref = 20

Select Case ref

Case [mark]

V = "Excellent"

CaseElse

V = "To study"

EndSelect

A variable is created.

ref is the reference value. It is 20 in the example.

The instruction is executed by the observation: if the mark of the observation is 20 then the calculated variable takes the value "Excellent", otherwise it takes the value "To Study".

Select Case [Mark]

Case 20

Case 19

V = "Excellent"

Cas 18

Cas 17

V = "Good"

CaseElse

V = "To study"

EndSelect

In this case, if the mark of the observation is 19 or 20 then the calculated variable takes the value "excellent", if the mark is 17 or 18 then the variable takes the value "Good" otherwise, it is the value " To study ".

ref = "MERCEDES"

Select Case ref

Case [Brand]

V="OK"

EndSelect

The reference value is MERCEDES.

The instruction checks, by observation, if the variable Brand is Mercedes (without considering the breakage and the accents). In this case, the created variable takes the value "OK".

While

Description:

Repeats a group of instructions as long as the execution conditions are satisfied.

Syntax:

Do While <condition>

           <instructions>

Loop

Repeated as long as the condition is true.

Examples:

Example

Comments

T(1) = V1.Number

N(1) = V1.Label

T(2) = V2.Number

N(2) = V2.Label

T(3) = V3.Number

N(3) = V3.Label

T(4) = V4.Number

N(4) = V4.Label

T(5) = V5.Number

N(5) = v5.Label

permut = True

Do While permut = True

    permut = False

    For cpt = 1 To 4

        IfT(cpt) < T(cpt + 1) Then

            permut = True

            tmp = T(cpt)

            T(cpt) = T(cpt + 1)

            T(cpt + 1) = tmp

            tmpch = N(cpt)

            N(cpt) = N(cpt + 1)

            N(cpt + 1) = tmpch

        EndIf

    Next cpt

Loop

V = N(1) & ";" & N(2) & ";" & N(3) & ";" & N(4) & ";" & N(5)

The variables from 1 to 5 evaluate 5 criteria on a scale of 5 levels (not at all agree, disagree, moderately agree, agree, strongly agree).

 

The purpose of this loop is to calculate the level of importance of each criterion based on responses to the scales.

 

At the end of the loop, a closed variable with multiple responses is created. The modalities of this variable are saved in the order of importance of the criteria for each observation.

 

Example :

V1 corresponds to security, V2 to speed ; V3 to aesthetics ; V4 to comfort and V5 to space.

 

The result of this loop is:

Observation 1: Security; aesthetics; space ; speed; comfort

Observation 2: speed; comfort; space ; security ; aesthetics
