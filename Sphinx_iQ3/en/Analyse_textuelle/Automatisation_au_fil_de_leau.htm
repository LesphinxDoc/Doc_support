On-the-Fly Text Processing Automation

With Sphinx iQ3 you can now automatically perform lemmatization, codification and Semantic orientation at each response registration.

To activate the processing automation on a text question, proceed as follows:

  1. From the Questionnaire Design section, select your text question.

  2. Click on the tab Calculation.

  3. Check the actions to automate: lemmatization, orientation detection, codification.

    Lemmatization

    By activating this option, the content seized by the respondent to this question will be automatically lemmatized online upon registration of observation.

    The benefit is to be able to display then the analysis "words clouds" in the web-reporting much faster. Indeed, normally, the lemmatization is carried out at the time when the analysis is requested. If the number of observations is large, the time to display the analysis can take several seconds.

    By lemmatizing one observation after another, the display time is reduced and the words clouds can be displayed almost instantly.

    Semantic orientation (positive / negative)

    By activating this option, the orientation of the content entered by the respondent to this question will be automatically calculated at each recording.

    You can thus consult in real time the evolution of satisfaction for example. Or you can create an alert by email in case of a negative observation in order to launch a reminder.

    It is possible to associate a note variable (scale from 0 to 10) to force the orientation of a verbatim on the extremes, to do this:

    1. Click on the button.

    2. Select the variable to use.

      NOTE: The NPS variable must be present in the survey.

      All observations that will be categorized as "no opinion" and have a recommendation score of 0,1,2 or 3 will be tagged as negative and those with 9,10 will be tagged as positive.

    Codification (content analysis by dictionary)

    By activating this option, the codification of the observation is made at registration. The themes detected will be automatically linked.

    Again, the benefit is to follow in real time the evolution of the distribution of the cited themes in the survey. You can also create alerts if a particular topic is cited for example.

    If the options Semantic orientation and Codification are activated, another variable will be automatically created : a variable that gives the orientation for each detected theme.

    So for each theme of the dictionary, a variable is created with 4 modalities by theme:

    • Theme +: positively cited theme,

    • Theme –: negatively cited theme,

    • Theme =: theme cited with a shared orientation,

    • Theme: theme cited in a neutral manner.

    The cutting of the observation is made by sentence.

    EXAMPLE: If for one observing the theme "Agency" is detected in the sentence 1 (this sentence has a positive orientation) and in the second sentence the theme "advisor" is detected but cited negatively, then the created variable will contain for this observation the modalities "Agency +" and "Advisor -".

    To add a dictionary, proceed as follows:

    1. Click on button.

    2. Click on button.

    3. Select one or more dictionaries (*.dic or *.txt format).

    4. Click on OK to confirm.

    To render this information in a more visual and interactive way, a new view is available in the Webreporting, « Themes/orientations crossings ».

  4. Select the variable to use to detect the observation language (by default, the input language is selected).
