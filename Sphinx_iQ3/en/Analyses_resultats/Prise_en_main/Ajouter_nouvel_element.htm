Add a new item (analysis, filter, text, image, shape)

When hovering over the button on the right, next to the dialog boxes, 9 analysis options appear.

ANALYSIS AND FILTER

  • The One way table allows to do a basic sorting using one variable.

  • The Cross analysis allows to do cross sorting or multivariate analysis with at least two variables analyzed simultaneously.

  • The Advanced analysis allows to perform a satisfaction analysis, a KeyViews, data analysis, classification and map representation.

  • The Custom table allows you to create advanced analyzes where you can define profiles that will act on the variables to be displayed in your rows and columns.

  • The Textual and semantic analysis allows you to explore your textual data through the display of verbatim, keyword cloud, influences and specificities by context, automatic lexical analysis or through a thematic analysis.

  • The View filter allows you to add a filter, which will be effective on all pages of the view, to study only a specific category of respondents.

TEXT

The text button is used to illustrate the analysis with a text zone that can be edited according to its size, color or font.

To create a text box, proceed as follows:

  1. Click on the button.

  2. Click on text.

    NOTE: It is possible to add a text box by double clicking on the are of the page where you want to place it.

  3. Fill in your text in the field.

  4. (Optional) Change its appearance (color, background color, border).

  5. (Optional) Apply a preset style (Title 1, Title 2, Title 3, Normal, Quotation).

  6. (Optional) Change the proportions/ change the orientation of the text area using the icon.

Apply filtering options to a text field and define the number of decimals to display

It is possible to apply filtering options to a text field that contains a calculation formula and also to define the number of decimal places to be displayed.

EXAMPLE: In a view that displays the results for the year 2022, we want to recall the turnover achieved in 2021 via a calculation formula inserted in a text box that should not be filtered when using the view filters.

To do this:

  1. Select the text box containing the calculation formula.

  2. From the Advanced tab, Calculation section, click on Filtering options.

  3. Select the filtering option to use.

  4. From the Format section, set the number of decimals to be displayed.

Insert a hyperlink in a text box

To insert a hyperlink in your text box, proceed as follows:

  1. Select your text.

  2. Click the button .

  3. Insert the web address to use.

    NOTE: To generate an email to an address when a person clicks on the link, add the term "mailto:" in the Web Address field.

  4. (Optional) Fill in a tooltip (which will display a text when the link is hovered over).


Assign an action to a text box

To assign an action to a text box, proceed as follows:

  1. Select the text box.

  2. From the Scenario tab, choose an action:

    • Illustrate with a view: allows to display a view in a popup when clicking on the text.

    • Filter analyzes: select the analyzes to be filtered and then define the filter to be used.

      EXAMPLE: In this example, we have defined a filter "Gender among Man" on the text box "Man".

    • Navigate to an external link: enter the URL then choose the target (open in a new tab or in the current tab).

    • Navigate to a page: choose the page to display when clicking on the text box.

    • Go to a view: choose the view to display when clicking on the text box.

Insert a study parameter in a text box

You can insert a parameter (s) of the study into your view.

EXAMPLE: Display automatically the page number and the total number of pages.

To do so:

  1. Double-click on the text box.

  2. Click on the Auto legend drop-down menu.

  3. Select the setting to use.

IMAGE

The image button can be used to illustrate an analysis by adding images or pictograms to the page.

  • Images can be imported from the computer or the internet.

  • The pictograms can be displayed by category from the category menu or by searching them directly from the search bar.

To import an image / pictogram, proceed as follows:

  1. Click on the button.

  2. Click on Image.

  3. Select the image from the gallery or click on the Add Image tab to import one from your computer or from the internet.

  4. Click OK to validate.

  5. (Optional) Modify its style (color of the pictogram, add a colored layer for the images).

  6. (Optional) Change the proportions/change the orientation of the image using the icon.

It is possible to assign an action to an image, to do this:

  1. Select the image.

  2. From the Scenario tab, choose an action:

    • Illustrate with a view: allows you to display a view in a popup when you click on the image.

    • Filter analyzes: select the analyzes to be filtered and the define the filter to be used.

      EXAMPLE: In this example, we have defined a filter "Gender among Man" on the pictogram in blue.

    • Navigate to an external link: enter the URL and choose the target (open in a new tab or in the same tab).

    • Navigate to a page: choose the page to display when clicking on the image.

    • Go to a view: choose the view to display when clicking on the image.

SHAPE

The Shape button allows you to add figures to better illustrate the analysis.

To add a graphic shape, do the following:

  1. Click on the button.

  2. Click on the Shape icon.

  3. Choose the shape to use.

  4. (Optional) Change its style (color, border).

  5. (Optional) Change the proportions / change the orientation of the shape using the icon.

It is possible to assign an action to a shape, to do this:

  1. Select the shape.

  2. From the Scenario tab, choose an action:

    • Illustrate with a view: allows you to display a view in a popup when you click on the shape.

    • Filter analyzes: select the analyzes to be filtered and the define the filter to be used.

    • Navigate to an external link: enter the URL and choose the target (open in a new tab or in the same tab).

    • Navigate to a page: choose the page to display when clicking on the shape.

    • Go to a view: choose the view to display when clicking on the shape.

ADD ELEMENTS TO THE MASK

Text boxes, images and shapes can be added to the mask in order to display them on all the pages in your view.

To do this:

  1. Select the elements (image, text box or shape).

  2. Right click and click Add to the mask.

NOTE: Once added to the mask, the elements can only be edited from the first page of the view.

To remove an object from the mask area, do the following:

  1. Select the element.

  2. Right click on it then click Remove from the mask.
