Calculate a variable by script

This feature allows you to calculate a new variable by writing a calculation formula (mean, standard deviation, etc.) based on one or more other variables.

To access this feature, go to the Analysis section and, once you are in an analysis view, click on the Calculate a variable... button below the list of variables.

Then proceed as follows:

  1. Select the Calculate a variable by script option.

  2. Write your calculation formula in the provided area, choosing the calculation function and the variables to be used.

    A few tips:

    • You can double-click on a variable in the list of variables on the right to add it to your calculation formula.

    • A variable can be called by its name or by its number preceded by the letter V, for example: “security” or “V1.”

    • A variable whose name contains a space must be written in square brackets.

    NOTE: To help you write your calculation formula, you can find a writing assistant below the text box. For more information on expressions and the processing of non-responses in particular, please refer to the page dedicated to calculation formulas.

  3. Click Next.

    You will see a preview of your calculation results.

  4. Click Next.

  5. Configure the variable to be created by entering its name (label) and type (numerical, single closed, text, code, etc.).

  6. (Optional) Select the Automatic variable check box so that the calculation is executed for any observation added or modified after the creation of the calculated variable.

  7. Choose where to insert the new variable.

  8. Click Finish.

Your calculated variable is created.
