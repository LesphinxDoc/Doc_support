CREATE A NEW FORM

It is useful to create several forms when the different forms have a common structure (many questions in common) but each one has some particularities (hidden questions, different display conditions, etc).

EXAMPLE: It can be a common questionnaire but with some specificities depending on the type of respondents: for example, for the same survey, the researcher will create a provider form and a client form.

To create a new form, proceed as follows:

  1. In the Forms tab, click on  .

  2. Give the form a name.

  3. Select the type and size of the form (web, paper, screen, scanner).

  4. (Optional) Add the study variables to the form by checking this option.

  5. Choose the form layout template from the available list or create a new one.

  6. Set the numbering mode of the variables according to:

    • According to the rank in the form: the questions are numbered according to the order of presentation on the current form.

    • The hierarchical index: the questions are numbered according to a hierarchical index.

    • Number questions: questions are numbered according to the order of presentation in the variable list.

    • No numbering: no numbering is applied to the questions.

  7. Click on Add.

    The new form created will be added to the list of forms in the explorer at the bottom left of the screen.

  8. To switch from one form to another, double-click on the form you wish to work on.

Import a form from another survey

To import a form from another survey, do the following:

  1. From the Forms tab, click on the New button.

  2. Click on Create from an existing form.

  3. Choose the survey containing the form to be imported.

  4. Select the form from the drop-down menu.
