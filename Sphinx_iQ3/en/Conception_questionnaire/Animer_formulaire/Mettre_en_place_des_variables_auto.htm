SET UP AUTOMATIC VARIABLES

An automatic variable allows the researcher to collect useful and precise information on the respondents' entry in the questionnaire. These variables are called "automatic" because their value is automatically incremented when the person answers the questionnaire.

There are several types of automatic variables depending on the information you want to collect and the type of variable.

To create an automatic variable, proceed as follows:

  1. In the questionnaire design stage, go to the Insert tab.

  2. Click on the Question button.

  3. Choose the type of question to use from the Definition tab.

  4. Go to the calculation tab.

  5. Check the box Calculated variable and select the automatic variable to use.

NOTE: The ability to select an automatic variable depends on the type of question selected. For example, in order to select the automatic variable Date and time of entry, you have to select the question type Date/Time.

AI Calculation

This automatic variable allows you to run an AI prompt based on one or more variables.

EXAMPLE: A prompt to analyze the emotional tone expressed in the response. To use it, replace [Variable] with your own variable.

Copy 
Analyze this text and identify the dominant emotion.
Expected output: one of the following: Joy, Serenity, Gratitude, Pride, Hope, Fear, Anger, Sadness, None
Text: [Variable] 

Access prompt templates

WARNING: If an AI-calculated variable is used to conditionally display an element in the form (another variable, text field, image, etc.), it is recommended to place the conditional element on the next page. This helps prevent any display delay caused by AI processing time, especially when the source variable is on the same page.

EXAMPLE: On page 1 of the form, the user enters a response in the "Comment" variable. An AI-calculated variable named "Satisfaction" analyzes this comment to determine whether the respondent is satisfied or dissatisfied. Another conditional variable, such as "Would you like to be contacted again?", should only be displayed if the value of "Satisfaction" is "dissatisfied".
In this case, it is recommended to display this question on the next page rather than on the same page as "Comment", in order to avoid any display delay related to AI processing time.

Same as previous observation

This automatic variable is generally used when a characteristic is common to all respondents, and/or when the researcher enters several large batches of questionnaires, each with a response that is identical for all respondents.

EXAMPLE:
A survey is disseminated by paper questionnaires in several cities (annecy, aix-les-bains, chambéry,...). In order to identify the responding city, a « city » question is created. It is then interesting, for the researcher who will take care of the input, to create an automatic variable about the city. After sorting out questionnaires by cities, when the researcher enters the first questionnaire of "Annecy", he shows the suitable modality « Annecy » for the question "city" . Thus, for any input of the other questionnaires about Annecy, the variable city will be pre-informed and editable with the suitable modality. This spares giving the same response for any entered questionnaire. This option is also useful for the scanner input.

NOTE: The variable named Same as previous observation is the only automatic variable that can be applied to any type of variable.

Identify the respondent (Primary key & Public IP address)

Primary key

If you want to be able to identify the respondent, his answer among the others, or allow him to modify his entry, it is possible to assign a primary key to the respondent (unique code composed of numbers and letters, each respondent has a different key). The researcher should create a Primary key question, this variable will then be automatically incremented when the respondent enters the questionnaire.

  • In order to select the automatic variable Primary Key, your question must be of type Text/Code.

Public IP address

To "trace" the respondent, it is also possible to know his public IP address .

  • To be able to select the IP address/host name automatic variable, your question must be of type Text/code.

Counter

In the context of specific questionnaires, it is sometimes requested to know the rank to which the respondent answers.

EXAMPLE: In the context of a contest, we would like to offer a gift to the first 50 respondents.

It is then useful to create an automatic Counter question in order to identify the 50 winners.

Moreover, a legend with a presentation condition can be set up to inform the respondent if he is one of the winners or not (the presentation condition is made from the Counter variable).

  • To create this automatic variable, set the variable to Numeric and select Counter.

Data entry duration

In order to know how much time the respondent spends typing the questionnaire, an automatic variable Data entry duration can be created (duration in seconds). It is useful to calculate the average time spent on the questionnaire for all respondents, and possibly to delete the answers of people who spent too little time answering the questionnaire (these answers can be considered as unreliable)..

  • To create this variable, proceed as presented above, define the variable as Numerical and select Data entry duration.

Retrieve information on the date and time saved, modified or data entry

The automatic variables Date and time saved, Date and time modified, Date and time of data entry allow a precise follow-up of the collection of responses. It will then be possible to sort the responses in chronological order of registration, modification or entry of data.

  • To create this variable, proceed as presented above, define the variable as Date/Time and select one of these three variable types.
