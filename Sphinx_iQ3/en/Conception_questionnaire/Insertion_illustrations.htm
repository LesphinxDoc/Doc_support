Insert an illustration (text, image, video, etc...)

Illustrations include both multimedia objects (image, sound, video,) and text boxes. To include them in the questionnaire, proceed as follows:

  1. Please go to the Insert tab, Texts and media group.

  2. Select the element to insert in your form.

    Image

    1. From the Definition tab, click on the ... button.

    2. Select an image from the gallery or click on Select another image to use an image from your computer.

    3. (Optional) Change the size of the image by scaling it in %.

      You can allow respondents to display the image in its real size by clicking on it, just check the option Allow respondent to click on the image to enlarge (actual size) it.

    4. (Optional) Crop the image if necessary.

    5. (Optional) Check the Hover text option if you want to display text when the respondent hovers over the image.

      This option can be used to give explanations / additional information about a question etc...

    6. (Optional) The Dynamic object option allows you to recall the images selected in a previous question or the image uploaded from a document type question. Learn more about dynamic objects.

    7. Click on Ok to validate.

    Note that it is possible to apply a display condition on an image as for questions and to associate an action to an image.

    Open text field

    1. From the Definition tab, enter the text to be inserted in the area provided for this purpose.

    2. Customize the font and color of your text.

    3. Click on OK to validate.

    Note that it is possible to apply a display condition on a text zone as for questions.

    Video

    • From the Definition tab, select the source of the video to use.

      • To embed an online video:

        1. Select Online Video.

        2. Copy the video embed code.

      • To embed a video on your computer:

        1. Select File.

        2. Click on ....

        3. Select the video.

        4. (Optional) Check the Load at start up box so that the video starts automatically.

        5. (Optional) Check the option Loop playback if you want to play the video in loop.

        6. Click on OK to validate.

          NOTE: File-based videos are very poorly supported by browsers, it is recommended to use online videos with embedding code for a better accounting and an optimal user experience.

    Note that it is possible to apply a display condition on a video as for questions.

    Sound

    1. From the Definition tab, click on the ... button.

    2. Select the sound file to use.

    3. Click on OK to validate.

    Note that it is possible to apply a display condition on a sound as for questions.
