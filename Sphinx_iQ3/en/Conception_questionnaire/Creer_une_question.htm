CReate a QUESTION

In the Insert tab, click on the Question, Table question or Matrix button.

A dialog box will appear where you can enter the title, the short name, the type and, for closed questions or scales, the answer mode.

After creating several questions, if you want to add a question at a specific location in the questionnaire, you have to select in the work area the question just before the one you want to add. Then click on the Question button as shown above. The new question will be placed in the desired location.

Below are the parameters of the question creation windows, Definition tab, for each type of question.

CLOSED QUESTION 

The closed-ended question asks respondents to make a choice (or several choices) among predefined answers.

EXAMPLE: We ask respondents which mode of transportation they use most frequently.

To create a closed-ended question, proceed as follows:

  1. From the questionnaire design environment, Insert tab.

  2. Click on Question.

  3. Choose the type Closed (type selected by default).

  4. Set the label and the variable name.

  5. Set the number of possible answers: one answer or multiple answers (number of answers to be indicated).

    Rank the response to a multiple closed question

    For multiple closed-ended questions, the respondent can be asked to rank his or her answers in order of importance. The first checked answer will be ranked first, the second checked answer will be ranked second and so on.

    Importance scores can then be calculated for each modality.

    To do so:

    1. From the dialog box for defining a multiple closed question.

    2. Specify the number of possible answers.

    3. Check the box Ranked responses.

    4. Click on OK to validate.

  6. (Optional) Assign a scale to the terms.

    EXAMPLE: When distributing a quiz, it can be useful to define scales to calculate the final score.

  7. Click on OK to validate.

SCALE QUESTION

The scale type question allows you to evaluate the opinion, preference or satisfaction of respondents on a given subject.

This type of question is equivalent to a single closed-ended question, with each modality assigned a score corresponding to the rank of the scale or a defined weight.

EXAMPLE: We would like to get feedback from customers on some points after testing our new orange juice.

To create a scale question, follow these steps:

  1. From the questionnaire design environment, Insert tab.

  2. Click on Question.

  3. Choose the type Scale.

  4. Set the label and the variable name.

  5. Fill in the scales to be used in the Modalities section.

    Predefined scales are available. Click on Select scales... to access the complete list.

  6. Assign a scale to each mode.

  7. Click on OK to validate.

TEXT / CODE QUESTION

Free text

This type of question allows to provide respondents with a free field where they can enter what they want. Without restrictions of characters or length.

EXAMPLE: Ask respondents to indicate the reason for their dissatisfaction.

To create a free text question, proceed as follows:

  1. From the questionnaire design environment, Insert tab.

  2. Click on Question.

  3. Choose the type Text / Code.

  4. Select Free text.

  5. Set the label and the variable name.

  6. (Optional) Check the box Limit the number of characters by defining a number if you want to limit the answer in number of characters.

  7. (Optional) Select the Enable voice dictation option to allow respondents to enter their answers using voice dictation.

    NOTE: Voice dictation uses the native capabilities of the respondent's browser: the voice may be transmitted to third parties (the browser vendor) for conversion to text, and the feature may be unavailable on some browsers or older versions. Only the text is saved with the responses.

  8. Click on OK to validate.

    Note that you can change the default text displayed in the "Type your text here" input field. You can either display a customized text, or leave the input field blank.

    To do so:

    1. Select your text variable,.

    2. From the Style tab, Content section.

    3. Select the display type to be used.

Code

These questions are also text fields but have input restrictions to prevent respondents from entering data unrelated to the question (e.g. email).

The different types of restrictions are:

  • « Fixed size »: we limit the number of characters.

  • « French postal code »: it is necessary to enter a 5-digit number.

  • « Email »: requests an address containing a '@'.

  • « Customized »: allows to create a customized format (see below for settings).

    The Customized format corresponds to the application of a regular expression. It is a specific syntax that allows to define syntactic rules.

    Learn more about regular expressions.

    NOTE: Remember to customize the alert message (Controls tab) to inform the respondent of the type of syntax required. By default, if the syntax is incorrect, the regular expression will be presented to the respondent as a template, which is not necessarily readable.

  • « Code list »: this type allows to offer to the respondents a list of answers previously defined in a text file.

    This function allows to have a drop-down list of predefined codes from which the respondent selects the code that corresponds to him. To do this:

    1. In the Code Question Definition dialog box, check the Code box.

    2. Choose the Code List format.

    3. Click on to manually enter a list or import a file containing your code list.

      NOTE: The file to import must be in *.dic or *.txt format.

      You can have a preview of the code list in plain text or in a spreadsheet.

      Plain text code list Code list in a spreadsheet

    4. Click on OK.

    5. (Optional) Check the Input help box to make input easier for respondents:

      WARNING: Upon activation of this option, the code list will be accessible online and without specific protection. Do not add any personal data to this list.

      1. Choose the columns to be displayed during the input.

        NOTE: By default all columns will be displayed, if you do not want to display a column, just move it to the Available columns area.

      2. Enable column filtering by checking the Enable column filtering option while choosing the text filter to use: starts with / contains.

        Textual filtering "beginswith" Textual filtering "contains"

      3. Fill the variables present in the code file and not displayed on the page.

      4. Tick the Pre-filter by variable option to filter the values displayed in the question based on the response to a previous question.

        EXAMPLE: Registering for an event
        The respondent first selects a country (e.g. Portugal), then the next question only offers the cities available for that country (e.g. Porto, Braga, Lisbon).
        A third question can then suggest available slots (DateTime), pre-filtered according to the selected city.

        If your code file contains all the columns, link it to each variable and then choose the variable used for pre-filtering for each question.

NUMERICAL QUESTION

The numerical question allows respondents to enter a numerical value that can correspond to age, expenses, grade, etc...

EXAMPLE: We would like to know the number of people living in the household.

To set up a numerical question, proceed as follows:

  1. From the questionnaire design environment, Insert tab.

  2. Click on Question.

  3. Choose the Numerical type.

  4. Set the label and the variable name.

  5. Set the limits of the possible values (Minimum/Maximum).

  6. Set the number of decimal places.

  7. Set the size of the input field (in numbers).

  8. Set the unit of the input field from the drop-down menu provided for this purpose (%, $, Km, €).

NOTE: It is possible to manually enter a unit in the corresponding field.

DATE / TIME QUESTION

The Date/Time question collects information about the date and time.

EXAMPLE: Set up a date/time type question to ask vacationers when they arrived in the area.

To create a question of type Date/Time, proceed as follows:

  1. From the questionnaire design environment, Insert tab.

  2. Click on Question.

  3. Choose the Date / Time type,

  4. Set the label and the variable name.

  5. (Optional) Set the limits of the possible values for the dates (minimum/maximum).

  6. Select the date format to use from the drop-down menu.

    NOTE: You can disable the possibility to use a calendar when typing, just uncheck the option Use a calendar from the formatting part.

  7. Click on OK to validate.

TABLE QUESTIONS

The question table allows you to display several questions with the same modalities in the same table.

EXAMPLE: We would like to know the vacation budget for each of the following categories.

To set up a table question, proceed as follows:

  1. From the questionnaire design environment, Insert tab.

  2. Click on Table question.

  3. Choose the type of variable to be used (in the above example type: Numerical).

  4. Set the label and the name of the table as well as the label and the name of the variables.

  5. Set the options according to the type of question used.

MATRIX QUESTION

It is possible to create a multiple table with several questions. This allows you to link several tables with identical rows and different columns.

EXAMPLE: A satisfaction scale table completed by a comment table.

To create a multiple table, proceed as follows:

  1. From the questionnaire design environment, Insert tab.

  2. Click on Matrix.

  3. Fill in the table name and label.

  4. Add and set up the questions in your table.

  5. Adjust the column width (for row labels and questions).

    The total width must be equal to 100%.

  6. Click on OK to validate.

NOTE: It is possible to group your questions directly to build a multiple table. To do this, select the questions then right click and click on Group.

DOCUMENT QUESTION 

The "document" question allows respondents to document their answer by allowing them to upload attachments (images or Word, Excel or PDF files, among others).

Various options allow you to control the uploads (limit the number of files, extension types, rename the files).

To create a Document question, proceed as follows:

  1. From the questionnaire design environment, Insert tab.

  2. Click on Question.

  3. Choose the Document type.

  4. Set the label and the name of the variable.

  5. Select the option to use for the names of the uploaded files, you can:

    • Keep the original name,

    • Rename the file,

      EXAMPLE: The respondent is invited to upload his resume. We want to automatically rename the file by recalling in the file name the answer to the question Name and add the suffix "_resume".

    • Prefix or suffix.

      EXAMPLE: _resume 
      The name will include the name of the file imported by the respondent followed by the text "_resume"

  6. Check the Allow only the following file extensions box if you want to define a specific list of extensions.

    EXAMPLE: We want to allow only the .pdf extension for uploading resumes.

    Below the list of extensions allowed on shared servers.

    Copy 
    "jpg","jpeg","png","gif","bmp","tif","tiff","heic","jfif",
    "jp2","jpe","odg","3gpp","3gp","3ga","wav","aac","wma","mp3",
    "mp4","m4a","mov","txt","rtf","odt","doc","docx","csv","xls",
    "xlsx","ods","pdf","xps","oxps","pub","ppt","pptx","odp",
    "zip","7z","rar","gz","tar.gz","eml","sav","msg"

    NOTE: This list can be modified on demand when hosted on a dedicated server.

  7. Set the maximum number of documents that can be uploaded,

  8. Click on OK to validate the creation of your question.

The maximum size of a file that can be uploaded is 10 MB.

NOTE: This limit can be modified when hosting on a dedicated server.

To view and/or download the files uploaded by respondents, proceed as follows:

  1. From your SphinxOnline account, access your survey.

  2. Click on the My survey button.

  3. Click on the Files... button and then click on Uploaded Files.

  4. Select the files you want to download and click on the Download button.

    To view a file, click directly on the link in the File Name column.

"ADDRESS BLOCK" QUESTION 

It is possible to insert what we call an "address block" question in your questionnaire. This one has 2 interests:

  • Insert 5 text fields in one go to fill in the address (Postal Code, Town, Street, Number and Complement).

  • Once online, these questions are connected to a governmental database allowing to manage the auto-completion during the input.

    EXAMPLE: Once a postal code is entered, only the corresponding towns will be proposed to the respondents. And then the same for the roads of the chosen city

    NOTE: For possible non-existent addresses in the database, there is an additional address field.

To insert an Address Block question, proceed as follows:

  1. From the questionnaire design environment, Insert tab.

  2. Click on the small arrow below the Question icon.

  3. Select Address block.

  4. Fill in the label and the variable name.

  5. Rename the labels of the variables in the address block if necessary.

  6. Click on OK to validate.

Hide a question

To hide a question on the form, do the following:

  1. Select it, right click on it.

  2. Click on Hide from form/Delete.

  3. A small window will open, click on the Hide button.

    Or click on the icon when hovering over the question.

NOTE: When you hide a question, it will no longer be displayed on the form but will remain in the survey.

Once the question is hidden, an orange triangle will appear in the list of variables. This triangle means that the question is not present in the form.
