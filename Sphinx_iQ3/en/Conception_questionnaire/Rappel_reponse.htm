Piping an answer to a previous question

In some cases, answer piping can be useful in your questionnaire. Whether it is in the label, in a modality, in a text block or as an image.

Piping an answer in the question label, in a modality or in a text block.

To pipe the answer to a question, either the name or the number of a variable will be used.

EXAMPLE: The variable "country" is the 1st variable of this survey and can be piped by writing [country] or [V1].

  1. Open the text block or the question with the label or modality to be edited.

  2. Enter the name or the number of the variable to be piped. In this example, it would be [country] or [V1].

    NOTE: You can also click on the icon Survey information and select the variable to be piped in the label or text block.

    The field will be replaced by "..." in edit mode but will be automatically filled when the respondent answers the first question.

    Example to test how it works: Test-survey.

    In case you need to pipe several modalities for a closed-ended question as modalities for another question, you need to indicate the position of the modality in addition of the variable name/number.

    [V1(1)] for the 1st selected variable, [V1(2)] for the 2nd selected modality, etc.

    Example to test how it works: Test-survey.
