FORM PROPERTIES

The form properties enable the setting of several options specific to a form. You can manage the name of the form and certain graphical aspects (type and size of form, management of templates), but also parameters related to local or online data entry, as well as integrity constraints allowing the validation, or not, of the form.

To access the form properties, proceed as follows:

  1. From the Forms tab, click on the Properties button.

  2. Set the options from the Definition, Internet and Controls tabs.

    Definition tab

    You can:

    • Change the form name.

    • Choose the form type (web, paper, screen, scanner).

    • Change the form size (800*600, 1024*768, custom size, etc...).

    • Select a form template from the available list or create a new template by clicking on Create Template.

    • Choose the method by which the numbering of variables will be done.

      • According to the rank in the form: questions are numbered according to the order of presentation on the current form.

      • Hierarchical index: questions are numbered according to a hierarchical index.

      • Number questions: questions are numbered according to the order of presentation in the variable list.

      • No numbering: no numbering is applied to the questions (option selected by default).

    Internet tab

    1. Navigation mode

      This section allows you to set up the navigation to the next page.

      • Standard navigation : moving to the next page is done with the navigation bar. It is possible to customize the style and color of the navigation bar.

      • Sequential navigation: moving to the next page is done automatically after the respondent has filled in the questions on the current page.

        Click on the image for an animated preview

    2. Specific smartphone formatting

      • Check the Enable smartphone formatting option to customize the display of the questionnaire on smartphones.

    3. Input time

      • Select Limit data entry time to limit data entry to the specified number of seconds.

      • (Optional) It is possible to redirect the respondent to a site by inserting the link in the Optional link field.

      • Checking the box Display elapsed time allows you to display a countdown in the form.

    4. Automatic resizing

      • Check the box Automatically adjust the form to the browser width to activate the responsive design.

      • Check the box Automatically adapt the height of the form to the number of visible questions to remove the empty space between the questions and the navigation buttons.

    5. Transition of pages

      • Select the page transition mode: Fading, Slide or None (default mode, no effect).

    Controls tab

    This section allows you to set up navigation constraints to alert the respondent and block the progress of the questionnaire in certain cases. Learn more about setting up a data entry constraint.
