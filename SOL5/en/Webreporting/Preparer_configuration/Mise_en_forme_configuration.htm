Modify configuration layout

Through this section, you will learn about the customization options available in the WebReporting configuration interface. You will learn how to edit graphical elements such as the menu colors, logo, title, how to choose a language and translate the configuration content as well as to integrate custom home or help pages to guide users viewing your reports.

Modify menu colors: Text / Background

You can modify the menu text colors and the side menu background color. To do so;

  1. Access the WebReporting section, Configure settings tab.

  2. Select the text color (forecolor).

  3. Select the background color (backcolor).

Add a logo

To add a logo:

  1. Access the WebReporting section, Configure settings tab.

  2. Check the Logo box.

  3. Click on Add.

  4. Click on Add image.

  5. Click on Choose File to select a file from your hard disk.

    NOTE: The maximum size is 2 Mo. Allowed formats: .bmp, .emf, .gif, .jpg, .png, .wmf.

  6. Click on Upload.

  7. Select the image from the list then click on Insert.

    NOTE: You can resize the image by typing a percentage in the Size field and clicking on Apply.

Add a title

This text stands for the title displayed above the actions you configure:

  1. Access the WebReporting section, Configure settings tab.

  2. Check the Title box.

    NOTE: By default, the displayed title is: "[Enquête.Titre] - #NombreObservations] obs.] or [Survey.Title] - [ObservationsNumber] obs.". This automatically displays the survey title along with the total number of associated observations.

  3. Click on to edit the title.

    The text in square brackets can be replaced with one of the following keywords:

    • [Enquête.Nom] or [Survey.Name]: replaced by the survey name when the online report is generated.

    • [Enquête.Titre] or [Survey.Title]: replaced by the survey title (or the survey name if no title has been set).

    • [NombreObservations] or [ObservationsNumber]: replaced by the total number of survey observations.

    • [NombreObservationsFiltre] or [FilterObservationsNumber]: replaced by the number of observations that match the restricted access or the default stratum. This number is calculated when the online report is loaded and is not updated if the filter is later modified.

    • [Profil] or [Profile]: replaced by the text representing all defined filters.

    • [Session]: replaced by the text defined in the Session column of a restricted access configuration. If no restricted access is defined for the survey, the text is replaced by the values of the profile variables. If no profile variables are defined or if they contain no values for a given user, [Session] is replaced by an empty string.

  4. Click on OK to confirm your changes.

Add a help page

You can create a help page in HTML format to guide users in using the reporting you provide.

To do so:

  1. Access the WebReporting section, Configure settings tab.

  2. Check the Help page box.

  3. Click on Create a page or on the Manage files icon.

  4. Select Create a new HTML file.

  5. Name your HTML file, then click on Create.

  6. Click the pencil icon to edit your HTML page.

    NOTE: It is also possible to import an existing HTML file from your computer:
    1- Select Upload a file from disk.
    2- Click on Choose File.
    3- Select the .html file to import.
    4- Click on Upload.

  7. Finally, select the page to use from the Help page dropdown menu.

    The configured help page will then be accessible to Webreporting users via the “?” icon located at the top right of their screen.

Add a home page

You can create a home page in HTML format that will be displayed by default when the reporting is opened.

To do so:

  1. Access the WebReporting section, Configure settings tab.

  2. Check the Home page box.

  3. Click on Create a page or on the Manage files icon.

  4. Select Create a new HTML file.

  5. Name your HTML file, then click on Create.

  6. Click the pencil icon to edit your HTML page.

    NOTE: It is also possible to import an existing HTML file from your computer:
    1- Select Upload a file from disk.
    2- Click on Choose file.
    3- Select the .html file to import.
    4- Click on Upload.

  7. Finally, select the page to use from the Home page dropdown menu.

Translate the configuration content

When creating an online report, the configuration language is your survey's default language. You can change language for the configuration as a whole and/or for specific actions if your survey includes several languages.

When editing your configuration, click on the drop-down menu Language to select the language of the configuration as a whole. The menu and actions will be displayed in the selected language.

EXAMPLE: Your survey's languages and English and French. By default, your configuration is in English, but you want your reporting to be displayed in French.

You can also set a language per action (it will only affect the content, not the menu display).

EXAMPLE: Your survey's languages are English and French. You want your reporting to be displayed in French except for the Spreadsheet action:
1 - Click on the relevant action.
2 - Click on Modify.
3 - In the action settings, check Language and select the action display language in the drop-down menu. By default, the action is displayed in the configuration language.
