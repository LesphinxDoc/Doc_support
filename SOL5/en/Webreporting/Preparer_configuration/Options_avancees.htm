Configure advanced options

Configuring advanced options is a way to refine your online reporting.

To do so, click on the Display advanced options toggle switch at the very bottom of the Configure settings page.

Filter display

By checking the Filters title box, you can display a title above the filter management (predefined, custom, automatic filters).

The text in square brackets can be replaced with one of the following keywords:

  • [Enquête.Nom] or [Survey.Name]: replaced by the survey name when the online report is generated.

  • [Enquête.Titre] or [Survey.Title]: replaced by the survey title (or the survey name if no title has been set).

  • [NombreObservations] or [ObservationsNumber]: replaced by the total number of survey observations.

  • [NombreObservationsFiltre] or [FilterObservationsNumber]: replaced by the number of observations that match the restricted access or the default stratum. This number is calculated when the online report is loaded and is not updated if the filter is later modified.

  • [Profil] or [Profile]: replaced by the text representing all defined filters.

  • [Session]: replaced by the text defined in the Session column of a restricted access configuration. If no restricted access is defined for the survey, the text is replaced by the values of the profile variables. If no profile variables are defined or if they contain no values for a given user, [Session] is replaced by an empty string.

The Visible filters text field allows you to select all the filters to be displayed. This setting is only applied if the Display predefined filters box is checked (see filters). Filters are represented by their number, separated by semicolons. If the filter chosen in the Start with list is not included in the Visible filters list, the online reporting will then start with the total sample. The text field remains empty if all filters are visible.

If the filters are displayed on the left or at the top, defining the Width of the filter list allows you to customize the space allocated to filters, and in particular enlarge it if the variable names or labels are very long. By default, this value is set to 120px.

If filter display is enabled, you can prevent the user from accessing the total sample (uncheck Total sample). Changing the text Total sample allows you to customize the label shown to access all observations when running the online reporting.

The Variables considered closed text field allows you to specify the set of variables for which automatic filter switching is not available. In this case, only the value list is displayed (see Using filters). Variables can be represented by their number, by a number range such as “3-12”, or by their name, separated by semicolons.

The Max. no. of items in a list text field allows you to set the maximum threshold after which automatic filters switch from a value list to a text field (see Using filters). This threshold must be a positive integer. If not, the system defaults to 255.

The Truncate labels after text field allows you to control the appearance of automatic filter labels. By default, after 25 characters the text is replaced with “…”.

The Truncate text after text field allows you to control the appearance of value texts displayed in the lists associated with automatic filters. By default, after 25 characters the text is replaced with “…”. This ensures, for example, that when filters are displayed at the top, the lists do not take up too much visual space.

Several Automatic filter usage modes are available:

  • Automatic: This is the default mode, explained in detail in Using filters. Selecting a value automatically updates the possible values in the automatic filters located below. You must click Apply to refresh the selected action’s result using the chosen filter options.

  • Manual: The sets of values associated with automatic filters do not change based on selections. The full set of possible values is always displayed. You must click Apply to refresh the selected action’s result using the chosen filter options. This option can be used if automatic filter updates take too long.

The names of the variables used in automatic filters and in variable selection lists for statistical analyses (Single Table, Cross Table, etc.) can be displayed either by the Variable Name or by the Question Label.

Command panel management

The Toolbar checkboxes allow you to select which additional tools you would like to provide the user with. You can add:

  • Options;

  • History;

  • Export;

  • Print;

  • Change the language.

Security management

It is possible to ignore certain profile variables for a configuration. To do so:

  1. Check the option Ignore some profile variables for this configuration.

  2. Select the profile variables to ignore.

By default, if restricted access is defined, it applies to all online reportings of the survey. To bypass the login screen for a given reporting (for example, to consult overall results), check Ignore restricted access for this configuration.

To anonymize the display of results, you can specify that certain variables should be hidden for the user. Variables can be represented by their number, by a number range such as “3-12”, or by their name separated by semicolons.

  1. Check the option Hidden variables.

  2. Select the variables to hide.

It is also possible to restrict access to the results by setting a condition:

  • If the number of observations (responses) is below a certain threshold (e.g., fewer than 10).

  • Or according to another condition. Example: Revenue.sum<2000000.

You can also display a custom HTML page to users instead of the results. This page may contain a message explaining that the results are not accessible due to the defined conditions (e.g., Insufficient number of responses).
