Add an action

A list of actions is available. They are grouped into the following five main categories:

  • Collect

  • View tables

  • View results

  • Display a page

  • Other actions

The action configuration window is structured as follows:

: A drop-down menu allowing you to choose the relevant action.

: A section for configuring the different options related to the selected action. These options vary depending on whether the action involves data entry, results, or consultation, for example.

: A section for "advanced configuration," where you can add queries and code.

To add an action:

  1. Go to the Configure settings section.

  2. Click on the button.

Select the action you want to use, then configure the different options.

COLLECT

Data Entry

  1. Name the action.

    The action name is the one displayed in the online report banner.

    The style of the name can be customized by clicking the pencil icon to the right of the field.

    By default, an icon is displayed. You can change it or hide it by unchecking the Icon box.

  2. Select the form to use for data entry.

    If you created several forms with Sphinx iQ3, a drop-down menu allows you to associate a specific form with the action.

    NOTE: The All forms option is selected by default. In this case, a drop-down will be displayed for the user to choose the form directly on the platform.

    If you only want to offer certain forms, select Select, then check the ones to display.

    Check the List is always visible box if you want the form list to appear automatically when accessing the reporting.

  3. Configure the remaining optional settings:

    • Automatic saving: Data entry is saved with each page change, and the page number reached is kept.

      auto=1 / auto=2 / auto=3 / auto=4

      If auto is 1, 2, or 3, this page will be automatically displayed on the next access.

      If auto is 4, the user is always redirected to the first page.

      When the questionnaire is permanently saved:

      Auto = 1: Access denied (the response is already saved).

      Auto = 2: Return to the first page.

      Auto = 3: Return to the last page.

    • Flow: Check the option Restart after saving to automatically display a new blank form after each submission.

    • Pre-fill with “Input” profile variables from restricted access.

      The questionnaire fields will be automatically filled according to the values associated with the user.

    • Pre-fill with variables (to select): Allows you to assign default values.

      EXAMPLE: Agency=Annecy&BankCode=7 pre-fills the variables Agency and BankCode.

      NOTE: Do not use quotation marks around values.

    • Choose the display language of the questionnaire.

      If the questionnaire is multilingual, the Ask option will be offered by default so that the respondent can select the language.

  4. Click on OK to confirm adding the action.

Consult observations

  1. Name the action.

    The action name is the one displayed in the online report banner.

    The style of the name can be customized by clicking the pencil icon to the right of the field.

    By default, an icon is displayed. You can change it or hide it by unchecking the Icon box.

  2. Select To consult to consult observations or To modify to allow observation modification.

  3. Select the form to use to consult observations.

    If you created several forms with Sphinx iQ3, a drop-down menu allows you to associate a specific form with the action.

    NOTE: The All forms option is selected by default. In this case, a drop-down will be displayed for the user to choose the form directly on the platform.

    If you only want to offer certain forms, select Select, then check the ones to display.

    Check the List is always visible box if you want the form list to appear automatically when accessing the reporting.

  4. Configure the remaining optional settings:

    • Limit the number of observations to display by applying a filter. By default, the total sample is displayed.

    • Allow navigation between observations with buttons and listing observations based on a variable's values. By default, observations are listed by number.

    • Allow printing an observation by checking Printing.

    • Allow deleting an observation by checking Deletion.

    • Choose the display language of the questionnaire.

      If the questionnaire is multilingual, the Ask option will be offered by default so that the respondent can select the language.

  5. Click OK to confirm adding the action.

VIEW TABLES

Observations table

The Observations table action enables you to view the study's responses in a spreadsheet.

The Variables row enables you to select the columns to display in the spreadsheet. By default, all survey variables are included, except for hidden variables (see configuration Advanced options).

To select the variables to display:

  1. Click on Manage variables.

  2. Drag and drop the variables you want to display in the spreadsheet towards the column on the right.

    NOTE: You can change the columns (variables) display order with the arrows.

    NOTE: One variable can be added multiple times.

    • You can limit the number of observations to display by applying a filter. By default, the total sample is displayed.

    • You can sort the observations according to the values of one or several variables (to be specified in the Order by field).

    • To display the column headers as the variable labels instead of the variable names, check Labels.

    • To add the observation numbers in the first column of the spreadsheet, check Numbers of variables.

    • You can also apply formatting: to do so, check Layout and then click on "Define".

    • To change the number of responses displayed per page, click the responses per page dropdown menu and select a value (available options: 50 – 100 – 200 – 500).

    • To add an observation directly in the spreadsheet, check Adding; this displays the add button at the end of the spreadsheet (top right of the page).

    • To allow the online reporting user to download the responses, check Download.

    • To allow the user to directly edit the observation values in the spreadsheet, check Modification.

    • To allow deleting an observation, check Deletion.

    • You can also allow the variable choice.

Verbatim

This action allows you to display the verbatim of one or several text variables, either as a structured list or as a table.

  1. Name the action.

  2. Select the display format for the verbatim: Structured list or Table.

  3. Select the text variables to use.

    To select the variables to display:

    1. Click onManage variables.

    2. Drag and drop the variables you want to display in the spreadsheet towards the column on the right.

      NOTE: You can change the columns (variables) display order with the arrows.

  4. (Optional) Insert signature variables if needed.

  5. (Optional) Select an evaluation variable (e.g., overall satisfaction score).

  6. (Optional) Configure the display options of the analysis:

    • Customize the title of the analysis if necessary by selecting the Custom title option and entering the title you want.

    • Check Record numbers to display a column showing the observation numbers when the user clicks on a word in the word cloud (option available only in Table view).

    • Check Comment, then enter a text to display a comment at the bottom of the analysis.

    • Check Simplify, then specify the maximum number of rows to display.

Word cloud

Your study includes a text-type variable. For a more synthetic view of this type of variable, Sphinx offers a visualization in the form of a word cloud.

NOTE: You can create a word cloud directly from the analysis environment and then link the view to an action.

  • The Variable field allows you to select the text variable.

  • You can also choose a signature variable as well as a filter variable.

  • You have the option to restrict the candidate words that will be displayed in the word cloud (based on their grammatical category).

  • You can choose to display the global word cloud or contextual word clouds (i.e., a separate word cloud for each modality of the selected context variable).

Comparative text analysis

This action enables you to compare the word cloud of a text type variable based on two distinct modalities of another variable.

  1. Name the action.

  2. Select the text variable to use.

  3. (Optional) Select signature variables.

    These variables are displayed when the user clicks on a word in the word cloud.

  4. (Optional) Select a filter variable if needed.

  5. Select the context variable and the two modalities to compare.

    You can rename the word cloud title, color and icons.

  6. Configure word cloud options:

    • Select the elements to display in the word cloud: verbs, adjectives, common names, proper names, without category.

    • Number of words to display per word cloud.

    • Minimum frequency of a word.

    • Use specific words.

    • Ignore certain words (they have to be separated by a semi-colon ";").

  7. (Optional) Configure analysis display options:

    • Customize the analysis title by selecting the option Custom title in the drop-down menu then by entering your title.

    • Check Record numbers to display a column with the number of observations when the use clicks on a word in the word cloud.

    • Check the Comment box, then enter a text to display a comment below the analysis.

Net Promoter Score

The Net Promoter Score (NPS) measures respondents’ likelihood of recommending a product or brand. Promoters score 9–10, detractors 0–6, and passives 7–8.

The NPS score is calculated by subtracting the percentage of detractors from the percentage of promoters and thus varies between -100 and +100.

  • The promoters are very satisfied and loyal. They are ready to recommend and promote the brand's products or services.

  • The passives are satisfied customers. They may come back but won't promote the brand.

  • The detractors are unsatisfied customers who are likely to talk negatively about the brand.

To display the NPS in your reporting:

  1. Name the action.

  2. Select the NPS variable to use.

  3. Enter a title and abbreviation for the analysis.

  4. (Optional) Select a variable to show NPS evolution.

  5. Select a context variable.

  6. (Optional) Check the Comparison option to display the comparison between Promoters and Detractors.

    You can customize titles, icons and the threshold from which an item is assigned to the Promoters or Detractors category (e.g., lower or higher than 10).

  7. (Optional) Check the Textual analysis box and select a text variable to display a textual analysis (word cloud and verbatim) in addition to the NPS score.

DISPLAY A PAGE

Show a web page / a file

This action enables you to give the user access to complementary files (.pdf, .html, etc.).

  1. Name the action.

  2. Select the files from the available file list.

    To create an HTML file:

    1. Click on the Manage files icon .

    2. Select Create a new HTML file.

    3. Name the file the click on Create.

    4. Click on the pencil icon to edit your HTML page.

      NOTE: You can also import an existing file from your hard disk. To do so:
      1 - Select Upload a file from disk.
      2 - Click on Choose file.
      3 - Select the .html file to import.
      4 - Click on Upload.

  3. Choose where the file or web page will open:

    • Result zone;

    • Current page;

    • New page.

Text (no action associated)

This action enables you to enter a text without associating an action. This can be useful to divide the reporting actions into sections for example.

Print / Export

This action enables you to print or to export in PDF format the selected actions.

When exporting, you can customize several options by clicking on Configure options...:

  • Orientation (Portrait / Landscape).

  • Page number and header display.

  • Records identification.

Action associated filter

This action allows you to add a filter on actions. When the filter is selected by the user, results automatically update.

  1. Name the action.

    The action name is the one displayed in the online report banner.

    The style of the name can be customized by clicking the pencil icon to the right of the field.

    By default, an icon is displayed. You can change it or hide it by unchecking the Icon box.

  2. Select the filter variable to use.

  3. Select the actions affected by the filter.

  4. (Optional) Check the Add (all) to the filter values box if you want to enable the user to select all modalities of the filter variable.

  5. Select the default value displayed when opening the reporting: First value or Last value.

Restricted access management

This action allows the user to access the list of all users that can access the online reporting. They can add, modify or delete a user.

NOTE: If restricted access management is operated via "Sphinx study", this action will not be visible when executing configuration.

    The style of the name can be customized by clicking the pencil icon to the right of the field.

    By default, an icon is displayed. You can change it or hide it by unchecking the Icon box.

  2. Select the sequence to execute. By default, all sequences will be executed.

Statistics workshop

This action allows the user to view statistical analyses such as the data set quality, summary tabulations, crosstabs, frequency distributions, and more.
