Add filters

In an online reporting, you can get results after applying filters. Those filters can come from:

  • Using period filters.

  • Using automatic filters.

  • Using survey samples defined in the Data section.

  • Using custom filters.

  • Using the Filter action in the configuration.

  • Using a profile assigned in restricted access.

The following steps describe how to select and set filters from the configuration environment that will be available at runtime.

Display a period filter

This filter allows you to filter the results of the online reporting over a custom period.

EXAMPLE: As a campsite manager, for example, you can view results from Saturday to Saturday in July, then from Saturday to Saturday of the following week, or display results for a specific weekend.

  1. Check the Period filter option.

  2. Select a date-type variable in the Start menu.

  3. Select a date-type variable in the End menu.

    NOTE: You can select the same variable for both the start and end dates.

    NOTE: Only date variables containing at least the DD/MM/YYYY format can be selected.

The period filter is displayed above the automatic filters and allows results to be filtered according to a specific time period.

Display automatic filters

Checking Display automatic filters means that at runtime, the user will have direct access to automatic filters defined in the text area.

To select the variables to display as automatic filters:

  1. Click on Manage variables.

  2. Drag and drop the variable into the column on the right.

    NOTE: Check Allow multiple select to authorize users to select several modalities in an automatic filter.

    NOTE: You can change the columns (variables) display order with the arrows.

Display the "Limit to a profile" button

Checking the Display "Limit to profile" button box allows users to access custom filter creation and automatic filters modification at runtime.

The text defines the label of the link that gives access to managing custom and automatic filters. If automatic filters are selected but the "Limit to profile" button is not enabled, the report user will not be able to modify the automatic filters.

Display predefined filters

Checking Display predefined filters means that the user will have access to predefined samples at runtime.

It is possible to choose which sample the online reporting loads by default by selecting one from the Start with list.

By allowing users to choose their automatic and/or custom filters, you can also allow them to save custom filters for further use.

To do this, check the last option Allow to save and manage filters. At runtime, by clicking on Limit to profile, users can add their custom filter to the saved filters.
