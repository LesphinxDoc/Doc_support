Setting up restricted access via an internal database

The Define users tab allows you to configure and enable restricted access. This restriction applies to all created configurations (unless Ignore restricted access for the current configuration is checked in the Security management section in the configuration's Advanced options). The purpose of restricted access is to partition access to results beforehand.

BEWARE: This authentication mode is nowadays depreciated and does not guarantee secure access. We recommend you use Sphinx Authentication.

To set up restricted access using an internal database:

  1. Go to the WebReporting section, Define users tab.

  2. Check the Active restricted access box.

  3. Select Internal data base - not recommended from the Manage restricted access by: menu.

  4. Click on Manage user access to add users and define profile variables to use if needed.

  5. Click on Add the user and enter the following elements:

    Mandatory:

    • User's login.

    • User's password.

    Optional:

    • User's email (for distribution via email).

    • Session title: Specify a label for each user (e.g., "Branch Director").

    • Authorized configurations: Define which configurations can be viewed by the user (names must be separated by semicolons ";").

    • Additional parameters: Specify additional options (e.g., define actions available to the user).

      NOTE: You can import users from a CSV file by clicking on "Import...". The file must contain the columns "Login" and "pwd".

      NOTE: It is possible to configure all users through a spreadsheet or text interface (click Table / Edition to switch from one to another).

  6. Click on Close.
