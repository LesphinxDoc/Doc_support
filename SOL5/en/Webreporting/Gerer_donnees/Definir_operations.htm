Define a list of operations

Data may be updated before accessing the results of a survey. You can use three preset operations or manually define a list of operations to run.

Upload and import a data file

This operation allows import of a data file. Depending on what you choose, this file can:

  • Add or change data;

  • Entirely replace the existing data file.

Proceed as follows:

  1. Select the Add / Modify or Replace option.

  2. Select the format of the file to import: .txt, .csv, .xls or .xlsx.

  3. (Optional) By default, automatic variables will be recalculated on the entire dataset. If you want the calculation to be applied on imported data only, check the option Recalculate automatic variables only on the imported data.

  4. (Optional) If you want to stop the import if there is incoherent data, check the Inconsistent data option.

  5. Set up execution of the operation.

    (Optional) You can click on Execute operation now... and the operation will be executed immediately.

Combine with another survey

This operation allows you to combine your survey with another.

  1. Select Combine with another survey.

  2. Select the relevant survey in the drop-down menu.

  3. Set up execution of the operation.

    (Optional) You can click on Execute operation now... and the operation will be executed immediately.

Merge with another survey

This operation allows you to merge two surveys.

  1. Select Merge with another survey.

  2. Select the relevant survey in the drop-down menu.

  3. Set up execution of the operation.

    (Optional) You can click on Execute operation now... and the operation will be executed immediately.

Manually define a list of operations

  1. Click on See the list...

  2. Click on the + button to add an operation.

  3. Select the operation.

    • Upload a file

      This operation allow you to upload a file from your hard disk that will then be added to your overall additional files (in the Advanced tab).

      1. Enter the name of the file that will be uploaded.

    • Import data

      This operation enables you to import a data file.

      1. Enter the name of the file to import (if it is in your list of additional files) or specify the source by entering the file URL if it is hosted outside your account.

      2. Select the Add / Modify or Replace option.

      3. Select the format of the file to import: .txt, .csv, .xls or .xlsx.

      4. (Optional) By default, automatic variables will be recalculated on the entire dataset. If you want the calculation to be applied on imported data only, check the option Recalculate automatic variables only on the imported data.

      5. (Optional) If you want to stop the import if there is incoherent data, check the Inconsistent data option.

    • Export data

      This operation enables you to export your survey's data.

      1. Enter the name of the file data will be exported to.

        EXAMPLE: File_name.csv

        BEWARE: This file must already be in your list of additional files.

    • Combine with another survey

      This operation allows you to combine data (spreadsheet rows) from two surveys. Only variables from the reference survey will be retained.

      It is useful for centralizing results in a single dataset for analysis. In particular, it allows you to:

      • Save time by avoiding manual entry or copying.

      • Perform cross-sectional analyses on several populations that responded to the same questionnaire.

      • Compare results according to the origin of the data.

      To configure the operation:

      1. Select the survey to be combined from the drop-down menu.

      2. Select the identification variable.

        This variable is used to indicate the original survey of the imported observations.

        It will be pre-filled with the name of the survey to be combined. It must have been created beforehand and must be of the single closed type.

    • Merge with another survey

      This operation allows you to combine variables from two surveys. If one of the surveys contains additional variables, these will be added to the survey to which the merge is applied. Observations from identical surveys will also be merged.

      EXAMPLE: You have conducted two separate surveys with the same target audience: - a survey on purchasing habits, - a survey on brand awareness. By merging the two, you obtain a single file that allows you to cross-reference responses and analyze, for example, whether purchasing habits influence brand perception.

      1. Select the survey to be merged from the drop-down menu.

      2. Select the key variable.

      This variable uniquely identifies each respondent or observation in both surveys. It ensures that responses relating to the same person or entity are correctly merged into the data file.

    • Deduplicate

      This operation identifies duplicates in a data file and automatically deletes the most recent observation, or observations, for each duplicate detected.

      A duplicate is defined as two (or more) observations sharing the same value for one or more key variables.

      • Select the variables on which the deduplication operation will be based. To do this:

        1. Click on Manage variables.

        2. Drag and drop the relevant variables to the right-hand column.

          NOTE: The display order of the columns (variables) can be changed using the up and down arrows.

    • Recalculate variables

      This operation allows you to:

      • Recalculate automatic variables and, if necessary, apply textual and semantic analysis calculations.

      • Perform a custom calculation.

      To recalculate variables:

      1. Select Calculate.

      2. If necessary, check Apply text analysis and semantic calculations.

      To run a calculation:

      1. Select Execute a calculation.

      2. Enter the formula to be used in the field provided.

    • Delete observations

      This operation (Records delete:) allows you to delete all observations or only those associated with a specific profile.

      • To delete all observations, select All the records.

      • To delete observations linked to a profile, select Define a profile and then specify the profile to use.

        EXAMPLE: [Gender] = “Male”

    • Update a file

      This feature allows you to replace an existing file with its most recent version in your survey.

      1. Enter the update URL. This is the link to the latest version of the file you want to use.

      2. Enter the exact name of the file to be updated in the File Name field.

        EXAMPLE: My_file.xlsx

      3. Choose the folder where you want to save the file in your overall list of additional files: Resources or Advanced folder.

    • Lexical analysis

      This operation allows you to redefine nouns, verbs, and adjectives for each text variable that has been previously lemmatized (MYVAR_L, MYVAR_WORDS, etc.)

    • FTP transfer

      This operation allows you to send or download files.

      BEWARE: To configure this operation, your IT department will need to fill in certain technical fields, such as the host, port, or encryption type.

      NOTE: If an error occurs during the FTP transfer, please contact technical support.

    • Advanced functions

      Advanced features allow you to customize certain data management operations. These advanced features are called “macros.”

      BEWARE: This feature requires advanced programming knowledge. We recommend that you seek assistance from your IT department to help you implement it.

      Advanced functions allow you to:

      • Import a data file (to automatically update dashboards);

      • Merge two surveys (to integrate additional data into a survey);

      • Combine several surveys (to analyze them together);

      • Deduplicate survey observations (to remove duplicate entries);

      • Group survey observations (to change the statistical unit by grouping observations with the same characteristic);

      • Export data (table, text file, etc.)

      The macros are written in XML. A file containing the technical specifications of the available functions is available.

      Group

      This feature allows you to change statistical unit. All observations with the same identifier in the source survey will result in a single observation in the survey.

      For each variable, you can choose the grouping mode:

      • Ignore,

      • Keep the first or last value encountered,

      • Keep the minimum or maximum value,

      • Concatenate into a text variable,

      • Calculate the average or sum (numeric variables),

      • Merge into a multiple closed variable (closed variables).

      EXAMPLE: The “visits” survey is grouped into a patient survey. The patient ID is "PatientID", the last value is kept for "Gender" and "DateofBirth", the "Diagnoses" are concatenated, the sum is calculated for the "MedicationAmount", and the "MainReason" variable is a single closed variable that becomes a multiple closed variable in the grouped survey.

<task id="regrouper" function="dupgroupby">
      <input>
      <survey>visits</survey>
      <variables>PatientID</variables>
      <group> <!--op=keepfirst/keeplast/minimum/maximum/average/sum/mergetext/mergemultiple-->
      <groupby name="Gender" op="keepfirst" />
      <groupby name="DatOfBirth" op="keepfirst" />
      <groupby name="Diagnoses" op="mergetext" />
      <groupby name="MedicationAmount" op="sum" />
      <groupby name="MainReason" op="mergemultiple" />
      </group>
      </input>
      <output>
      <survey>patients</survey>
      </output>
      </task>

  4. Name the operation.

  5. (Optional) Give the operation a sequence number in the seq. field if you want to execute operations separately.

  6. Click on OK to confirm.

  7. Set up execution of the operation.

    (Optional) You can click on Execute operation now... and the operation will be executed immediately.

Manage the order and state of operations:

You have the following options to organize operations:

  • Move an operation up or down the list to change the order of operations at runtime.

    NOTE: When multiple operations are defined, their order in the list is important. For example, running the Recalculate all variables operation before importing data won't be useful since the data is not available yet.

  • Delete an operation by clicking on the cross icon.

  • Temporarily disable an operation by unchecking the Active box: the operation will be ignored at runtime.
