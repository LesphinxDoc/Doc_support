Send a report by email

Sending a report by email allows you to provide a list of recipients with access to a report.

NOTE: You can send a report only if its access is set to Restricted Access.

To send a report by email, you must:

  • Write the message;

  • Create an invitation;

  • Configure the sending settings.

Write the message

To write an invitation email:

  1. From the WebReporting section, click Send.

  2. Go to the Messages section of the Webreporting - restricted access channel.

    NOTE: By default, an invitation message is available. You can edit and use it, or duplicate it if necessary.

  3. If you duplicate the default message, name your message, then click Duplicate.

    The editor opens. Edit your message content.

The message editor is divided into 3 areas:

  • The left pane allows you to select custom links, sections, or content to drag and drop into the message.

  • The workspace allows you to add the email subject, the sender's name and email address, write your message, preview it on desktop, tablet, and mobile devices, and access other additional actions.

    Add a subject, sender name, and sender email address

    Enter the email subject, enter the sender's name, and select the sender's email address.

    • Email subject: Enter the email subject.

      EXAMPLE: "We value your feedback" for a satisfaction survey.

    • Sender name: This field is optional; it stands for the text displayed in the FROM field of your email.

    • Email sender: Email address that will be used to send the email.

      Add a sender email address

      To add a new email address, you need to click on the + button and enter the email address.

      A confirmation email is sent to this address. The address need to be confirmed before you can use it a the sender email address.

      Click on the gear icon to manage sender email addresses - you can delete them or resend the confirmation email.

      NOTE: Please follow these steps to add a sending domain.

  • The right pane allows you to edit the properties of the selected elements.

If you start from a blank message, first add columns so that you can insert text, images, and other elements:

  1. Drag and drop the 1, 2 or 3 Column(s) element from the Section area in the left pane.

    Click the image to view the animation

  2. Insert the elements you want to include in your message from the Custom links and Content sections into the corresponding columns.

    Custom links

    • Report button: allows you to add a button that provides access to the report.

    • Report link: allows you to add a link that provides access to the report.

    • Report image: allows you to add a clickable image that provides access to the report.

    • View online version: allows recipients to access the online version of the email if the content is not displayed correctly in their email client.

    • Unsubscribe: allows recipients to unsubscribe from future sends.

    Content

    • Text: allows you to add a text area.

      NOTE: You can rephrase, improve clarity, correct grammar, or enrich your content using artificial intelligence. Learn more about AI-assisted text editing.

    • Button: allows you to add a button that links to a website.

      You can customize the button from the Element properties pane.

    • Image: allows you to insert an image from your computer or a URL.

    • GDPR: allows you to insert a GDPR notice to inform users about the collection and use of their personal data.

    Select an element to access its properties in the right pane. You can modify:

    • The element alignment: align left, right, center, or justify.

    • Padding: allows you to adjust the position of the element relative to its parent element.

      EXAMPLE: The "No" button has a 25 px top and bottom padding, while the "Yes" button has no padding.
      The position of each button is therefore different inside the column.

    • Formatting (font, font size, color, width, background color, border, etc.).

Click Save to save your changes.

A message verification window appears if an element is not configured correctly. Learn more about message verification.

Create an invitation

  1. From the WebReporting section, click Send.

  2. Click Manage my sendings.

  3. Click Create my first invitation (or Invite if sends have already been created).

  4. Name your send.

  5. Select the scheduling type.

    • Immediate or scheduled sending: allows you to send the invitation immediately or schedule it for a later date.

    • Automated sending: allows you to configure automatic sends.

  6. Click Apply.

    Your invitation is now created. You can proceed to writing the message to send.

Configure the sending settings

  1. Go to the sending configuration step of an invitation.

  2. The default message is selected automatically. To use another message, click Choose another message, then select the message you want to use.

  3. Select the recipients to contact.

    All recipients: allows you to contact all recipients in the list.

    Custom selection: allows you to manually select the recipients to contact.

    Click to preview the list of recipients matching the selected type.

    Filter the selection

    You may need to filter recipients based on data from the import file, such as a subscription type, status, or date.

    To filter the selection:

    1. Click Add a filter.

    2. Click Add a filter in the Filter recipients dialog box.

    3. Select the variable to use and set the criteria.

      NOTE: You can define multiple filters by combining conditions with the AND / OR operators.

    4. Click Validate.

      The number of recipients to contact is updated automatically.

  4. Select the sending type:

    • Send now: the email is sent immediately.

    • Send later: the email is sent on the specified date and time.

    • Automated sending: allows you to schedule automatic sends.

  5. (Optional) Modify the regulation options if necessary. These options help optimize deliverability, especially for large email campaigns.

  6. Click Confirm.

    A confirmation window appears with a summary of the send and, where applicable, warning messages.

  7. Select I accept the terms of use, then click Confirm.

When users sign in for the first time, they are prompted to create a password by clicking Activate your access. This password is valid for all reports they are authorized to access.

NOTE: Credentials are shared across the entire server. If an existing user is invited to sign in to another report from another survey on the same account or another account, they can sign in directly using their existing credentials.
