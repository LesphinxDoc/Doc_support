Create a study by importing data

Explore and analyze data from different data sources. To create a new study by importing files, proceed as follows:

  1. From the home page, click on the New study button.

  2. Select the type of import to use depending on the source of your data.

    Available data sources: CSV file, XLSX file, SPSS file and Triple-S file.

    IMPORT DATA FROM A CSV FILE

    To import data from a CSV file:

    1. From the data import interface, click on ‘CSV file’.

    2. Then click on the ‘Select file...’ button to add your data file.

      NOTE: The data file must be in .csv or .txt format.

    3. Set the import options before finalizing the import of your file.

      • Choose the type of separator: comma, semicolon or tab. The semicolon separator is selected by default.

      • The encoding: Automatic, windows-1252, utf-8, utf-16 and utf-16BE.

      • Values detection: This option enables date and decimal formats to be correctly interpreted according to the selected regional format.

        Suppose your data file contains dates displayed in US format, i.e. MM/DD/YYYY.

        To interpret them correctly in French format (DD/MM/YYYY), select ‘Français’ from the Values detection menu.

      • Language: Select the language of your study.

      • The second line contains the variable labels: check this option if you have inserted the labels of the variables in the 2nd line.

        Once this option is checked, the second line (containing the labels of the variables) will disappear and each label will be assigned to the corresponding variable.

      • Ignore lines at the beginning

        This option allows you to ignore x lines at the beginning.

        EXAMPLE: In the CSV file below, the first two rows contain the names of the survey and of the survey administrator and the third row contains the names of the variables.


        When importing this file, the name of the survey will be considered as a variable name since the first row is intended for variable names.
        In this case, you must ignore the first two rows so that the variable names are displayed on the first row.

        Data preview after deleting the first two rows

      • Detection of multiple-choice questions

        • In Sphinx software, the responses to multiple-choice questions are contained in a single column and are separated by semicolons. If they are ordered, the order determines the rank. In your file, if each answer option corresponds to a column, it is advisable to group them together in a single column before importing the file or using the options below.

          • Merge columns with consecutive names

            This option groups in a single column the columns with consecutive header names such as: choice1, choice2, choice3 or choice_1, choice_2, choice_3. The software will then be able to treat this column as a closed multiple-choice question.

          • Merge columns with the same name

            This option groups columns with strictly identical header names into a single column. The software will then be able to treat this column as a closed multiple-choice question.

          • Consider a single column containing a separator

            This option allows you to identify columns containing answer options separated by a sign of your choice (for example ";" or ",") as multiple-choice questions.

      • Parameters of a variable

        During the import step, from the data preview, click on the pencil next to each variable to display its parameters:

        It is possible to change the name / label of the variable as well as the type of data.

        Click the Validate button to save the changes made.

    4. Give your study a name and click the Create study button to finalize the data import step.
