Create an account

There are three ways of creating an account:

Creating an account manually, creating it by importing a file or creating it using access keys.

  1. Log in to your administrator account.

  2. Click on Administration (top right of your screen).

  3. From this interface, choose the method for creating the account:

    Create a user account manually

    1. Click on the Create an account button.

    2. Fill in the required information.

      • Username (Only letters, numbers, hyphens and underscores are accepted).

      • Email address.

      • Opening / closing date.

        NOTE: If the opening date defined is different from the account creation date, the user will receive the creation email on the date specified in the "Opening date" field.

    3. (Optional) Fill in information about the profile: first name, last name, phone number, company, language.

    4. Determine the rights to grant to the account.

      You can activate or deactivate certain rights such as AI assistants, or external data import.

      The distribution of credits / units (responses, emailing, SMS, codification on the fly and AI) depends on the number of accounts that can be created.

      EXAMPLE: For an administrator account that can create 10 user accounts and has 50,000 AI units, each account created will have 5,000 AI units granted by default (50,000/10).

      To activate AI consent of the account to create, you need to accept the general conditions specific to AI assistants.

      After checking the "AI Consent" option, proceed to the following steps:

      Acceptance of the general conditions specific to AI assistants is required.

      1. Read the specific terms and conditions for AI Assistants carefully.

      2. Check the following box:

        • "I acknowledge that I have accepted without reservation the ‘AI Assistant’ addendum displayed above and I declare that I am the legal representative of the holder of this account or have the authority to represent them validly and that I accept liability in the event of any false declaration".

      3. Click on the I accept button.

    5. Set the limits:

      • Number of possible responses by survey.

      • Maximum number of questions by survey.

      • Maximum number of surveys that can be created.

    6. Click on the SAVE button.

      The account is now created, and a validation email is immediately sent to the address associated with the account.

      The user must click on the link received by email to confirm their email address and set a password to access the account.

      NOTE: The link is only valid for 96 hours.

    Create accounts by importing a file

    Creating accounts by importing files saves you precious time when you have several users.

    If you need to create accounts for different groups of users (different classes within a school, etc.). You can differentiate between them by adding a prefix to the identifier (in the ‘Login’ column). This will make it easier to find and identify accounts that need to be modified or deleted for a given group at a later date.

    EXAMPLE: In this simplified example, we will import 3 groups of users, one with the prefix ‘A-’, another with the prefix ‘B-’ and the last with the prefix ‘C-’.

    All you then need to do is perform a search in the Identifier field based on the prefix to find all the accounts in the relevant group.

    Click on the image above for an animated preview

    To create accounts by importing a file, proceed as follows:

    1. Click on the little arrow and then on Import accounts.

    2. Click on the Select file... button to upload the file you want to use.

      NOTE: Authorized file type (".txt", ".csv", ".xlsx").

      The file must contain the following two columns:

      • Login: User ID.

      • Email: Account email address.

      Optional columns:

      • firstname / lastname: First name & surname of user.

      • startdate: Account opening date.

        This column should be used when you want to schedule the opening of an account for a later date.

        When an account is created, users must confirm their email address and set their password by clicking on the link sent to them by email. The password is only valid for 96 hours.

        It is therefore recommended to:

        • Create accounts at the beginning of the week, rather than on Fridays, as users tend not to check their email on the weekend.

          or

        • Determine an opening date in the startdate column, which will allow the confirmation email to be sent on this date and not on the account creation date (when the file is imported).

          EXAMPLE: Accounts will be created on Friday 20/10/2023. Users will be notified by email on Monday 23/10/2023 (opening date) as configured in the file to be imported (see screen-shot below).

      • enddate: Account closing date.

        NOTE: If no date is entered in the enddate field, or if the latter is not present in the file to import, the account will inherit the administrator account's closing date.

      You can download a sample file by clicking on the sample_admin_import_accounts.xlsx.

      The first row is always considered to contain the column names.

    3. A summary will be displayed following the import (number of users to be created, error message/warning in the event of a problem, for example: a user name that already exists).

    4. Click on the Create x account(s) button to confirm the creation.

    Create accounts using access keys

    1. Click on the Access keys button.

    2. Click on the Generate new access keys button.

    3. Enter the number of keys you wish to generate, then click OK to confirm.

      The keys generated will be displayed in the table.

    4. Click on the Send keys by email button.

    5. Enter the e-mail addresses of future users.

      NOTE: You must enter only one email address per row.

      EXAMPLE: In our example, we have 4 access keys available, which means that if we insert 15 email addresses, only the first 4 will be taken into account for sending.

      The Use the keys available from those distributed by email option authorizes the reuse of expired keys (following the failure to create an account after 96 hours) in your shipment.

    6. Click OK to confirm that the keys have been sent.

      Information about each key generated can be viewed directly from the table.

      Date on which the key was last distributed/email address used when it was last distributed, name of the account that activated the key, status of the key (key used or not).

      If required, the key list can be exported in .xlsx format by clicking on the Export list of keys button.

      NOTE: The export takes into account the sorting/filters applied in the table.

    Procedure for creating an account using an access key (user end)

    Below is an example of the e-mail that will be sent to the user after a key has been sent.

    The user must:

    1. Click on the "Sign Up" link in the e-mail.

      NOTE: Link expires after 96 hours.

    2. Fill in the information requested in the form.

    3. Click on the Create my account button.

    4. Click on the confirmation link sent by e-mail to validate the account.
