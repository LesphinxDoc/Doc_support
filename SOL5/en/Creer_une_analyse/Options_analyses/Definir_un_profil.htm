Define a filter

Defining a filter allows you to designate the modalities or values of one or more variables that will be applied as a filter to a selected analysis object. To do so, proceed as follows:

  1. Select your analysis.

  2. In the Advanced tab, calculation category, next to define a filter, click .

    NOTE: It is also possible to use an analysis profile already done previously by selecting .

  3. Give a name to the profile to be created.

  4. Choose the editing mode to be used to fill in the profile.

EXPRESSION EDITION

After selecting the expression edit mode from the drop-down menu, you can edit the profile yourself.

To do this, when defining the profile for the qualitative variables, you must name the variable, followed by the « = » operator, then the modality to be applied as a filter in quotation marks. For quantitative variables, you must name the variable, followed by a mathematic operator such as « > » or « <= », and then the value to apply as a filter. If you want to fill in several filter variables, you must separate them by a Boolean operator « and » / « or ».

EXAMPLE: In a tourism survey and in the case of a food expenditure analysis, one may want to process only a portion of the total sample. If one wishes to study the food expenditures of women over 35, whose PSC is "employee", the profile can be named as « Women employees over 35 » and the profile (filter) as « [PSC] ="Employee" and [Gender] = "Woman" and [Age]> = 35 ».

MULTICRITERIA EDITION

After selecting the multicriteria editing mode from the drop-down menu, you can configure the profile yourself.

To do this, you must set the filter variable and, for qualitative variables, type the values and / or the ranges of values that will be applied as filters, separated by semicolons. For quantitative variables you must select the modality (s) that will be applied as a filter.

You can add or delete a filter variable and if you want to fill in several filter variables, you must separate them by a Boolean operator « And »  / « Or » from the drop-down menu.

EXAMPLE: In a tourism survey and in the case of a food expenditure analysis, one may want to process only a portion of the total sample. If you want to study the activities of women aged between 25 and 40 years, you can name the profile as « women between 25 and 45 years » and then select the filter variables.

The definition of filters can also be applied in multiple tables. To do this:

  • Right click on the table to modify and click on Edit.

  • Click on the button corresponding to each variable to define a filter.
