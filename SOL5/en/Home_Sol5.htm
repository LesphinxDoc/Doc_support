What's new in Sphinx Online v 5.2.12

MAJOR NEW FEATURES

  • New RCS distribution channel: A new channel is now available for sending invitations and reminders as rich messages combining a title, text, an image, and a call-to-action button.

  • New WhatsApp distribution channel: Create an outbound WhatsApp channel, select a Meta-approved message template, map its variables to merge fields or the survey link, and track the status of each recipient.

  • New Recommendation Impact Score matrix: Create an analysis that cross-references themes identified through coding with a satisfaction score to identify priority drivers. Themes can be filtered by a minimum response count, and shared orientations can be adjusted using a satisfaction scale.
