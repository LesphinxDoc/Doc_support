Manage variables of a data import study

You can manage the variables in your study after import (this section only applies to studies that have been imported from data files (Excel, Csv, SPSS, Triple S). Several actions are possible:

  • reorganize the list of variables / parts / modalities.

  • Rename variables.

  • Change the data type.

  • Add new modalities.

  • Delete variables.

To do so:

  1. Go to the Structure section, Variables tab.

  2. To carry out the actions listed below, click on Unlock.

    reorganize THE LIST OF VARIABLES

    • Use drag&drop to move a part/variable.

    NOTE: The numbering of the variables is automatically updated according to the new display order.

    RENAME VARIABLES, CHANGE DATA TYPE, ADD MODALITIES

    • Select a variable to modify its name, label, data type and modalities from the panel on the right.

    • To change the data type of a variable, click on the drop-down menu provided and choose another type.
