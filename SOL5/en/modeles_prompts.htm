AI Prompts: Guide and Templates

Practical Guide: Easily creating a prompt to generate a variable with AI

Creating a prompt may sound technical, but in practice it simply means clearly explaining to the AI what you expect.

This guide is designed to help you step by step when writing effective prompts.

1. What is a prompt used for?

A prompt is an instruction that tells the AI what you want it to do. It explains the task to perform, the information to use, and the format of the result to produce.

A well-written prompt ensures that the result is clear, consistent, and aligned with your needs.

2. The essential components of a good prompt

A good prompt follows a simple and logical structure: optional context, main instruction, rules to follow, and the expected output format.

  • Context (optional but helpful)

    The context helps the AI understand what the variable is about, without telling it what to do. It provides background information or a general scope for the task.

    It may include a topic, a concept, or a domain related to the variable.

    EXAMPLE: HR topic, user experience, service perception.

  • The task

    The task describes what the AI must do. It is the concrete action to perform based on the input data.

    EXAMPLE: analyze a text, detect a tone, select a category from a list, assign a score based on defined criteria.

  • The rules

    Rules explain how the AI should make its decision. They define the criteria, conditions, and boundaries needed to ensure a consistent result.

    EXAMPLE: describe possible categories, define thresholds, explain what to do if an answer is ambiguous.

  • The expected output format

    The expected output format specifies exactly how the result should look.

    This is essential to ensure that the variable can be used correctly in your analysis.

    EXAMPLE: a single number, a fixed label, a list, one or multiple values, a text format (lowercase / uppercase), etc.

3. Tips for an effective prompt

  • Keep it clear and direct: there is no need to over complicate things.

  • Explain categories or levels clearly to avoid misinterpretation.

  • Specify what is not allowed (justifications, reformulations).

  • Avoid vague or subjective terms (“a lot”, “long”, “not clear enough”, etc.)

  • Make sure that none of the rules contradict each other.

  • Test your prompt to ensure it works as expected.

- If the content mainly expresses positive appreciation → Positive
