Créer une campagne

  1. Cliquez sur le bouton du menu Campagnes puis Nouvelle campagne.

  2. Renseignez le nom de votre campagne, les mots-clés qui lui sont associées et une description dans toutes les langues nécessaires.

    REMARQUE : Vous pouvez choisir ces langues dans la Configuration de ma communauté puis dans la partie Général.

  3. Sélectionnez l'enquête à diffuser.

    • Enquête Sphinx : Sélectionnez l'enquête associée depuis la liste des enquêtes présentes sur le compte.

    • Activité externe : Indiquez l'URL de votre enquête issue d'un autre outil externe dans le champ URL externe.

      Votre enquête externe doit obligatoirement rediriger les répondants vers Community à la fin du questionnaire.

      Configuration des URLs de callback pour l'enquête externe

      Votre enquête externe doit obligatoirement rediriger les répondants vers Community à la fin du questionnaire.

      • URL minimale (sans gestion de quotas), à utiliser si vous ne gérez pas les quotas dans votre enquête :

        • URL de callback obligatoire

      • URLs avancées (avec gestion de quotas), à utiliser si votre enquête externe gère les quotas :

        • URL pour l'enquête terminée ;

        • URL pour le Quota full ;

        • URL pour le Screen out.

    REMARQUE : Vous pouvez affecter automatiquement une valeur à certaines variables de votre questionnaire à l’aide des paramètres de requête complémentaires.

  4. Paramétrez les propriétés de votre campagne :

    • Type de réponse :

      • Unique : les répondants ne peuvent répondre qu’une seule fois au questionnaire ;

      • Unique et modifiable : les répondants peuvent modifier leurs réponses après enregistrement ;

      • Unique et anonyme : les identifiants des répondants ne seront pas enregistrés dans l’enquête et n'apparaîtront pas dans les données de votre communauté.

    • Rétribution : attribuez le nombre de points que récupéreront les membres en répondant au questionnaire ;

      REMARQUE : Le répondant doit enregistrer ses réponses afin d’obtenir sa rétribution.

    • Ouverture : ouvrez, fermez, ou définissez une période d'ouverture pour la campagne pendant laquelle les membres pourront répondre au questionnaire.

    • Inscriptions : inscrivez automatiquement les nouveaux membres à cette campagne et/ou empêchez l'inscription des membres inscrits à cette campagne à une autre campagne tant qu'ils n'ont pas répondu au questionnaire.

      REMARQUE : Il est possible de bloquer le répondant pendant x jours : les membres inscrits à cette campagne exclusive ne peuvent pas être sélectionnés pour une nouvelle inscription pendant X jours après avoir répondu au questionnaire.

  5. Choisissez l'action à effectuer après enregistrement des réponses du membre :

    • Afficher le message de remerciement de l'enquête ;

    • Afficher un message personnalisé ;

    • Rediriger vers une URL ;

    • Renvoyer vers le formulaire ;

    • Renvoyer vers l'espace membre.

  6. Cliquez sur Créer pour valider la création de votre campagne.
