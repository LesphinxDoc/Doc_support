Définir des opérations à exécuter

L'accès aux résultats d’une enquête peut être précédé par une mise à jour des données. Vous avez la possibilité d'utiliser trois opérations prédéfinies ou de définir manuellement une liste de plusieurs opérations à exécuter.

Télécharger et importer un fichier de données

Cette opération permet d’importer un fichier de données. Selon votre choix, ce fichier pourra :

  • Ajouter ou modifier des données ;

  • Remplacer entièrement le fichier de données existant.

Étapes à suivre :

  1. Sélectionnez l’option Ajouter/modifier ou Remplacer, selon l’action souhaitée.

  2. Choisissez le format de fichier à importer : .txt, .csv, .xls ou .xlsx.

  3. (Facultatif) Par défaut, les variables automatiques seront recalculées sur l’ensemble des données.

    Si vous souhaitez effectuer ce calcul uniquement sur les données importées, cochez l’option Recalculer les variables automatiques uniquement sur les données importées.

  4. (Facultatif) Si vous souhaitez bloquer l’importation en cas de données incohérentes, cochez l’option Données incohérentes.

  5. Paramétrez l'exécution de l'opération.

    (Facultatif) Vous pouvez cliquer sur Exécuter l’opération maintenant... pour lancer immédiatement l’opération de votre côté.

Rassembler avec une autre enquête

Cette opération permet de rassembler l'enquête avec une autre.

  1. Sélectionnez Rassembler avec une autre enquête.

  2. Sélectionnez l'enquête concernée depuis le menu déroulant.

  3. Paramétrez l'exécution de l'opération.

    (Facultatif) Vous pouvez cliquer sur Exécuter l’opération maintenant... pour lancer immédiatement l’opération de votre côté.

Fusionner avec une autre enquête

Cette opération permet de fusionner l'enquête avec une autre.

  1. Sélectionnez Fusionner avec une autre enquête.

  2. Sélectionnez l'enquête concernée depuis le menu déroulant.

  3. Paramétrez l'exécution de l'opération.

    (Facultatif) Vous pouvez cliquer sur Exécuter l’opération maintenant... pour lancer immédiatement l’opération de votre côté.

Définir manuellement une liste d'opérations

  1. Cliquez sur voir la liste.

  2. Cliquez sur le bouton + pour ajouter une opération.

  3. Sélectionnez l'opération à paramétrer.

    • Télécharger un fichier

      Cette opération permet de télécharger un fichier depuis votre disque qui sera par la suite ajouté aux fichiers complémentaires (onglet Avancés).

      1. Indiquez le nom du fichier qui sera téléchargé.

    • Importer des données

      Cette opération permet d'importer un fichier de données.

      1. Indiquez le nom du fichier à importer (présent dans vos fichiers complémentaires) ou précisez la source de données en saisissant l’URL du fichier s’il est hébergé en dehors de votre compte.

      2. Sélectionnez l’option Ajouter/modifier les observations ou Remplacer les observations, selon l’action souhaitée.

      3. Choisissez le format de fichier à importer : .txt, .csv, .xls ou .xlsx.

      4. (Facultatif) Par défaut, les variables automatiques seront recalculées sur l’ensemble des données.

        Si vous souhaitez effectuer ce calcul uniquement sur les données importées, cochez l’option Recalculer les variables automatiques uniquement sur les données importées.

      5. (Facultatif) Si vous souhaitez bloquer l’importation en cas de données incohérentes, cochez l’option Données incohérentes.

    • Exporter les données

      Cette opération permet d'exporter les données de votre étude.

      1. Indiquez le nom du fichier dans lequel les données seront exportées.

        EXEMPLE : Nom_du_fichier.csv

        ATTENTION : Ce fichier doit être présent dans la liste des fichiers complémentaires.

    • Rassembler avec une enquête

      Cette opération permet de rassembler les données (lignes du tableur) de deux études. Seules les variables de l'étude de référence seront conservées.

      Elle est utile pour centraliser les résultats dans un seul jeu de données pour analyse. Elle permet notamment de :

      • Gagner du temps en évitant une saisie ou une recopie manuelle.

      • Réaliser des analyses transversales sur plusieurs populations ayant répondu à un même questionnaire.

      • Comparer les résultats selon l’origine des données.

      Pour configurer l'opération :

      1. Sélectionnez l'enquête à rassembler depuis le menu déroulant.

      2. Sélectionnez la variable d'identification.

        Cette variable permet d’indiquer l’étude d’origine des observations importées. Elle sera préremplie avec le nom de l’étude à rassembler.

        Elle doit avoir été créée au préalable et doit être de type fermée unique.

    • Fusionner avec une enquête

      Cette opération permet de rassembler les variables de deux enquêtes. Si l’une des enquêtes contient des variables supplémentaires, celles-ci seront ajoutées à l’enquête sur laquelle la fusion est effectuée. Les observations provenant d’enquêtes identiques seront également fusionnées.

      EXEMPLE : Vous avez réalisé deux enquêtes distinctes auprès de la même cible :
      - une enquête sur les habitudes d’achat,
      - une enquête sur la notoriété de votre marque.
      En fusionnant les deux, vous obtenez un fichier unique permettant de croiser les réponses et d’analyser, par exemple, si les habitudes d’achat influencent la perception de la marque.

      1. Sélectionnez l'enquête à fusionner depuis le menu déroulant.

      2. Sélectionnez la variable clé.

        Cette variable permet d’identifier de manière unique chaque répondant ou observation dans les deux enquêtes. Elle garantit que les réponses concernant la même personne ou entité sont correctement fusionnées dans le fichier de données.

    • Dédoublonner

      Cette opération permet d’identifier les doublons présents dans un fichier de données et de supprimer automatiquement l’observation la plus récente, ou les observations les plus récentes, pour chaque doublon détecté.

      Un doublon est défini comme deux (ou plusieurs) observations partageant la même valeur pour une ou plusieurs variables clés.

      • Sélectionnez les variables sur lesquelles l’opération de dédoublonnage se basera. Pour ce faire :

        1. Cliquez sur Gérer les variables.

        2. Glissez déposez les variables souhaitées vers la colonne de droite.

          REMARQUE : L’ordre d’affichage des colonnes (variables) peut être modifié à l’aide des flèches haut et bas.

    • Recalculer les variables

      Cette opération permet :

      • De recalculer les variables automatiques et, si nécessaire, d’appliquer les calculs d’analyse textuelle et sémantique.

      • Ou d’exécuter un calcul personnalisé.

      Pour recalculer les variables :

      1. Sélectionnez Recalculer les variables.

      2. Si nécessaire, cochez Appliquer les calculs d’analyse textuelle et sémantique.

      Pour exécuter un calcul :

      1. Sélectionnez Exécuter un calcul.

      2. Renseignez la formule à utiliser dans le champ prévu à cet effet.

    • Supprimer des observations

      Cette opération vous permet de supprimer l’ensemble des observations ou uniquement celles associées à un profil spécifique.

      • Pour supprimer toutes les observations, sélectionnez Toutes les observations.

      • Pour supprimer les observations liées à un profil, sélectionnez Définir un profil puis indiquez le profil à utiliser.

        EXEMPLE : [Sexe] = "Un Homme"

    • Mettre à jour un fichier

      Cette fonctionnalité vous permet de remplacer un fichier existant par sa version la plus récente dans votre étude.

      1. Saisissez l’URL de mise à jour. Il s’agit du lien vers la dernière version du fichier que vous souhaitez utiliser.

      2. Renseignez le nom exact du fichier à mettre à jour dans le champ Nom du fichier.

        EXEMPLE : Mon_fichier.xlsx

      3. Choisissez le dossier dans lequel vous souhaitez enregistrer le fichier dans votre liste de fichiers complémentaires : Ressources ou Avancés.

    • Analyse lexicale (verbes, noms, adjectifs)

      Cette opération permet de redéfinir les noms, verbes, adjectifs pour chaque variable texte préalablement lemmatisée (MAVAR_L, MAVAR_MOTS...).

    • Transfert FTP

      Cette opération permet d'envoyer des fichiers ou de télécharger des fichiers.

      ATTENTION : Le paramétrage de cette opération requiert l’intervention de votre service informatique afin de renseigner certains champs techniques, tels que l’hôte, le port ou le type de chiffrement.

      REMARQUE : En cas d'erreur lors du transfert FTP, merci de prendre contact avec le support technique.

    • Fonctions avancées

      Les fonctions avancées permettre de personnaliser certaines opérations de gestion de données. Ces fonctions avancées sont appelées des "macros".

      ATTENTION : Cette fonctionnalité requiert des connaissances avancées en programmation. Nous vous recommandons de solliciter l’assistance de votre service informatique afin de vous accompagner dans sa mise en œuvre.

      Les fonctions avancées permettent de :

      • Importer un fichier de données (pour mettre à jour automatiquement des tableaux de bord)

      • Fusionner deux enquêtes (pour intégrer des données complémentaires dans une enquête)

      • Rassembler plusieurs enquêtes (pour les dépouiller conjointement)

      • Dédoublonner les observations d'une enquête (pour supprimer les saisies en double)

      • Regrouper les observations d'une enquête (pour changer l'unité statistique en regroupant des observations ayant une même caractéristique)

      • Exporter les données (tableau, fichier texte, ...)

      Les macros sont écrites en XML,un fichier contenant les spécifications techniques des fonctions disponibles est à votre disposition.

      Importer

      La fonction permet d'importer des données externes pouvant provenir d'un fichier (.txt, .csv, .xls ou .xlsx) stocké localement sur le serveur ou bien d'une URL ou encore d'une base de données.

      EXEMPLE : 1 Importation d'un fichier Excel : les données sont sur la première feuille du fichier, les noms des colonnes ne sont pas les mêmes dans l'enquête et le fichier Excel. Les données remplacent les données existantes.

      Regrouper

      La fonction permet d'effectuer un changement d'unité statistique. Toutes les observations ayant le même identifiant dans l'enquête source donnera lieu à une seule observation dans l'enquête.

      Pour chaque variable, on choisit le mode de regroupement :

      • Ignorer

      • Conserver la première ou la dernière valeur rencontrée

      • Conserver la valeur minimum ou la valeur maximum

      • Concaténer dans une variable texte

      • Calculer la moyenne ou la somme (variables numériques)

      • Fusionner dans une variable fermée multiple (variables fermées)

      EXEMPLE : L'enquête "visites" est regroupée dans une enquête patient. L'identifiant du patient est PatientID, on garde la dernière valeur pour Sexe et Datenaissance, on concatène les Diagnostics, on fait la somme pour le MontantMédicaments, la variable MotifPrincipal est une variable fermée unique qui devient fermée multiple dans l'enquête regroupée.

<task id="regrouper" function="dupgroupby">
      <input>
      <survey>visites</survey>
      <variables>PatientID</variables>
      <group> <!--op=keepfirst/keeplast/minimum/maximum/average/sum/mergetext/mergemultiple-->
      <groupby name="Sexe" op="keepfirst" />
      <groupby name="Datenaissance" op="keepfirst" />
      <groupby name="Diagnostics" op="mergetext" />
      <groupby name="MontantMédicaments" op="sum" />
      <groupby name="MotifPrincipal" op="mergemultiple" />
      </group>
      </input>
      <output>
      <survey>patients</survey>
      </output>
      </task>

Gérer l'ordre et l'état des opérations :

Vous disposez des options suivantes pour organiser les opérations :

  • Remonter ou descendre une opération dans la liste afin de modifier son ordre d’exécution.

    REMARQUE : Lorsque plusieurs opérations sont définies, leur ordre d'exécution est important. Par exemple, exécuter l’action Recalculer toutes les variables avant l’import de données n’a pas de sens, car les données à traiter ne seraient pas encore disponibles.

  • Supprimer une opération en cliquant sur l’icône en forme de croix.

  • Désactiver temporairement une opération en décochant l’option Active ; l’opération sera ignorée lors de l’exécution.
