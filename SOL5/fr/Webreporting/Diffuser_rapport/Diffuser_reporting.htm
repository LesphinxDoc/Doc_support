Diffuser un reporting par email

La diffusion d’un reporting par e-mail permet d’envoyer un accès à un rapport à une liste de destinataires.

REMARQUE : Vous pouvez diffuser un reporting uniquement si son accès est configuré en Accès restreint.

Pour diffuser un reporting par e-mail, vous devez :

  • Rédiger le message ;

  • Créer une invitation ;

  • Paramétrer l’envoi.

Rédiger le message

Pour rédiger un e-mail d'invitation :

  1. Depuis la partie WebReporting, cliquez sur Diffuser.

  2. Accédez à la rubrique Messages du canal Webreporting - accès restreints.

    REMARQUE : Par défaut un message d'invitation est mis à votre disposition. Vous pouvez le modifier et l'utiliser ou le dupliquer si nécessaire.

  3. Dans le cas d'une duplication du message par défaut, nommez votre message, puis cliquez sur Dupliquer.

    L’éditeur s’ouvre. Modifiez le contenu de votre message.

L'environnement de rédaction du message est composé de 3 zones :

  • Le volet de gauche, qui vous permet de sélectionner des liens personnalisés, des sections ou des contenus à glisser-déposer dans le message.

  • Le plan de travail, qui vous permet d'ajouter l'objet du message, le nom et l'adresse de l'expéditeur, de rédiger votre message, de visualiser son rendu sur ordinateur, tablette et mobile et d'accéder à d'autres actions complémentaires.

    Ajouter un objet, un nom et e-mail d'expéditeur

    Saisissez l'objet du mail, indiquez le nom de l'expéditeur et sélectionnez l'e-mail d'expéditeur.

    • Objet du mail : Insérez l'objet du mail.

      EXEMPLE : "Votre avis nous intéresse" dans le cadre d'une enquête de satisfaction.

    • Nom de l'expéditeur : Ce champ est facultatif, il correspond au texte qui apparaîtra dans le champ DE de votre e-mail.

    • Email expéditeur : Il s'agit de l'adresse e-mail qui sera utilisée pour l'envoi.

      Ajouter une adresse d'expéditeur

      Pour ajouter une nouvelle adresse, il suffit de cliquer sur le bouton + puis renseigner l'adresse.

      Un e-mail de validation sera envoyé à cette adresse. Elle devra être validée avant de pouvoir être utilisée comme adresse d'expédition.

      Cliquez sur la roue dentée pour gérer les adresses d'expédition (suppression / renvoi d'e-mail d'activation).

      REMARQUE : Veuillez suivre la procédure suivante pour ajouter un domaine d'envoi.

  • Le volet de droite, qui vous permet de modifier les propriétés des éléments sélectionnés.

Si vous partez d'un message vide, il faut d'abord ajouter des colonnes pour y insérer par la suite votre texte, images et tout autre élément :

  1. Glissez déposer l’élément 1, 2 ou 3 Colonne(s) depuis la partie Section au niveau du volet de gauche.

    Cliquez sur l'image pour un aperçu animé

  2. Insérez les différents éléments que vous souhaitez mettre dans votre message (depuis les parties Liens personnalisés et Contenu) dans les colonnes correspondantes.

    Liens personnalisés

    • Rapport bouton : permet d’ajouter un bouton donnant accès au rapport.

    • Rapport lien : permet d’ajouter un lien donnant accès au rapport.

    • Rapport image : permet d’ajouter une image cliquable donnant accès au rapport.

    • Voir la version en ligne : permet d’accéder à la version en ligne de l’e-mail si le contenu ne s’affiche pas correctement dans la messagerie.

    • Se désabonner : permet à l’utilisateur de se désabonner des envois.

    Contenu

    • Texte : permet d'ajouter une zone de texte.

      REMARQUE : Il est possible de reformuler, d'améliorer la clarté, de corriger la grammaire ou d'enrichir votre contenu grâce à l'intelligence artificielle. Consultez plus d'informations sur la modification de texte par IA.

    • Bouton : permet d’ajouter un bouton donnant accès à un site web.

      Le bouton peut être personnalisé depuis le volet Propriétés de l’élément.

    • Image : permet d’insérer une image depuis votre ordinateur ou depuis une URL.

    • RGPD : permet d'insérer une mention RGPD afin d'informer et de rassurer l'utilisateur sur la récolte et l'utilisation de ses données personnelles.

    Sélectionnez un élément pour accéder à ses propriétés dans le volet de droite. Vous pouvez modifier :

    • L'alignement de l’élément : Aligner à gauche, à droite, centrer ou justifier.

    • La marge interne : permet d'ajuster la position de l’élément par rapport à l’élément parent.

      EXEMPLE : Le bouton "Non" dispose d'une marge interne de 25 px en haut et en bas tandis que le bouton "Oui" n'a aucune marge interne.
      La position de chaque bouton est donc différente à l'intérieur de la colonne.

    • Mise en forme (police de caractères, taille de police, couleur, largeur, couleur de fond, bordure, etc.).

Cliquez sur le bouton Enregistrer pour sauvegarder vos modifications.

Une fenêtre de vérification du message s'affichera si un des éléments n'est pas correctement paramétré. Consultez plus d'informations sur la vérification du message.

Créer une invitation

  1. Depuis la partie WebReporting, cliquez sur Diffuser.

  2. Cliquez sur Gérer mes envois.

  4. Cliquez sur Créer ma première invitation (ou sur Inviter si des envois ont déjà été créés).

  5. Nommez votre envoi.

  6. Sélectionnez le type de programmation.

    • Envoi de manière Immédiate ou différée : permet d’envoyer l’invitation tout de suite ou de la planifier pour une date ultérieure.

    • Envoi de manière Automatisée : permet de configurer des envois automatiques.

  7. Cliquez sur Appliquer.

    Félicitations, votre invitation est désormais créée. Vous pouvez passer à la rédaction du message à envoyer.

Paramétrer l'envoi

  1. Accédez à l'étape de paramétrage de l'envoi d'une invitation.

  2. Le message par défaut est sélectionné automatiquement. Pour utiliser un autre message, cliquez sur Choisir un autre message, puis sélectionnez le message souhaité.

  3. Sélectionnez les destinataires à contacter.

    Tous les destinataires :  permet de contacter tous les destinataires présents dans la liste.

    Sélection personnalisée : permet de sélectionner manuellement les destinataires à contacter.

    Cliquez sur pour prévisualiser la liste des destinataires correspondant au type sélectionné.

    Filtrer la sélection

    Il peut être utile de filtrer les destinataires en fonction de données issues du fichier d’import, par exemple un type d’abonnement, un statut, une date, etc.

    Pour filtrer la sélection :

    1. Cliquez sur Ajouter un filtre.

    2. Cliquez sur Ajouter un filtre depuis la modale Filtrer les destinataires.

    3. Sélectionnez la variable à utiliser et définissez les critères.

      REMARQUE : Il est possible de définir plusieurs filtres en combinant les conditions avec les opérateurs ET / OU.

    4. Cliquez sur Valider.

      Le nombre de destinataires à contacter est automatiquement mis à jour.

  4. Sélectionnez le type d'envoi :

    • Envoi Immédiat : l'envoi est effectué immédiatement.

    • Envoi différé : l’envoi est effectué à la date et à l’heure définies.

    • Envoi Automatisé : permet de programmer des envois automatiques.

  5. (Facultatif) Modifiez les options de régulation si nécessaire (cela permet d’optimiser la délivrabilité, notamment pour les campagnes d’emailing volumineuses).

  6. Cliquez sur Valider.

    Une fenêtre de confirmation s'affiche avec un récapitulatif de l'envoi et, le cas échéant, des messages d'avertissement.

  7. Cochez J'accepte les conditions générales d'utilisation puis cliquez sur Valider.

Lors de sa première connexion, l’utilisateur est invité à créer un mot de passe en cliquant sur Activer votre accès. Ce mot de passe est valable pour tous les rapports auxquels l’utilisateur est autorisé à accéder.

REMARQUE : Les identifiants sont communs à tout le serveur. Si un utilisateur existant est invité à se connecter à un autre report d'une autre enquête sur le même compte ou sur un autre compte, il pourra directement se connecter en utilisant ses identifiants.
