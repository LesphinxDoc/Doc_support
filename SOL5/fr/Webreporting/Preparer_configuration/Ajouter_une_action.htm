Ajouter une action

Une liste d'action vous est proposée. Elles sont classées dans les 5 grandes catégories suivantes :

  • Collecter

  • Voir les tables

  • Voir les résultats

  • Afficher une page

  • Autres actions

La fenêtre de paramétrage d'une action se présente et se décompose comme suit :

 : Menu déroulant permettant de choisir l'action voulue.

 : Zone permettant le paramétrage des différentes options en lien avec l'action choisie. Ces options sont différentes si l'on souhaite faire une action de saisie, de résultats ou consultation par exemple.

 : Zone permettant un "paramétrage avancé" en ajoutant des requêtes et du code.

Pour ajouter une action :

  1. Accédez à la partie Paramétrer la configuration du WebReporting.

  2. Cliquez sur le bouton .

Sélectionnez l'action à utiliser puis paramétrez les différentes options.

COLLECTER

Saisir

  1. Donnez un nom à l'action.

    Le nom de l’action est celui qui s’affichera dans le bandeau du rapport en ligne.

    Le style du nom peut être personnalisé en cliquant sur l’icône en forme de crayon à droite du champ.

    Par défaut, une icône est affichée. Vous pouvez la modifier ou la masquer en décochant la case Icône.

  2. Sélectionnez le formulaire à utiliser pour la saisie.

    Si vous avez créé plusieurs formulaires avec Sphinx iQ3, un menu déroulant vous permet d’associer un formulaire spécifique à l’action.

    REMARQUE : Le choix Tous les formulaires est sélectionné par défaut. Un menu déroulant s’affichera alors pour permettre à l’utilisateur de choisir le formulaire directement sur la plateforme.

    Si vous souhaitez proposer uniquement certains formulaires, sélectionnez Sélectionner, puis cochez ceux à afficher.

    Cochez la case Liste toujours visible si vous voulez que la liste des formulaires s’affiche automatiquement à l’accès au reporting.

  3. Configurez le reste des options facultatives :

    • Enregistrement automatique : La saisie est enregistrée à chaque changement de page, le numéro de la page atteinte est conservé.

      auto=1 / auto=2 / auto=3 / auto=4

      Si auto vaut 1, 2 ou 3, cette page sera automatiquement affichée lors du prochain accès.

      Si auto vaut 4, on revient toujours sur la première page.

      Lorsque le questionnaire est définitivement enregistré :

      Auto = 1 : Accès interdit (la réponse est déjà enregistrée).

      Auto = 2 : Retour à la première page.

      Auto = 3 : Retour à la dernière page.

    • Déroulement : cochez l'option Recommencer après enregistrement pour afficher un nouveau formulaire vierge automatiquement après chaque saisie.

    • préremplir avec les variables de profil "Saisie" de l'accès restreint.

      Les champs du questionnaire seront remplis automatiquement selon les valeurs associées à l’utilisateur.

    • préremplir avec les variables (à définir) : Permet d’attribuer des valeurs par défaut.

      EXEMPLE : Agence=Annecy&CodeBanque=7
      préremplit les variables "Agence" et "CodeBanque".

      REMARQUE : Ne pas utiliser de guillemets autour des valeurs.

    • Choisissez la langue d'affichage du questionnaire.

      Si le questionnaire est multilingue, l'option Demander sera proposée par défaut pour permettre au répondant de choisir la langue.

  4. Cliquez sur OK pour valider l'ajout de l'action.

VOIR LES TABLES

Table des observations

L'action Tables des observations permet de consulter l'ensemble des réponses de l'étude dans un tableur.

La colonne Variables permet de sélectionner les colonnes à afficher dans le tableur. Par défaut, toutes les variables de l’enquête sont incluses, à l’exception des variables masquées (voir Options avancées de la configuration).

Pour sélectionner les variables à afficher :

  1. Cliquez sur Gérer les variables.

  2. Glissez déposez les variables souhaitées vers la colonne de droite pour les afficher dans le tableur.

    REMARQUE : L’ordre d’affichage des colonnes (variables) peut être modifié à l’aide des flèches haut et bas.

    REMARQUE : Une variable peut être ajoutée plusieurs fois, si nécessaire.

  • Il est possible de limiter le nombre d'observations à afficher dans le tableur en indiquant une strate à appliquer.

  • Il est possible de trier les observations selon les valeurs d'une ou de plusieurs variables (à indiquer dans le champ Trier selon).

  • Pour que l'en-tête des colonnes soit le libellé des variables et non pas le nom des variables, cochez Libellés.

  • Pour ajouter les numéros des observations dans la première colonne du tableur, cochez Numéros des variables.

  • Il est possible d’appliquer une mise en forme, pour ce faire, cochez Mise en forme puis cliquez sur « Définir ».

  • Pour modifier le nombre de réponses à afficher par page, cliquez sur le menu déroulant Réponses par page puis sélectionnez une valeur (valeurs disponibles 50 – 100 – 200 - 500).

  • Pour ajouter directement une observation dans le tableur, cochez Ajout pour afficher le bouton d'ajout à la fin du tableur (en haut à droite de la page).

  • Pour permettre à l'utilisateur du rapport en ligne de télécharger les réponses, cochez Téléchargement.

  • Pour permettre à l'utilisateur de modifier directement dans le tableur les valeurs des observations, cochez Modification.

  • Pour permettre à l'utilisateur de supprimer une observation, cochez Suppression.

  • Il est également possible de permettre le choix des variables ainsi que la possibilité de voir les documents.

      REMARQUE : L’ordre d’affichage des colonnes (variables) peut être modifié à l’aide des flèches haut et bas.

      REMARQUE : Une variable peut être ajoutée plusieurs fois, si nécessaire.

  3. Sélectionnez l'option Numéros des variables pour afficher les numéros des variables dans la liste déroulante.

Verbatim

Cette action permet d’afficher le verbatim d’une ou plusieurs variables texte, soit sous forme de liste structurée, soit sous forme de tableau.

  1. Donnez un nom à l'action.

  2. Sélectionnez le format d'affichage du verbatim : Liste structurée ou Tableau.

  3. Sélectionnez les variables texte à utiliser.

    Pour sélectionner les variables à afficher,

    1. Cliquez sur Gérer les variables.

  6. (Facultatif) Paramétrez les options d'affichage de l'analyse :

    • Personnalisez le titre de l’analyse si nécessaire en sélectionnant l’option Titre personnalisé, puis en saisissant le titre souhaité.

    • Cochez Numéros d’observations pour afficher une colonne indiquant le numéro des observations lorsque l’utilisateur cliquera sur un mot du nuage de mots (option disponible uniquement dans le cas d'un affichage Tableau).

    • Cochez la case Commentaire, puis saisissez un texte afin d’afficher un commentaire en bas de l’analyse.

    • Cochez Simplifier, puis indiquez le nombre maximal de lignes à afficher.

Nuage de mots

Votre étude comporte une variable de type texte. Pour une vision plus synthétique de ce type de variable, Sphinx propose une restitution sous la forme d'un nuage de mots.

REMARQUE : Il est possible de créer un nuage de mots directement depuis l'environnement d'analyse puis d'associer la vue à une action.

  • Le champ Variable vous permet de sélectionner la variable texte.

  • Vous pouvez choisir une variable de signature ainsi qu'une variable de filtre.

  • Vous avez également la possibilité de restreindre les mots candidats qui seront affichés dans le nuage de mots (selon leur catégorie grammaticale).

  • Vous pouvez choisir d'afficher le nuage global ou les nuages par contexte (c'est-à-dire que vous aurez un nuage de mots pour chaque modalité de la variable de contexte choisie).

Analyse de texte comparative

Cette action permet de comparer le nuage de mots d’une variable textuelle selon deux modalités distinctes d’une autre variable.

  1. Donnez un nom à l'action.

  2. Sélectionnez la variable texte à utiliser.

  3. (Facultatif) Sélectionnez des variables à afficher en signature.

    Ces variables s’afficheront lorsque l’utilisateur cliquera sur un mot dans le nuage de mots.

  4. (Facultatif) Sélectionnez une variable filtre si nécessaire.

  5. Sélectionnez la variable contexte ainsi que les deux modalités distinctes à comparer.

    Vous avez la possibilité de renommer l'intitulé et modifier la couleur et les icônes des nuages de mots.

  6. Paramétrez les options du nuage de mots :

    • Sélectionnez les éléments à afficher dans le nuage de mots : verbes, adjectifs, noms communs, noms propres, sans catégorie.

    • Nombre de mots à afficher par nuage.

    • Fréquence minimal d'un mot.

    • Utiliser les mots spécifiques.

    • Exclure des mots : Pour exclure plusieurs mots, saisissez-les dans le champ prévu à cet effet en les séparant par un point-virgule « ; ».

  7. (Facultatif) Paramétrez les options d'affichage de l'analyse :

    • Personnalisez le titre de l’analyse si nécessaire en sélectionnant l’option Titre personnalisé, puis en saisissant le titre souhaité.

    • Cochez Numéros d’observations pour afficher une colonne indiquant le numéro des observations lorsque l’utilisateur cliquera sur un mot du nuage de mots.

    • Cochez la case Commentaire, puis saisissez un texte afin d’afficher un commentaire en bas de l’analyse.

Croisements thèmes/orientations

Ce paramétrage s'effectue dans l'onglet Analyse et calcul d'une variable dans Sphinx iQ3.

  1. Donnez un nom à l'action.

  2. Sélectionnez le format d'affichage de l'analyse : Graphique et/ou Tableau.

  3. Indiquez un titre pour l'analyse.

  4. Sélectionnez la variable texte à utiliser.

  5. (Facultatif) Sélectionnez des variables à afficher en signature.

Net Promoter Score

Le Net Promoter Score (NPS) est un indicateur de fidélité permettant de mesurer le niveau de recommandation d'un client pour une marque ou un produit. Le score NPS est calculé en faisant la différence entre le pourcentage de promoteurs et le pourcentage de détracteurs. On obtient ainsi un score variant de -100 à + 100.

Les différentes catégories :

  • Les promoteurs sont les clients très satisfaits et fidèles, prêts à recommander et promouvoir les produits ou services de la marque.

  • Les passifs sont les clients satisfaits, qui reviendront peut-être mais ne feront pas de publicité spécifique pour la marque.

  • Les détracteurs sont les clients non satisfaits qui risquent de propager une mauvaise image de marque.

  1. Donnez un nom à l'action.

  2. Sélectionnez la variable NPS à utiliser.

  3. Indiquez un titre et une abréviation pour l'analyse.

  4. (Facultatif) Sélectionnez une variable pour montrer l'évolution du NPS.

  5. Sélectionnez une variable de contexte.

  6. (Facultatif) Cochez l'option Comparaison pour afficher une comparaison entre les Promoteurs et les Détracteurs.

    Vous pouvez personnaliser les intitulés, les icônes ainsi que le seuil à partir duquel un élément est affecté à la catégorie des Promoteurs ou des Détracteurs (par exemple : inférieur ou supérieur à 10).

  7. (Facultatif) Cochez la case Analyse textuelle puis sélectionnez une variable texte pour afficher une analyse textuelle (nuage de mots + verbatim) en plus du graphique NPS.

AFFICHER UNE PAGE

Montrer une page html / un fichier

Cette action permet de donner accès à des fichiers annexes (.pdf, .html etc...).

  1. Donnez un nom à l'action.

  2. Sélectionnez le fichier à utiliser depuis la liste des fichiers disponibles.

    Pour créer une page HTML.

    1. Cliquez sur l'icône Gérer les fichiers.

    2. Sélectionnez Créer un nouveau fichier html.

    3. Nommez votre fichier HTML, puis cliquez sur Créer.

    4. Cliquez sur l’icône en forme de crayon pour éditer votre page HTML.

      REMARQUE : Il est également possible d’importer un fichier existant depuis votre disque dur. Pour cela :
      1- Sélectionnez Uploader un fichier depuis le disque dur.
      2- Cliquez sur Choisir un fichier.
      3- Sélectionnez le fichier .Html à importer.
      4- Cliquez sur Uploader.

  3. Choisissez où s’ouvrira le site web:

    • Zone de résultat ;

    • Page courante ;

    • Nouvelle page.

  2. Indiquez l'URL du site dans le champ Destination.

  3. Choisissez où s’ouvrira le site web:

    • Zone de résultat ;

    • Nouvelle page.

  • La numérotation des pages, affichage des en-tête et identification des observations.

Filtre associé à une action

REMARQUE : Si la gestion des accès restreints s'effectue par "Enquête Sphinx", cette action ne sera pas visible à l'exécution de la configuration.
