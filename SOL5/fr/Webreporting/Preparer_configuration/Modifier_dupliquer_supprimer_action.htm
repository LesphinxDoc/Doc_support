Modifier, déplacer, dupliquer ou supprimer une action

Depuis la partie Préparer les configurations, vous pouvez modifier, déplacer, dupliquer ou supprimer une action. Vous pouvez également sélectionner une action par défaut ou rendre une action inactive.

Modifier une action

Pour modifier le paramétrage d'une action :

  1. Cliquez sur le nom de l'action à modifier.

    La fenêtre de paramétrage de l'action apparaît.

  2. Cliquez sur Modifier.

    Il est alors possible de modifier le nom et l'icône de l'action, les paramétrages de l'action mais aussi changer complètement l'action en sélectionnant une autre dans la liste déroulante Action.

Déplacer une action

Pour déplacer une action :

  1. Sélectionnez l'action.

  2. Cliquez sur l'icône située à gauche du nom de l'action sélectionnée. (en drag & drop vers le haut/bas).

    Ou utilisez les icônes mises à disposition pour monter l'action d'une ligne / descendre d'une ligne.

Dupliquer une action

Pour dupliquer une action :

  1. Sélectionnez l'action à dupliquer.

  2. Cliquez sur Dupliquer.

Supprimer une action

Pour supprimer une action :

  1. Sélectionnez l'action à supprimer.

  2. Cliquez sur Supprimer.

Sélectionner une action par défaut

Lorsque vous définissez une action par défaut, cette dernière s'affichera par défaut lors de l'ouverture de rapport.

Pour sélectionner une action par défaut :

  1. Sélectionnez l'action concernée.

  2. Cochez la case Action par défaut.

    Deux ** s'afficheront à droite du nom de l'action par défaut.

Rendre une action Inactive

Rendre une action inactive permet de masquer celle-ci aux utilisateurs lorsqu’ils consultent le rapport.

Cette option est particulièrement utile si vous souhaitez préparer une nouvelle action tout en laissant le rapport accessible.

Pour rendre une action inactive :

  1. Sélectionnez l'action concernée.

  2. Cochez la case Inactive.

    L’action ainsi désactivée apparaîtra en grisé dans le bandeau.
