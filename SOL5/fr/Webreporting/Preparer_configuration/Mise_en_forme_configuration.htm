Modifier la mise en forme de la configuration

Cette section décrit les options de personnalisation disponibles dans l’interface de configuration du Webreporting. Vous apprendrez comment modifier les éléments visuels tels que les couleurs du menu, le logo, le titre, choisir la langue et traduire le contenu d'une configuration ainsi que comment intégrer des pages d’aide ou d’accueil personnalisées pour accompagner les utilisateurs dans l’exploitation de vos reportings.

Modifier les couleurs du menu : Texte / fond

Il est possible de modifier les couleurs du texte des actions ainsi que la couleur de fond du menu latéral. Pour cela, veuillez suivre les étapes suivantes :

  1. Accédez à la partie Webreporting, onglet Paramétrer la configuration.

  2. Sélectionnez la couleur du texte des actions.

  3. Sélectionnez la couleur de fond à appliquer au menu latéral.

Ajouter un logo

Pour ajouter un logo :

  1. Accédez à la partie Webreporting, onglet Paramétrer la configuration.

  2. Cochez la case Logo.

  3. Cliquez sur Ajouter.

  4. Cliquez sur Ajouter image.

  5. Cliquez sur Choisir un fichier pour choisir un fichier depuis votre disque dur.

    REMARQUE : La taille maximale d'une image est de 2 Mo. Les formats acceptés sont : .bmp, .emf, .gif, .jpg, .jpeg, .png, .wmf.

  6. Cliquez sur Charger.

  7. Sélectionnez l'image depuis la liste puis cliquez sur Insérer.

    REMARQUE : Il est possible de redimensionner l'image, en insérant un % dans le champ Taille puis en cliquant sur Appliquer.

Afficher un titre

Ce texte représente le titre qui est affiché au-dessus des actions définies. :

  1. Accédez à la partie Webreporting, onglet Paramétrer la configuration.

  2. Cochez la case Titre.

    REMARQUE : Par défaut, l’intitulé affiché est : "[Enquête.Titre] - [NombreObservations] obs.", ce qui permet de visualiser automatiquement le nom de l’enquête ainsi que le nombre d’observations associées.

  3. Cliquez sur pour éditer le titre.

    Le texte entre crochet peut être un des mots clé suivant :

    • [Enquête.Nom] ([Survey.Name]) est remplacé par le nom de l'enquête à l'exécution du rapport en ligne.

    • [Enquête.Titre] ([Survey.Title]) est remplacé par le titre de l'enquête (ou son nom si le titre n'est pas défini)

    • [NombreObservations] ([ObservationsNumber]) est remplacé par le nombre d'observations total de l'enquête.

    • [NombreObservationsFiltre] ([FilterObservationsNumber]) est remplacé par le nombre d'observations satisfaisant à l'accès restreint, à la strate définie par défaut. Ce nombre est calculé au chargement du rapport en ligne, il n'est pas modifié si la strate utilisée est modifiée.

    • [Profil] ([Profile]) est remplacé par le texte représentant l'ensemble des filtres définis

    • [Session] est remplacé par le texte défini dans la colonne Session d'un accès restreint, si aucun accès restreint n'est défini sur l'enquête le texte est remplacé par les valeurs des variables de profil. Si aucune variable de profil n'est définie ou si pour cet utilisateur elles ne contiennent pas de valeur, [session] est remplacé par une chaîne vide.

  4. Cliquez sur OK pour valider les modifications.

Ajouter une page d'aide

Vous pouvez créer une page d’aide au format HTML pour guider les utilisateurs dans l’exploitation du reporting que vous mettez à disposition.

Pour ce faire,

  1. Accédez à la partie Webreporting, onglet Paramétrer la configuration.

  2. Cochez la case Page d'aide.

  3. Cliquez sur l'icône Gérer les fichiers.

  4. Sélectionnez Créer un nouveau fichier html.

  5. Nommez votre fichier HTML, puis cliquez sur Créer.

  6. Cliquez sur l’icône en forme de crayon pour éditer votre page HTML.

    REMARQUE : Il est également possible d’importer un fichier HTML existant depuis votre disque dur. Pour cela :
    1- Sélectionnez Uploader un fichier depuis le disque dur.
    2- Cliquez sur Choisir un fichier.
    3- Sélectionnez le fichier .Html à importer.
    4- Cliquez sur Uploader.

  7. Sélectionnez la page à utiliser depuis le menu déroulant Page d'aide.

    La page d’aide ainsi configurée sera accessible aux utilisateurs du Webreporting via l’icône « ? » située en haut à droite de leur écran.

Ajouter une page d'accueil

Vous pouvez créer une page d’accueil au format HTML pour qui s'affichera par défaut lors de l'ouverture du reporting.

Pour ce faire :

  1. Accédez à Webreporting, onglet Paramétrer la configuration.

  2. Cochez la case Page d'accueil.

  3. Cliquez sur l'icône Gérer les fichiers.

  4. Sélectionnez Créer un nouveau fichier html.

  5. Nommez votre fichier HTML, puis cliquez sur Créer.

  6. Cliquez sur l’icône en forme de crayon pour éditer votre page HTML.

    REMARQUE : Il est également possible d’importer un fichier HTML existant depuis votre disque dur. Pour cela :
    1- Sélectionnez Uploader un fichier depuis le disque dur.
    2- Cliquez sur Choisir un fichier.
    3- Sélectionnez le fichier .Html à importer.
    4- Cliquez sur Uploader.

  7. Sélectionnez la page à utiliser depuis le menu déroulant Page d'accueil.

Traduire le contenu d'une configuration

Lorsque vous créez un reporting, la langue de la configuration est la langue par défaut de votre enquête. Il est possible de changer de langue pour la configuration en entier et/ou pour certaines actions si votre enquête contient plusieurs langues.

Lorsque vous paramétrez votre configuration, cliquez sur le menu déroulant Langue pour sélectionner la langue de la configuration en entier. Le menu et les actions seront affichés dans la langue sélectionnée.

EXEMPLE : Les langues de votre enquête sont l'anglais et le français. Par défaut, votre configuration est définie en anglais, mais vous voulez que votre reporting s'affiche en français.

Il est également possible de définir une langue par action (qui n'affectera que son contenu, pas l'affichage du menu).

EXEMPLE : Les langues de votre enquête sont l'anglais et le français. Vous voulez que votre reporting s'affiche en français sauf pour l'action Tableur :
1 - Cliquez sur l'action concernée.
2 - Cliquez sur Modifier.
3 - Dans les paramètres de l'action, cochez Langue et sélectionnez la langue d'affichage de l'action dans le menu déroulant. Par défaut, l'action est affichée dans la langue de la configuration.
