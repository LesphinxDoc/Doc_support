Regrouper les modalités

Dans le cas d’une analyse contenant des variables de types fermée ou échelle, il est possible de regrouper les modalités d’une variable qualitative.

EXEMPLE : Dans une enquête portant sur le tourisme et dans le cas d’une analyse du mode d'hébergement (hôtel, famille/amis, location/gîte, camping) on peut vouloir les regrouper en « Premium » et « Lowcost »  pour avoir une lecture plus synthétique de l’analyse.

Pour regrouper des modalités, procédez comme suit :

  1. Sélectionnez votre analyse.

  2. Dans l’onglet options, catégorie calcul, cochez la case Gestion des modalités.

  3. Cliquez sur le bouton .

  4. Cliquez sur le bouton Nouvelle catégorie pour ajouter une catégorie.

    REMARQUE : Vous pouvez sélectionner des regroupements que vous avez déjà réalisés depuis le menu déroulant "Sélectionner des regroupements existants...".

  5. Déplacez les modalités en drag & drop pour les intégrer dans chaque catégorie.

  6. (Optionnel) Vous pouvez masquer/exclure des modalités :

    • Modalités Exclues : Ces modalités sont masquées et ignorées dans les calculs.

    • Modalités Cachées : Ces modalités ne sont pas affichées mais sont prises en compte dans les calculs.

  7. Cliquez sur OK pour valider.

  8. (Facultatif) Cochez l'option détailler les regroupements si vous souhaitez détailler le contenu des catégories créées.

Dans le cas d’une analyse croisée contenant une ou plusieurs variables de type échelle ou fermée, il est possible de choisir la variable sur laquelle le regroupement des modalités sera effectif grâce au menu déroulant et si vous souhaitez l’appliquer à toutes les variables similaires.
