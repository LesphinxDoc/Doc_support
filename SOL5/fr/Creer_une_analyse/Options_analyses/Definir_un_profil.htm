Définir un profil

Définir un profil permet de désigner les modalités ou les valeurs d’une ou plusieurs variables qui seront appliquées comme filtre à un objet d’analyse sélectionné. Pour définir un profil, procédez comme suit :

  1. Sélectionnez votre analyse.

  2. Dans l’onglet avancé, catégorie calcul, à côté de définir un profil, cliquez sur .

    REMARQUE : Il est possible d’utiliser un profil d’analyse déjà réalisé auparavant en cliquant sur le bouton .

  3. Donnez un nom au profil à créer.

  4. Choisissez le mode d'édition à utiliser pour renseigner le profil.

ÉDITION EN EXPRESSION

Après avoir sélectionné le mode d’édition expression dans le menu déroulant, vous pouvez rédiger vous-même le profil.

Pour cela, lors de la définition du profil pour les variables qualitatives, il faut nommer la variable, suivie de l’opérateur « = », puis de la modalité à appliquer comme filtre entre guillemets. Pour les variables quantitatives, il faut nommer la variable, suivie d’un opérateur mathématique comme « > » ou « <= », puis de la valeur à appliquer comme filtre. Si vous souhaitez renseignez plusieurs variables de filtre il faut les séparer par un opérateur booléen « et » / « ou ».

EXEMPLE : Dans une enquête portant sur le tourisme et dans le cas d’une analyse sur les dépenses d’alimentation, on peut vouloir ne traiter qu’une partie de l’échantillon total. Si l’on souhaite étudier les dépenses alimentaires des femmes de plus de 35 ans, dont la CSP est employé, on peut nommer le profil comme suit « Femmes employées de plus de 35 ans » et le profil ainsi « CSP = "Employé" et Sexe = "Femme" et Age >= 35 ».

ÉDITION EN MULTICRITÈRES

Après avoir sélectionné le mode d’édition multicritères dans le menu déroulant, vous pouvez configurer vous-même le profil.

Pour cela, vous devez paramétrer la variable de filtre puis, pour les variables qualitatives taper les valeurs et/ou les intervalles de valeurs qui seront appliqués comme filtres, séparés par des points virgules. Pour les variables quantitatives vous devez sélectionner la ou les modalités qui seront appliquées comme filtre.

Vous pouvez ajouter ou supprimer une variable de filtre et si vous souhaitez renseigner plusieurs variables filtre il faut les séparer par un opérateur booléen « Et »  / « Ou » depuis le menu déroulant.

EXEMPLE : Dans une enquête portant sur le tourisme et dans le cas d’une analyse sur les dépenses activités touristiques, on peut vouloir ne traiter qu’une partie de l’échantillon total. Si l’on souhaite étudier les activités pratiquées par les femmes de 25 à 40 ans, on peut nommer le profil comme suit « Femmes de 25 et 40 ans » et ensuite sélectionner les variables filtre.

La définition de profils peut aussi s'appliquer dans les tableaux multiples. Pour ce faire :

  • Faites un clic droit sur le tableau à modifier puis cliquez sur Éditer.

  • Cliquez sur le bouton correspondant à chaque variable pour définir un profil.
