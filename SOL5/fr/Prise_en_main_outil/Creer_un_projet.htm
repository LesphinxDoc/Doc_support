Créer une étude par import de données

Explorer et analyser les données depuis différentes sources de données. Pour créer une nouvelle étude via import de fichiers, procédez comme suit :

  1. Depuis la page d'accueil, cliquez sur le bouton Nouvelle étude.

  2. Sélectionnez le type d'import à utiliser en fonction de la source de vos données.

    Sources de données disponibles : fichier CSV, fichier XLSX, fichier SPSS et fichier Triple-S.

    IMPORTER DES DONNÉES DEPUIS UN FICHIER CSV

    Pour importer des données depuis un fichier CSV :

    1. Depuis l'interface d'import de données, cliquez sur  "Fichier CSV".

    2. Cliquez par la suite sur le bouton "Sélectionner le fichier..." pour ajouter votre fichier de données.

      REMARQUE : Le fichier de données doit être au format .csv, .txt.

    3. Paramétrez les options d'import avant de finaliser l'import de votre fichier.

      • Choisir le type de séparateur : virgule, point virgule ou tabulation. Par défaut c'est le séparateur Point-virgule qui est sélectionnée.

      • L'encodage : automatique, windows-1252, utf-8, utf-16 et utf-16BE.

      • Détection des valeurs : cette option permet d'interpréter correctement les formats de dates et des décimales en fonction du format régional sélectionné.

        Supposons que votre fichier de données contient des dates affichées au format américain, à savoir MM/JJ/AAAA.

        Pour les interpréter correctement au format français (JJ/MM/AAAA), sélectionnez "Français" depuis le menu Détection des valeurs.

      • Langue du rapport : sélectionnez la langue de votre étude.

      • La deuxième ligne contient le libellé des variables : cochez cette option si vous avez inséré le libellé des variables à la 2e ligne.

        Une fois cette option cochée, la deuxième ligne (contenant le libellé des variables) disparaîtra et chaque libellé sera affecté à la variable correspondante.

      • Ignorer les lignes au début

        Cette option vous permet d'ignorer x lignes au début.

        EXEMPLE : Dans le fichier csv ci-dessous, les deux premières lignes contiennent le nom de l'étude/le nom de l'enquêteur et la 3e ligne contient les noms des variables.


        Lors de l'import de ce fichier, le nom de l’étude sera considéré comme nom de variable étant donné que la première ligne est réservée aux noms des variables.
        Dans ce cas, il faut ignorer les deux premières lignes pour que les noms de variables soient affichés à la première ligne.

        Aperçu des données après la suppression des deux premières lignes

      • Détection des variables à valeurs multiples

        • Dans les logiciels Sphinx, les réponses des variables à valeurs multiples sont contenues dans une seule colonne et sont séparées par des points-virgules. Si elles sont ordonnées, l'ordre détermine le rang. Dans votre fichier, si chaque modalité de réponse correspond à une colonne, il convient de les regrouper en une seule colonne avant import du fichier ou via les options ci-dessous :

          • Grouper les colonnes portant des noms consécutifs

            Cette option regroupe en une seule colonne les colonnes portant des noms d'en-têtes consécutifs tels que : choix1, choix2, choix3 ou encore choix_1, choix_2, choix_3. L'outil sera ainsi en mesure de traiter cette colonne comme une variable fermée à valeurs multiples.

          • Grouper les colonnes de même nom

            Cette option regroupe en une seule colonne les colonnes ayant des noms d'en-têtes strictement identiques. L'outil sera ainsi en mesure de traiter cette colonne comme une variable fermée à valeurs multiples.

          • Prendre en compte une colonne unique contenant un séparateur

            Cette option permet d'identifier les colonnes contenant des modalités séparées par le signe de votre choix (par exemple ";" ou ",") comme des variables à valeurs multiples.

      • Paramétrage d'une variable

        Lors de l'étape d'import, depuis l'aperçu des données, cliquez sur le crayon situé à côté de chaque variable pour afficher ses paramètres :

        Il est possible de modifier le nom/libellé de la variable ainsi que le type de données.

        Cliquez sur le bouton Valider pour enregistrer les modifications apportées.

    4. Donnez un nom à votre étude puis cliquez sur le bouton Créer l'étude pour finaliser l'étape de l'import des données.
