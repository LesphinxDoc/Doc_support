API Sphinx

Pour accéder à la liste des API Sphinx, procédez comme suit :

  1. Cliquez sur le nom de votre compte (en haut à droite).

  2. Cliquez sur Développeurs - API.

    REMARQUE : Pour ajouter un jeton d'accès API, veuillez cliquer-ici.

    Trois types de méthodes peuvent être utilisées :

    • GET : Pour récupérer des informations/données

    • DELETE : pour supprimer des données

    • POST : pour ajouter/modifier des éléments/données

Ci-dessous les différentes fonctions d'API disponibles :

Diffusion

  • GET : Lister tous les campagnes : Renvoie toutes les campagnes de diffusion pour un compte.

  • GET : Obtenir les informations d'une campagne : Renvoie des données sur la campagne donnée telles que son nom, le nombre de destinataires, l'étude associée et les liens de distribution, etc...

  • POST : Copier une campagne : Copie la structure d'une campagne d'une étude source vers une autre avec des options, et renvoie des informations générales sur la nouvelle campagne créée.

  • GET : Lister tous les envois : Renvoie la liste des envois de la campagne spécifiée.

  • GET : Lister tous les destinataires : Renvoie tous les destinataires et le statut actuel de la réponse pour chacun d'entre eux.

  • POST : Ajouter un destinataire : Crée un nouveau destinataire et l'ajoute à la campagne.

  • DELETE : Supprimer les destinataires identifiés par une adresse email ou un numéro de téléphone pour une campagne donnée.

  • DELETE : Supprimer un destinataire par son ID : Supprime le destinataire spécifié de la campagne, ainsi que toutes les données de suivi relatives à son activité.

  • GET : Lister les adresses emails ou numéros de téléphone blacklistés : Renvoie la liste des adresses emails et les numéro de téléphone présents dans la liste noire.

Etudes

  • GET : Lister toutes les études : Renvoie la liste des études pour un compte et, pour chaque étude, des informations telles que son nom ou le nombre de réponses.

  • POST : Créer une étude : Crée une étude vierge. Les dates d'ouverture et de clôture peuvent être définies en option. Des variables système sont automatiquement ajoutées (clé, date de saisie, ...).

  • GET : Obtenir des informations sur l'étude : Renvoie les détails de l'étude spécifiée.

  • DELETE : Supprimer une étude : Supprime l'étude spécifiée et ses ressources associées (données, images, campagnes, rapports web, ...).

  • POST : Copier une étude : Copie une étude, éventuellement avec les réponses, et renvoie des informations générales sur la nouvelle étude créée.

  • GET : Exporter les réponses vers un fichier JSON ou CSV : Renvoie les réponses à l'étude dans un flux JSON ou CSV (';' délimiteur) : noms des variables, étiquettes et données brutes.

  • POST : Ajouter ou mettre à jour des réponses : Ajoute de nouvelles réponses à l'étude ou met à jour les données si les enregistrements existent déjà (en fonction de la valeur de la variable "clé").

  • DELETE : Supprimer un ensemble de réponses : Supprime une ou plusieurs réponses identifiées par leur clé. L'API suppose que le corps de la demande contient la liste des clés à supprimer.

  • GET : Obtenir un lien vers une observation : Crée un lien temporaire ciblant le formulaire spécifié, pour une observation spécifique spécifié par une clé.

  • GET : Lister tous les liens des rapports : Renvoie tous les liens vers les rapports Web, ainsi que le lien de prévisualisation de l'étude.

Variables

  • GET : Lister toutes les variables : Renvoie les variables de l'étude, leur type et leurs caractéristiques.

  • POST : Créer une variable : Crée une nouvelle variable dans une étude existante.

  • GET : Rechercher une variable par son nom : Renvoie la variable spécifiée d'une étude donnée, son type et ses caractéristiques.

  • DELETE : Supprimer une variable : Supprime une variable existante d'une étude. Veuillez noter que cette opération supprime également toutes les réponses existantes à cette question.

  • PUT : Mise à jour du texte et des libellés des modalités : Mettre à jour les étiquettes de texte et de modalités pour une variable dans une étude existante.

    Notez que les modalités ne sont pertinentes que pour les variables fermées.

Vues d'analyse

  • GET : Lister toutes les vues : Renvoie la liste de toutes les vues d'analyse pour une étude donnée.

  • POST : Copier une vue : Copie d'une vue de d'analyse.

  • GET : Obtenir un lien vers une vue : Crée un lien éphémère ciblant la vue d'analyse spécifiée.

    Vous pouvez éventuellement indiquer un paramètre d'échantillon pour filtrer les données et ne traiter qu'une partie de l'échantillon total.
