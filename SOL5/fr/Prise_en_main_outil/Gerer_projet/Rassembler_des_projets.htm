Rassembler des études

La fonctionnalité Rassembler permet de rassembler les données (lignes du tableur) de deux études ou plus. Seules les variables existantes dans l’étude de référence sont conservées dans la nouvelle étude. Pour ces variables, seules les modalités présentes dans l’étude de référence sont retenues, même si d’autres existent dans les études ajoutées.

Cette fonctionnalité est utile pour centraliser les résultats dans un seul jeu de données pour analyse. Elle permet notamment de :

  • Gagner du temps en évitant une saisie ou une recopie manuelle.

  • Réaliser des analyses transversales sur plusieurs populations ayant répondu à un même questionnaire.

  • Comparer les résultats selon l’origine des données.

EXEMPLE : Une chaîne de restauration possède deux établissements : Le Bistro Bleu et La Table Verte. Chaque restaurant a diffusé un questionnaire de satisfaction avec les mêmes questions (qualité des plats, accueil, propreté...).
Objectif : Comparer les réponses selon le restaurant tout en centralisant les résultats.

Pour rassembler deux ou plusieurs études :

  1. Accéder à la liste des études en mode tableau.

  2. Sélectionner les études concernées.

  3. Cliquer sur Rassembler.

  4. Sélectionner l'étude de référence.

  5. Donner un nom à l'étude rassemblée.

  6. Cliquer sur Valider.

    Une fois les études rassemblées, une nouvelle variable intitulée Source sera ajoutée automatiquement dans la nouvelle étude. Elle permet d’identifier l’étude d’origine de chaque observation (chaque ligne du tableur).
