Qualité du jeu de données

La fonctionnalité Qualité du jeu de données permet d’évaluer la complétude et la documentation des données collectées. Elle est utile pour garantir la validité des analyses à venir en identifiant les lacunes éventuelles dans les réponses et la structuration des variables.

Pour y accéder :

  1. Accédez à la partie Données.

  2. Cliquez sur Qualité de l'échantillon.

Contenu de l'analyse :

  • Nombre d’observations : nombre total de réponses à l'enquête.

  • Nombre de variables : total de questions retenues dans le jeu de données.

  • Taux de remplissage global : pourcentage moyen de réponses effectives à l’ensemble des questions.

    REMARQUE : Une alerte vous indique si l’échantillon est suffisant pour obtenir des estimations fiables.

  • Taux de remplissage de la table des données : un graphique circulaire indique la proportion de cellules renseignées et non renseignées.

  • Documentation des variables

    Les variables sont classées selon leur type (fermées, échelles, numériques, textes) et leur niveau de complétude :

    • Intégralement documentées : toutes les cellules sont renseignées (100 %).

    • Correctement documentées : plus de 80 % des cellules sont renseignées.

    • Peu documentées : moins de 80 % des cellules sont renseignées.

  • Documentation des observations

    Un graphique circulaire évalue la qualité de chaque réponse individuelle sur l’ensemble des variables.

    • Intégralement documentées : 100 % des variables sont renseignées.

    • Correctement documentées : plus de 80 % des variables sont renseignées.

    • Peu documentées : moins de 80 % des variables sont renseignées.

  • Détail des taux de remplissage

    • Pour les variables :

      Un tableau détaille le nombre de variables bien ou mal documentées selon leur type.

    • Pour les observations :

      Un second tableau indique combien d’observations sont bien remplies pour chaque type de variable (fermées, échelles, numériques, textes), ainsi que celles :

      • Singulières (valeurs uniques)

      • Avec trop peu de variance (manque de diversité dans les réponses)

Appliquer une strate

Il est possible d'appliquer une strate pour filtrer la qualité du jeu de données sur une cible bien précise. Consultez la page "Définir une strate" pour plus d’informations.

Imprimer la qualité du jeu de données

Cliquez sur le bouton Imprimer pour lancer l’impression de l’évaluation de la qualité du jeu de données.
