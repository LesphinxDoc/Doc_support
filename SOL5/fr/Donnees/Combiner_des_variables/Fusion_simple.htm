Fusion simple

Cette fonctionnalité permet de créer une nouvelle variable fermée multiple dont les modalités sont toutes celles des variables sélectionnées.

EXEMPLE : Lors d'une enquête sur les loisirs, il est utile de combiner différentes activités en une seule variable pour simplifier l'analyse. La fonctionnalité "Fusion Simple" permet de regrouper des sports et des activités culturelles en une nouvelle variable fermée multiple. Cela aide à obtenir une vue d'ensemble des préférences de loisirs des répondants.
Dans l'exemple ci-dessous, nous avons fusionné les deux variables "Sports pratiqués" & "Activités culturelles" dans une nouvelle variable "Activités de loisirs.

Pour effectuer une fusion simple, procédez comme suit :

  1. Accédez à la partie Données, onglet Gestion des variables, puis cliquez sur Fusion simple.

  2. Sélectionnez les variables à fusionner.

  3. Définissez un nom et un libellé pour la nouvelle variable.

  4. Paramétrez le traitement des modalités identiques.

    Lorsque vous avez des modalités identiques qui sont présentes dans les variables à fusionner, vous pouvez soit :

    • Les regrouper en une seule modalité.

      EXEMPLE :
      Nous avons une modalité identique ("Rouge") dans les variables "Vos couleurs préférées" et "Couleur des vêtements", lors de la fusion dans la variable "Couleurs fusionnées", on affiche une seule modalité "Rouge".

    • Préfixer l'ensemble des modalités par le nom de leur variable.

      EXEMPLE :

  5. Cliquez sur Valider.

    La nouvelle variable créée peut être modifiée depuis la partie Structure, onglet Variables (uniquement pour les études créées par import de données).
