Modifier, ajouter ou supprimer des observations

Il est possible d'agir directement sur le fichier de données pour corriger des erreurs, compléter des informations ou ajuster des réponses si nécessaire. Pour accéder au tableur, cliquez sur la partie Données :

Il est alors possible de :

MODIFIER UNE OBSERVATION

Pour modifier directement une observation :

  1. Cliquez sur le bouton Déverrouiller.

  2. Cliquez sur la cellule à modifier depuis le tableur.

  3. Sélectionnez la nouvelle modalité.

  4. Cliquez sur le bouton Enregistrer les modifications pour appliquer les modifications.

AJOUTER UNE NOUVELLE OBSERVATION

Pour ajouter une nouvelle observation directement depuis le tableur :

  1. Cliquez sur le bouton Ajouter (au-dessus du tableau).

  2. Remplissez les cellules de la nouvelle observation insérée en dernière position.

  3. Cliquez sur le bouton Enregistrer les modifications pour appliquer les modifications.

SUPPRIMER UNE OU PLUSIEURS OBSERVATIONS

Pour supprimer des observations de votre fichier de données :

  1. Sélectionnez la ou les observations concernées.

  2. Cliquez sur le bouton Supprimer (au-dessus du tableau).

SUPPRIMER TOUTES LES OBSERVATIONS

Pour supprimer toutes observations affichées dans le tableur :

  1. Cliquez sur le bouton Supprimer tout.

  2. Renseignez le nombre de réponses à supprimer pour confirmer.

  3. Cliquez sur le bouton Supprimer.
