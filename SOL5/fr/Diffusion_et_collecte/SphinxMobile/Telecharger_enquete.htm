Télécharger une enquête sur Sphinx Survey

L'enquête peut être téléchargée de trois manières différentes sur l'application Sphinx Survey. En scannant un QR code, en important manuellement l'enquête, ou en important un fichier SMCF .

Scanner un QR code

  1. Depuis l'application SphinxSurvey, cliquez sur le bouton .

  2. Cliquez sur Scanner un QR Code puis scannez le QR code qui se trouve dans la page Paramétrage SphinxSurvey de votre compte SphinxOnline.

    Les informations ci-dessous seront automatiquement préchargées :

    • L'URL du serveur ;

    • Le nom du compte ;

    • Le nom de l'enquête.

  3. Renseignez le mot de passe (défini depuis la page Paramétrage SphinxSurvey) puis cliquez sur Continuer pour télécharger l'enquête.

Importer une enquête manuellement

  1. Depuis l'application SphinxSurvey, cliquez sur le bouton .

  2. Cliquez sur Importer une enquête manuellement.

  3. Renseignez les éléments suivants :

    • L'URL du serveur sur lequel votre compte est hébergé.

      Liste des serveurs mutualisés

      • Sphinx Online : https://www.sphinxonline.com

      • VIP Sphinx Online : https://cvip.sphinxonline.net

      • DECLIC : https://SphinxDeclic.com

      • Education : https://educ.sphinxonline.net

      • S1 : https://s1.sphinxonline.net

      • Campus : https://sphinx-campus.com

      REMARQUE : Si votre compte se trouve sur un serveur dédié ou un serveur installé chez vous, il suffit de rentrer l'URL correspondante.

    • Le nom de votre compte.

    • Le nom de l'enquête.

    • Le mot de passe.

  4. Cliquez sur Continuer.

  5. Un message de confirmation s'affichera suite au téléchargement, cliquez sur Fermer.

Importer un fichier SMCF

Pour importer un fichier SMCF depuis l'application SphinxSurvey, procédez comme suit :

  1. Téléchargez le fichier .smcf depuis la page Paramétrage SphinxSurvey de votre compte SphinxOnline, partie Installation de l'enquête.

  2. Depuis l'application SphinxMobile, cliquez sur le bouton .

  3. Cliquez sur Importer un fichier SMCF puis sélectionnez le fichier concerné.

    L'ouverture du fichier .smcf préchargera automatiquement les informations suivantes :

    • L'URL du serveur.

    • Le nom du compte.

    • Le nom de l'enquête.

  4. Renseignez le mot de passe puis cliquez sur Continuer pour télécharger l'enquête.
