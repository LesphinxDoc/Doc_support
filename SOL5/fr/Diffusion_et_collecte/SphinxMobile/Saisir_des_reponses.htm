Saisir, modifier et supprimer des réponses

En tant qu'enquêteur, vous pouvez saisir de nouvelles réponses via l'application SphinxSurvey mais également modifier ou supprimer les réponses existantes.

Effectuer une saisie

  1. Ouvrez l’enquête concernée depuis l'application SphinxSurvey.

  2. Cliquez sur le bouton + Nouvelle réponse puis procédez à la saisie.

    REMARQUE : Si votre enquête est multilingue, cliquez sur le drapeau afin de sélectionner la langue à utiliser.

    • Utilisez les boutons de navigation (ou la navigation séquentielle si applicable) du formulaire pour naviguer dans les pages du formulaire.

    • Utilisez le bouton-icône Sommaire pour accéder directement à une page.

    • Utilisez le bouton-icône Précédent pour Terminer et enregistrer la saisie ou Terminer sans enregistrer la saisie.

    Utilisation des ressources

    Télécharger une photo / insérer une signature manuelle, flasher un QR-code, récupérer la position GPS ou enregistrer un mémo vocal. Pour utiliser ces ressources, procédez comme suit :

    1. Depuis le questionnaire, cliquez dans le champ de saisie de la question concernée.

      REMARQUE : La question doit être de type "Texte/code".

    2. Cliquez sur l'icône Ressources.

    3. Sélectionnez l’élément à insérer.

      • Prendre une photo : prenez une photo avec l’appareil mobile puis validez son ajout en pièce jointe.

      • Localisation GPS : les coordonnées GPS sont automatiquement inscrites dans le champ correspondant.

      • Code Barre/QR code: dirigez l'appareil pour que le code s'inscrive au centre de l'écran, le texte associé sera automatiquement transféré dans le champ de formulaire.

      • Signature manuelle : une zone de dessin s’ouvre : il suffit de tracer la signature sur l’écran tactile.

      • Mémo vocal : vous permet d'enregistrer du son.

    REMARQUE : Les variables calculées et les conditions de présentation définies en expression ne fonctionnent pas sur l'application SphinxSurvey.

Modifier une réponse

REMARQUE : Pour pouvoir modifier des réponses depuis l'application SphinxSurvey, il faut que l'option "Permettre la modification des réponses.." soit bien cochée (voir partie Pré-requis de l'application & paramétrage depuis SphinxOnline ).

  1. Accédez à l'enquête concernée depuis SphinxSurvey.

  2. Cliquez sur le bouton X réponses.

  3. Sélectionnez l'observation concernée en cliquant sur le crayon.

  4. Appliquez les modifications puis enregistrez.

Supprimer une réponse

  1. Accédez à l'enquête concernée depuis l'application SphinxSurvey.

  2. Cliquez sur le bouton X réponses.

  3. Effectuez un glissement à gauche sur la réponse à supprimer puis cliquez sur Confirmer.

    Pour supprimer toutes les réponses, cliquez sur l'icône Corbeille en haut à droite de votre écran puis cliquez sur Supprimer toutes les réponses.
